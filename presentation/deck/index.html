부록 · 안전 계약
  • 확인된 것만 '됐어요' — LG 가전은 상태를 다시 읽고, 누름은 장치 응답과 전기 사용량으로 확인합니다.
  • 확인 못 하면 '확인 못 했어요' — 실패로 적지 않습니다. 실패로 보이면 다시 눌러 두 번 실행될 수 있어서입니다.
  • 정지가 먼저 — 정지는 전용 경로로 다른 명령보다 먼저 가고, 정지 뒤에 같은 명령을 다시 보내지 않습니다.
  • 열 나는 가전은 맡길 수 없음 — 전자레인지·인덕션은 매번 '네'를 받습니다.
  • 맡긴 것도 쉬는 때 — 조용한 시간·비상정지 중에는 알아서 하지 않습니다.
부록 · 기기 안 판단 범위
  • 사람 감지 — 본체 플랫폼 AI 런타임에서 공개 사전학습 검출 모델로 사람이 있는지 없는지만 봅니다. 사진은 저장·전송하지 않고, 카메라는 끌 수 있습니다.
  • 쓰는 곳 — 화면 쉬기·깨우기·인사, 그리고 '언제 물을지'. 실행·승인의 근거로는 쓰지 않습니다.
  • 방 밝기 — 본체 카메라의 아주 작은 회색 평균값(16×12)만 씁니다. 영상은 저장하지 않습니다.
  • 언어 모델 — 정해진 동작 목록에서 하나를 고르기만 하고, 실행은 늘 사람이 '네'로 확인합니다. 새 모델을 학습시키지 않았습니다.
  • 평가(10월 26일, 고정 50문장) — 규칙으로 먼저 거른 뒤 맞힘 77% · 잘못 고름 6%.
부록 · 습관 판단 규칙
  • 세는 기간 — 최근 28일의 직접 사용 기록.
  • 묶기 — 앞뒤 45분 안에 모인 사용을 한 시간대로 봅니다.
  • 습관 — 서로 다른 날 3일, 3번 이상.
  • 묻는 때 — 평소 시각 10분 전, 사람이 있을 때.
  • 쉬기 — 연달아 두 번 거절하거나 답이 없으면 7일 쉽니다. '이미 했어요'는 거절로 세지 않습니다.
  • 맡기기 — 확인 칸을 보고 사람이 눌러야만. '네'를 여러 번 받아도 저절로 바꾸지 않습니다.

부록 · 누름 장치
  • 구조 — 엔코더 모터 2개로 움직이는 CoreXY 2축(X·Y) + 누름 축.
  • 좌표 매핑 — 가전 앞면 사진에서 버튼 위치를 골라 좌표로 저장하고, 그 좌표로 이동해 누릅니다.
  • 지금 상태 — 좌표 이동은 확인했고, 실제 누름 정확도는 개선 중입니다.
  • 연결 — 본체 → 실행기(RPi4, Wi-Fi·페어링 키) → 모션 보드(ESP32). 걸림 알람이 나면 재시도 없이 멈춥니다.
  • 끝 확인 — 콘센트 모듈의 전기 사용량으로 가동·가열 종료를 봅니다.
