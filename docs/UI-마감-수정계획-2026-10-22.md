## 3. 우선순위와 구현안

### 1단계 — 기록 없음과 조회 실패 구분 (필수, S~M)

**확인한 사실:** 가전 상세의 `_TodayUse`는 `historyProvider.valueOrNull ?? []`로 로딩·오류를 빈 목록과 합친다. 빈 목록에는 ‘오늘은 아직 사용하지 않았어요’라고 표시한다. 가전 자체에서 직접 한 조작까지 추적한다는 근거도 없다.

- 코드: [appliance_detail_screen.dart](../app/lib/screens/appliance_detail_screen.dart), 기준 418·434~435줄.
- 시험: [appliance_detail_test.dart](../app/test/screens/appliance_detail_test.dart).
- 변경: 로딩 / 조회 실패 / 정상 조회했지만 해당 기록 없음 / 기록 있음의 네 상태를 나눈다. 재조회 중에는 이전 기록이 유효한지와 최신 조회 실패 여부를 구분하고, 오류를 ‘사용 없음’으로 바꾸지 않는다.
- 문구 후보: 로딩 ‘기록을 불러오고 있어요’, 오류 ‘기록을 불러오지 못했어요’, 정상 빈 목록 ‘오늘 SimpleLay에 남은 기록이 없어요’. 최신 제품 용어와 길이를 확인해 확정한다.
- ‘새로 보기’가 필요하면 기존 조회 갱신 경로를 사용한다. 서버 계약·기록 보관 범위는 바꾸지 않는다.
- **수정 전 실패 확인:** 조회 오류·로딩에서 ‘오늘은 아직 사용하지 않았어요’가 나오지 않아야 한다는 위젯 시험을 먼저 쓴다. 현재 코드에서 실패함을 기록한 뒤 수정한다.
- 완료 조건: 네 상태가 구별되고 가전별 필터가 유지된다. SimpleLay 밖의 조작을 ‘안 했다’고 단정하지 않는다.

### 2단계 — 키오스크에서 화면 그림과 실제 가전 구분 (필수, M)

**확인한 사실:** 정지 미확인 골든은 ‘취소 버튼을 손으로 눌러 주세요’ 옆에 실제 조작부와 닮은 노란 취소 칸을 보여 준다. 캡션은 ‘직접 누를 버튼이에요’다. 사용자가 그 그림을 누를 수 있다고 생각할 가능성은 **사용성 추정**이며 아직 사람에게 시험하지 않았다.

- 코드: [hold_view.dart](../rpi5-touchscreen-app/lib/widgets/kiosk/hold_view.dart), 기준 221·418줄. 공통 그림은 [panel_picture.dart](../rpi5-touchscreen-app/lib/widgets/kiosk/panel_picture.dart).
- 시험 출발점: [kiosk_redesign_panel_test.dart](../rpi5-touchscreen-app/test/kiosk_redesign_panel_test.dart). 기존 hold·비상정지 시험도 찾아 관련 경우를 추가한다.
- 변경: 사람이 취소를 눌러야 하는 상태에만 ‘실제 전자레인지에서 취소를 눌러 주세요’처럼 **대상과 장소**를 명시한다. 이름을 코드에 고정하지 않고 현재 대상 가전 이름·실제 취소 버튼 이름으로 만든다. 버튼 정보가 없으면 이름을 지어내지 않는다.
- 그림은 위치 설명용으로 유지하되 실제 화면 조작과 시각적으로 구분한다. 캡션·비대화형 Semantics를 우선 확인하고, 터치 가능한 단추처럼 보이는 강조는 골든과 사용자 확인으로 조정한다.
- **정지 버튼의 자리·크기·처리 경로는 유지한다.** 미확인 상태에서 정지를 숨기거나 비활성화하지 않는다. 서버가 모르는 정지 결과를 화면만으로 성공 처리하지 않는다.
- **수정 전 실패 확인:** 해당 상태에서 ‘실제 가전’ 안내가 있고 버튼판의 각 칸이 실행 가능한 버튼으로 접근성 트리에 노출되지 않는지 시험한다. 기존에 만족하는 조건은 ‘기존 통과’, 새 안내가 없어 실패하는 조건은 ‘수정 전 실패’로 구분한다.
- 완료 조건: 정지 미확인·비상정지·일반 실행·연습 각각에서 안내가 실제 동작과 맞는다. 1~2m 거리와 큰 글씨에서도 핵심 행동·정지가 보인다.

### 3단계 — 루틴에서 자동 실행을 찾는 비용 줄이기 (필수 검토, M)

**확인한 사실:** ‘내 루틴’ 안의 시각 루틴에도 자동 스위치가 있고 별도 ‘자동으로 하기’ 탭도 있다. 후자는 독립 규칙 목록이다. 둘의 차이를 사용자가 이해할지는 **미검증**이다.

- 코드: [routines_screen.dart](../app/lib/screens/routines_screen.dart), 기준 118~147·677~678줄. 다음 회차 조작은 [skip_next_control.dart](../app/lib/widgets/skip_next_control.dart).
- 시험: [routines_screen_test.dart](../app/test/screens/routines_screen_test.dart), [skip_next_test.dart](../app/test/screens/skip_next_test.dart).
- 먼저 팀 밖 사람에게 ‘매일 저녁 켜지는 공기청정기를 오늘만 건너뛰기’와 ‘계속 자동으로 켜지지 않게 하기’를 시킨다. 서로 다른 동작임을 이해하는지 기록한다.
- 최소 변경안: 현재 목록·분류·서버 연결은 유지한다. 시각 루틴과 상황 조건 규칙이 어느 목록에 있는지 **각 목록에서 짧게 설명**한다. 범례를 더 늘리는 해결은 피한다.
- 행은 ‘이름 → 언제 → 자동 여부 → 지금 하기’ 순서로 읽히게 한다. 같은 정보를 배지·스위치·범례가 반복하는 곳만 줄인다. ‘다음’은 다음 예정 표시라는 뜻을 보존한다.
- ‘자동’ 스위치와 루틴 전체 켜기 스위치가 같은 역할처럼 읽히지 않도록 실제 스위치 대상에 맞는 화면 읽기 이름을 유지한다.
- 탭 이름 변경·자동 목록 통합은 **사용자 결정이 필요한 후속안**이다. 이번 승인으로 구조 개편까지 확정된 것은 아니다. 짧은 안내로 혼동이 풀리면 현 구조를 유지한다.
- 회귀 시험: 예약·자동 켜짐·자동 꺼짐·오늘만 건너뜀·연결 실패·독립 규칙 없음·큰 글씨. 실행은 기존 승인 경로를 거치고, 표시 정리로 API 호출 수가 늘지 않는다.
- 완료 조건: 네 과업 중 ‘자동 실행 끄기’를 설명 없이 찾고, ‘오늘만 건너뛰기’와 구분한다. 사람 시험 전에는 성공으로 적지 않는다.

### 5단계 — 대기 화면의 날씨·시계 비중 (이번에는 보류)

큰 시계·날씨를 일괄 축소하지 않는다. 대기 중 생활 정보가 중심인 것은 제품 선택으로 성립한다. 제안·실행·위험이 생기면 그 과업이 우선하고, 자동 실행 결과 한 줄이 정지나 주요 안내를 가리지 않는지만 확인한다. 캡처의 빈 공간 자체를 결함으로 간주해 카드를 추가하지 않는다.

## 4. 검증 순서와 실제 사용자 과업

### 코드·화면 검사

1. 관련 시험을 먼저 추가하고 수정 전 실패를 확인한다. 이미 통과하는 경우는 결함을 발견했다고 쓰지 않는다. 실패 확인을 위해 사용자 변경을 지우거나 stash하지 않는다.
2. 폰 **360×780dp**, 글씨 1.0·2.0에서 홈·루틴·가전 상세·승인·결과를 확인한다. 큰 글씨에서 세로 스크롤은 허용하되 고정 영역이 본문·행동 버튼을 가리면 안 된다.
3. 키오스크 기준 해상도와 큰 글씨 골든에서 정지 미확인·비상정지·실행·연습·결과를 확인한다. 정지 위치와 크기를 바꾸지 않는다.
4. TalkBack은 읽는 이름·순서·선택 상태·실행 중 정지·화면 닫은 뒤 초점을 실제로 확인한다. Semantics 위젯 시험 통과를 실제 낭독 확인으로 적지 않는다.
5. 폰 조작 대상은 **48dp 이상**을 기준으로 확인한다. 키오스크는 실제 패널의 물리적 크기와 1~2m 가독을 별도로 확인한다. 폰 dp와 키오스크 캔버스 픽셀을 같은 기준으로 취급하지 않는다.
6. 변경한 골든은 **눈으로 먼저 확인한 뒤** 갱신한다. 화면 읽기·동작 시험과 골든 비교는 서로 대신하지 않는다.

- 처음 1~2명은 **형성적 사용성 점검**이다. 고령자·시각장애인 전체의 사용성 검증이나 통계적 성능 비교로 주장하지 않는다.
- 가능한 경우 ‘실제 가전에서 취소를 누르세요’ 화면도 별도 보여 주고 **화면과 실제 가전 중 어디를 누를지** 물어본다. 화면의 버튼판을 누르면 혼동 사례로 기록한다.
- 목표는 도움 없이 핵심 과업을 끝내고 위험한 대상을 혼동하지 않는 것이다. 참가자가 막힌 곳을 먼저 고치고 주관적 점수를 반복해서 올리는 작업은 멈춘다.
