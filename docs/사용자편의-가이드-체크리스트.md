# 사용자 편의(접근성) 가이드 체크리스트

> 2026-08-23 리서치. 공인 표준 3종을 SimpleLay(폰 앱 + 키오스크)에 매핑한 실행 체크리스트.
> ✅ = 적용됨(적용 날짜), ⬜ = 할 것(우선순위), ~ = 부분 적용.
> 사용자 테스트(장애인협회 자문·W5~6)와 발표 자료의 "고민의 깊이" 근거로도 활용한다.

## 참조 표준

| 표준 | 대상 | 핵심 |
|---|---|---|
| **KS X 3253** 모바일 앱 콘텐츠 접근성 지침 2.0 | 폰 앱 | 19개 항목: 인식(대체텍스트·명도대비 3:1↑·색 무관 인식…), 운용(초점·누르기 동작·응답시간 조절·컨트롤 간격·알림), 이해(일관성·예측 가능·입력 도움·오류 방지), 견고성(보조기술 호환) |
| **KS X 9211** 무인정보단말기 접근성 지침 (2022 개정, 법적 의무화 흐름) | 키오스크 | 음성 안내 제공, 조작 대체 수단, 오류 시 의사소통 수단, 물리 접근성(설치 높이 등 — HW 트랙) |
| **고령층 친화 디지털 접근성 표준** — 키오스크 적용가이드 (서울디지털재단, NIA 인증 평가 항목과 정합) | 키오스크 | 3원칙(정보구조·서비스 흐름·대체수단)·8지침·22방법: **글자 14pt↑**, 명도 대비, 음성 안내, **터치 영역·간격**, 조작 절차 단순화, 쉬운 용어, 시간 제한 여유 |
| WCAG 2.2 / Material Design | 공통 | 터치 타깃 **24px 최소(AA)·44px 권장(AAA)·48dp(Material)**, 대비 4.5:1(본문) |

## 폰 앱 체크리스트 (KS X 3253 기준)

### 인식의 용이성
- ~ **대체텍스트/Semantics** — 마이크 버튼 Semantics(8/23). ⬜ 가전 선택 칩·연결 카드·제안 카드·KPI 스트립에 Semantics 라벨 (S6 전 마무리, 중)
- ✅ **명도 대비** — 라이트 모드 테마 토큰 수리(8/21)로 저대비 하드코딩 제거. ⬜ 주요 화면 대비 4.5:1 실측 1회 (낮음)
- ⬜ **색에 무관한 인식** — 성공/실패가 색+아이콘(✓/✕)으로 이미 이중 표현. 상태 dot류 점검 (낮음)
- ✅ **명료성(청각 채널)** — 실행 결과 TTS(8/22)

### 운용의 용이성
- ✅ **누르기 동작 지원·터치 피드백** — 수동 조작 InkWell+햅틱(8/23)
- ✅ **컨트롤 간격/크기** — 수동 버튼 그리드 셀은 충분(≥48dp). 삭제 아이콘 히트박스 확대(8/23). ⬜ 남은 소형 탭 대상 전수 점검: 24px 미만 금지·44px 지향 (중)
- ✅ **응답시간 조절 여지** — 키오스크 제안 카운트다운은 KioskTimings 단일 상수(늘리기 쉬움). ⬜ 리허설 피드백에 따라 10초→15초 검토 (낮음)
- ✅ **알림 기능** — 실행 완료/실패를 시각+음성 이중 채널

### 이해의 용이성
- ✅ **오류 방지·확인** — 파괴적 동작(가전 삭제) 확인 다이얼로그(8/23), 긴급 정지는 실동작(8/20)
- ✅ **쉬운 오류 문구** — raw 예외 → 사용자 언어("연결을 확인해주세요") 전환(8/21~)
- ⬜ **입력 도움** — 서버 주소 입력에 정규화(8/22)로 대부분 해소. API 키 필드 도움말 있음. (완료로 간주 가능)
- ⬜ **일관성·예측 가능성** — 화면 간 버튼 위치·용어 통일 점검 1회 (낮음, W9 사용자 테스트와 함께)

### 견고성
- ⬜ **보조기술(TalkBack) 호환** — 실기기에서 TalkBack으로 핵심 3동선(음성 명령→상태 확인 / 수동 조작 / 제안 승인) 완주 테스트 (중, 실기기일)

## 키오스크 체크리스트 (KS X 9211 + 고령층 표준)

- ✅ **음성 안내** — 제안·결과·위험 경보 TTS(8/22), 토글 제공. KS X 9211의 1차 요구 충족
- ✅ **글자 크기** — 큰 글씨 모드 1.22배(8/23). ⬜ 기본 글꼴이 14pt 상당 이상인지 주요 화면 실측(800x480 설계 캔버스를 15인치 패널에 확대한 실물 기준 — 패널 해상도 확인 필요) (중, 실기기일)
- ✅ **터치 영역·피드백** — 뒤로가기 52px+잉크, 버튼 셀 88x60+잉크(8/23)
- ✅ **조작 절차 단순화** — 제안 승인은 탭 1회, 수동 실행 탭 1회 (고령층 표준의 '흐름 단순화' 부합)
- ✅ **시간 제한 배려** — 카운트다운 상수화. ⬜ 사용자 테스트 후 값 조정
- ⬜ **쉬운 용어** — "DND" 같은 외래 용어 → "방해 금지" 등 순화 점검 1회 (낮음)
- ⬜ **오류 시 의사소통** — 실패 화면에 "보호자/도움 요청" 동선은 미래 과제(보호자 알림과 묶임, W7 여유 시)
- (HW 트랙) 설치 높이·시야각 등 물리 접근성은 KS X 9211 참조해 하우징 설계 시 반영

## 발표 활용 포인트

- "KS X 3253·KS X 9211·고령층 친화 표준을 기준으로 설계했다"는 문장 + 이 체크리스트 표 1장 —
  교수님이 강조한 **"어디까지 고민했는지"의 물증**이 된다.
- 장애인협회 자문(W5~6) 때 이 체크리스트를 들고 가서 항목별 확인을 받으면 "표준 준수 + 당사자 검증" 이중 근거 완성.
