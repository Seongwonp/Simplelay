## 검증

- 항목별 수정 전 실패를 확인한 뒤 수정했다. 기대한 회귀 실패와 별도로 L3 시험 속성 이름 오타를 고쳐 실제 시간 초과를 재현했다.
- Windows 시계 해상도로 흔들린 UART 백오프 검사는 고해상도 시계·충분한 간격으로 조정했다. 기존 짧은 ADC 시험도 최소 표본 수를 확보하도록 관측 시간을 늘렸다.
- 첫 전체 시험: 2,532 통과·1 실패. 기존 정지 대기 시험의 6초 한도 중 단조 시계가 약 960초 뛰었다. 코드 변경 없이 해당 시험만 재실행해 통과했다.
- 두 번째 전체 시험 2,533 통과 후 v3 기동 경로 보완을 추가했다. **최종 전체 시험 2,534 통과**(저장소 가드 포함, 98.82초). `PYTHONUTF8=1`, `.venv/Scripts/python.exe -m pytest -q rpi rpi4 --basetemp C:\Temp\pt-f5-35c9a1`. 기존 라이브러리 폐기 예정·캐시 권한 경고 3건.

## 남은 것

- 실제 ADC·CT·모션·정지 지연 측정, 분압·gain·영점 및 수집 신선도/공백/개수 한계값 보정, MCU 실제 Z 시각 정렬.
- Docker 엔진이 실행 중이지 않아 이미지 빌드는 미검증. 장치 전달·권한 및 실보드 import/기동 확인 필요.
- Dart는 변경·실행하지 않았다. 음성 HTTP 실패 처리 등 앱 수리는 데스크톱 몫이다. 실폰·실물 검증은 하지 않았다.
