공용 부품은 네 상태가 같은 뜻으로 쓰는 **대상 가전 한 줄**(`KioskTargetLine`)

  키오스크에는 음성 입력이 없어 '말하거나'를 쓰지 않는다(백로그 B12).

  설치한 적 없는 전자레인지를 세우지 않는다.
- **제안**: 서버가 주던 `appliance_id`를 받지 않고 있었다. 이제 제안 **자신의**
  대상을 말하고, 모르면 대상 줄을 그리지 않는다(지금 고른 가전으로 메우지
  않음). 왼쪽 질문, 오른쪽 번호 붙은 '누를 순서'. 다섯 단계 이상은 세로 목록이

## 개발자 모드 Phase 0 — 계약만

`rpi/services/developer_session.py`. **API 경로·화면 진입·실제 모션 어댑터는
없다.** 계획서 3.4 안전 불변식을 테스트 48건이 못 박는다:

- 허용 목록(status·home·sensor read·stop·jog·press) 밖은 거절하고 어댑터에
  닿지 않는다 — 셸 문자·제어 문자·여분 토큰·범위 밖 이동량 포함.
- 제어권 하나. 일반 실행 중에는 세션을 열지 않고, 세션 중 실행이 시작되면 명령을
  받지 않는다. `blocks_execution()`이 실행기에 알릴 자리(연결은 다음 단계).
- heartbeat가 끊기면 정지 후 세션 종료. 정지 요청이 실패해도 제어권은 남기지 않는다.
- 긴급 정지·stop은 세션·대상 검증보다 먼저 항상 닿는다.
- 매 명령마다 대상 가전 확인, 보정 전 press 차단, jog는 0.3s TTL로만.
- jog 상한 5mm는 **하드웨어 확인 전 임시값**이다(H3·H4에서 정한다).
