# 실측 기록표 (원가 · 설치 시간 · 대안 비교 · 성공률 · 정지 지연)

작성 2026-09-14. **빈 표와 측정 방법만 둔다.** 실측하지 않은 숫자는 채우지 않는다 —
발표·질의응답에 쓰는 숫자는 이 표에 기록된 측정에서만 가져온다.

측정 순서와 원시 데이터 수집 도구는 [하드웨어 연결 설계](하드웨어-연결-설계.md) §6을 따른다.

## 공통 규칙

- 칸마다 **측정일·측정자·조건**이 추적돼야 한다. 조건이 바뀌면 새 행으로 쓴다.
- 원시 데이터(CSV·영상)는 저장소에 올리지 않는다. 이 문서에는 **요약 수치와 원시 파일 이름**만 적는다.
  - 센서 원시값: `python -m rpi.bench.raw_recorder` → `data/bench/` (git 무시 경로)
  - 실행 이력: 서버의 실행 이력 CSV 내보내기(작업 ID·결과·버튼별 시도 수·정지 지연)
- 추정·조사값은 실측과 섞지 않는다. 쓸 때는 비고에 `추정` 또는 `조사(출처)`를 붙인다.
- 빈칸은 "아직 모름"이다. 0이나 "-"로 메우지 않는다.

## 4. 성공률

**측정 방법**

- 대상: 전자레인지 버튼 3개부터. 버튼마다 목표 반복 수를 정하고 시작 전에 적는다.
- **사람 판정이 기준이다.** 가전 표시창 변화·버튼음을 영상으로 남기고, 누름이 실제로
  들어갔는지 사람이 판정한다. 센서 판정은 사람 판정과 비교하는 대상이다.
- 실패 주입(리허설 기능)을 쓴 시도는 따로 표시하고 자연 성공률 합산에서 뺀다.
- mock 모션 실행은 기록하지 않는다(실행 이력의 실행 모드로 확인).

**시도 기록** (한 행 = 한 버튼 누름)

| 측정일 | 가전 | 버튼 | 시도 번호 | 실패 주입 | 첫 시도 누름(사람) | 최종 누름(사람) | 재시도 수 | 센서 판정 | 소요 시간(초) | 작업 ID | 원시 파일 | 비고 |

## 5. 정지 지연

정지는 세 시각으로 나눠 잰다. 명칭과 보장 범위는 [하드웨어 연결 설계](하드웨어-연결-설계.md) §5.

| 시각 | 뜻 | 측정 방법 |
|---|---|---|
| **t0 누름** | 사람이 정지 버튼을 누른 순간 | 영상 프레임(화면·버튼과 장치를 한 화면에) |
| **① 요청 접수** | 서버가 정지를 접수 | 실행 이력의 `stop_requested_at` |
| **② 루프 종료** | 실행 루프가 끝남 | 실행 이력의 종료 시각. `stop_latency_seconds` = ① → ② |
| **③ 물리 정지** | 모터가 실제로 멈춤 | 엔코더 속도 0 시각, 없으면 고속 촬영 프레임 |

- 영상과 서버 시각을 맞추려면 촬영 시작 때 화면에 서버 시각을 띄우거나 기록기의
  marker를 찍는다. 시각 맞춤 오차를 비고에 적는다.
- 정지 경로(키오스크·폰·물리 버튼)와 정지 시점(이동 중·누름 중·재시도 대기 중)을
  행마다 적는다. 경계에서만 반영되는 현재 구조에서는 시점에 따라 값이 크게 다를 수 있다.

| 측정일 | 경로 | 정지 시점 | t0 → ① (ms) | ① → ② (ms) | ② → ③ (ms) | t0 → ③ (ms) | 노드 미확인 | 작업 ID | 영상·원시 파일 | 비고 |
|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |

| 요약 | 경로 | 표본 수 | t0 → ③ p50 (ms) | t0 → ③ 최대 (ms) |
|---|---|---|---|---|
|  |  |  |  |  |
