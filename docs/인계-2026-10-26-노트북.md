- **공공 데이터:** 기상청 예보(+바깥 습도)·특보, 에어코리아(가까운 측정소 실시간·예보), 천문연 공휴일·해 뜨고 짐, 생활기상지수 자외선. 모두 같은 공공데이터포털 키, 활용신청 완료.

## 3. 크레딧 절약 규칙 (같은 계정 — 노트북에서도 그대로)

- 메인 세션은 **판단·검토·커밋·배포만**. 구현은 서브에이전트(Opus), 자료조사는 서브에이전트(Sonnet). 에이전트끼리는 **영어**, 보고는 결과만 짧게.
- 서브에이전트 지시문은 한 번에 자세히(파일·계약·게이트·금지 사항) — 다시 묻는 왕복을 줄인다. 서로 다른 폴더만 건드리는 일만 동시에.
- 기다리는 동안 상태를 들여다보지 않는다(끝나면 알림). 배포는 묶어서 한 번에.
- 큰 출력 금지: 시험은 `| tail -1`(단, analyze·시험 게이트는 실제 'All tests passed'·error 0을 확인), 로그는 grep으로 필요한 줄만.
- **Codex CLI(사용자 크레딧이 남아 있을 때):** `codex exec -m gpt-5.6-sol -s workspace-write`(격리 모드, 0.164 이상), 보드 접속이 필요하면 `-c sandbox_workspace_write.network_access=true`, 백그라운드면 **표준 입력을 닫는다**(`< /dev/null` — 안 그러면 입력을 기다리며 멈춘다). 격리를 끄는 `danger-full-access`는 우리 쪽 안전 설정이 막는다 — 필요하면 사용자가 Codex 데스크톱에서 직접.

## 4. 키오스크 빌드·확인 (노트북에도 빌드 환경이 있다고 함)

- 키오스크 설치 파일은 **저장소 밖 로컬 빌드 환경(도커)**에서 만든다 — 명령은 그 PC의 로컬 메모를 따른다(플랫폼 이름을 저장소에 쓰지 않는다).
- **빌드 도구는 실패해도 성공처럼 끝난다.** 빌드 뒤 로그에 'Build error'가 없는지, 설치 파일 시각이 방금인지 꼭 본다. 보드 빌드 환경 Flutter가 옛 판이라 새 API(예: `Switch.activeThumbColor`)는 거기서만 깨진다 — `WidgetStateProperty` 쓰기.
- **키오스크 화면 캡처:** `ssh root@<RPi5 주소> "sh /mnt/rawdata/simplelay/capture.sh" > panel.png` — 설치 뒤 꼭 캡처로 확인(노란 밑줄, 잘림, 옛 판이 그대로인지).
- 화면 선을 뺐다 꽂으면 키오스크가 화면에 안 나오고 HDMI 소리도 사라질 수 있다 — 앱 다시 시작, 안 되면 화면 선을 꽂은 채 재부팅.
- RPi5 공간이 좁다(언어 모델 1.6GB). 배포 때 `docker image prune -f`, 옛 날짜 태그 이미지는 바로 전 판만 남긴다.
