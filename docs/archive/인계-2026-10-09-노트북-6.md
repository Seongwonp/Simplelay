## 1. 실측 그래프 도구 (하드웨어 전 준비)
- `docs/실측-계획-결선.md`: 그래프 4종의 목적·측정 방법·횟수·합격선(미정이면 "실측 후 정함")·기록 형식.
  1. 목표 좌표 vs 실제 누른 위치 오차(버튼별 산점도, 목표 원점 기준)
  2. 버튼별 누름 성공률(첫 시도/재시도 포함, 버튼 3개 × 30회 이상)
  3. 정지 요청 → 모터 정지 지연 분포(요청 시각·ACK·실제 정지 영상 프레임 구분)
  4. CT 전력 파형 위 "시작 확인" 판정 시점 표시(전자레인지 1회 사이클)
- `scripts/plots/`에 원시 기록기(`rpi/verifier/recorder.py`) 출력과 실측 기록표 CSV를 받아 위 4종 PNG를 만드는 스크립트. 합성 데이터로 시험하되, 합성 입력으로 만든 그림에는 반드시 "예시(합성 데이터)" 워터마크. 실측 데이터로 만든 그림에만 워터마크 없음.
- 테스트: 스크립트가 빈 데이터·결측을 거절하는지, 워터마크가 합성일 때만 붙는지.

## 2. A/B 비교 실험 설계
- `docs/AB-비교-실험.md`: 비교군 ① 사람이 직접 누름 ② 확인 없이 누르기만(단순 누름 장치 흉내 — 같은 갠트리로 L1~L3 끄고) ③ SimpleLay(확인·재시도). 같은 과업(전자레인지 즉석밥 → 시작), 일부러 좌표 2mm 어긋남 같은 실패 조건 포함. 지표: 과업 성공, 잘못된 상태로 끝난 횟수, 사용자가 알아챈 시간.
- ②를 위해 L1~L3 판정을 끄는 비교 모드가 필요하면 개발자 모드·env 게이트로만(기본 꺼짐, 시연 화면에 "비교 실험 모드" 표시). 모의로 먼저 돌려 표 형식만 확인하고 결과는 "모의"로 표시.

## 3. 피드백 Before/After 한 장

## 4. 실제 사용자 의견 받기 계획
