# 심사 관점 평가 (2026-10-07, `eb782ad` 기준)

Opus 서브에이전트가 결선 심사위원 관점에서 읽기 전용으로 검토했다. 이 평가를 바탕으로 같은 날 밤 소프트웨어·문서 수리를 진행했다.

## 점수 (지금 상태로 11/6에 선다고 가정)

| 항목 | 점수 | 한 줄 근거 |
|---|---|---|
| 완성도 (60) | 26 | 계약·시험·보드 배포는 탄탄하다. 하지만 시연 중심 평가에서 실물 누름이 0건이다. 6장면 중 ②~⑤는 모의 또는 주입이다 |
| 독창성 (20) | 12 | 누름 → 판정 → 보정 재시도와 승인 결속은 차별점이다. 부착형 누름 자체는 이미 알려진 개념이다 |
| 활용성 (20) | 13 | 기존 가전을 그대로 쓰는 것, 승인 게이트, 고령자 대상은 설득력이 있다. 당사자 평가·비용 비교는 없다 |
| 가산점 (10) | 1 | (1) 세 보드 연동 증거 미측정. (2) 무대 융합 장면이 주입이다 |
| **합계** | **약 52** | 전자레인지 갠트리로 **실물 폐루프를 1회만 성공**시켜도 완성도가 +8~12 오를 수 있다 |

## 점수를 잃는 이유 (순위)

1. **실물 누름 0건(치명):** 전자레인지 갠트리 1대 실물을 "반드시 성공시킬 장면"으로 좁힌다.
   - 세탁기·인터폰은 같은 작업 영역 안의 조작부 모형으로 둔다.
   - 10/20 영상 촬영 전에 H0~H1 합격 기록(예: 30회 누름 성공률)을 확보한다.
   - 하드웨어·팀이 할 일이다.
2. **가산점 증거 0:**
   - (1) 앱 권한으로 플랫폼 서비스 최소 호출을 1건 성공시킨다. ESP32 CT 1개를 배선해 "제안 → 승인 → 실행 → CT 검증" 1회를 기록한다.
   - (2) 무대에서 실제 두 입력을 교차 확인한다. 예: 전자레인지 CT 상승과 비프음.
3. **L1 "융합"이 사실상 전류 단독 판정:** 진리표와 실제 동작이 달랐다. 10/7에 진리표를 고쳤다. 발표에서는 "L1은 전류 판정, 음향은 보조 신뢰도"라고 말한다.
4. **전류 센서 측정 위치가 문서마다 다르다:** "누름 장치(Z 구동부) 전류, 정확한 지점은 HW 확정 전"으로 통일한다. 관측 구간을 Z 누름 구간으로 좁히는 일이 남았다.
5. **제출물 수치·버전이 낡았다:** 최종 시험을 돌린 뒤 한 번에 맞춘다.
6. **이력 재작성으로 끊긴 커밋 해시:** 문서 안 해시를 새 해시로 바꾼다(10/7).
7. **README 구조·링크가 현재 구성과 맞지 않는다:** 10/7에 정리한다.
8. **영상 일정과 주입 장면 비중:**
   - 영상에는 실물 전자레인지 장면 1개와 실물로 만든 실패 장면 1개를 넣는다. 실패는 좌표를 일부러 2mm 어긋나게 해서 만든다.
   - 10분 발표에서 실물이 30초도 안 되면 "시뮬레이터 발표"로 읽힌다.

## 예상 질의와 정직한 답

1. **"무대에서 실물로 된 것과 모의는 무엇인가? 실물 성공률은?"**
   - 실측값이 있으면 그 값을 말한다. 없으면 "아직 측정 전"이라고 말한다. 숫자를 지어내지 않는다.
   - 세탁 완료와 비상정지 래치는 시연 주입·모의이고, 화면에도 그렇게 표시한다.
2. **"전류 센서는 어디를 재나? 가전을 뜯나? 음향은 판정에 기여하나?"**
   - 가전은 뜯지 않는다. 누름 장치 쪽 전류와 마이크를 쓴다.
   - 지금은 전류가 필수이고, 음향은 신뢰도를 올리는 보조다. 오탐·미탐 비교는 실측 전이다.
3. **"가산점 (1) 3종 연동 증거는?"**
   - 측정한 것만 증거 대장에 적었다.
   - 앱 권한 플랫폼 호출과 ESP32 실물 연동은 [그날 상태 그대로] 말한다.
4. **"사진 좌표를 갠트리 mm로 어떻게 맞추나? 오차는?"**
   - 프레임 네 모서리로 변환하고, 확인 주행으로 사람이 확인한다.
   - 오차는 실측 전이다. 그래서 L1 보정 재시도로 다시 누른다.
5. **"비상정지는 가전 전원만 끊는데, 갠트리가 폭주하면? 정지 지연은?"**
   - 모터는 별도 전원 스위치와 MCU 워치독으로 멈춘다.
   - 정지 ACK와 실제 정지는 구분해서 표시한다. 정지 지연은 [실측값 / 측정 전]으로 말한다.
