# 스크린샷

이 폴더의 PNG는 **2026-08-30 디자인 개편 이전** 캡처다. 실기기/에뮬레이터에서 찍은
것이라 아이콘·폰트가 실제 그대로지만, 화면 구성과 문구는 지금과 다르다:

- 홈의 "AI가 N개 패턴을 발견했습니다" 학습 통계 카드는 삭제됐다
- 제안 문구가 "승인/거부" → "지금 실행/나중에"로 바뀌었다
- 제안 목록이 "3단계 동작" → 실제 버튼 순서를 보여준다

현재 화면은 각 앱의 골든 이미지에서 볼 수 있다(테스트 렌더라 아이콘은 네모로 나온다):

- `app/test/goldens/` — 폰 홈(다크·라이트·빈 상태·200% 확대)
- `rpi5-touchscreen-app/test/goldens/` — 키오스크 대기·제안·실행·완료

갱신: `flutter test test/screenshot_test.dart --update-goldens`

실기기 캡처는 다음 실기기 검증 때 다시 찍어 이 폴더를 교체할 것.
