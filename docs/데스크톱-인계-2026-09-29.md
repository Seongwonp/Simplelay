## 2. 데스크톱이 이어서 할 일 (우선순위)

### A. Flutter 화면에 새 서버 필드 반영 (S~M)
`/status`·SSE의 `last_retry_count`, `last_operation_confirmed`, `last_operation_source`, `last_operation_detail`; `/history`의 `operation_confirmed`, `buttons[].attempts`; 시나리오 `wash_then_dry`, 가전 `dehumidifier`. 필드 이름은 `rpi/api/schemas.py`와 [gaps-g1-g6](devlog_2026-09-29-gaps-g1-g6.md)에서 확인. 폰 재시도 배지는 기존 `retry_count`를 읽어 뜰 것으로 예상하나 눈으로 확인하지 않았다.

### B. 골든 비교·키오스크 웹 재빌드 (S)
- 두 앱 `screenshot_test.dart`가 `C:\flutter\flutter\bin\cache\...materialicons-regular.otf` 경로를 고정해 노트북에서 실패했다. 데스크톱에서 `--tags screenshot`으로 비교하고 필요하면 골든 갱신.
- `kiosk-web/`(untracked)은 9/27 빌드다. `rpi5-touchscreen-app`에서 `flutter build web --base-href /kiosk/ --output <저장소>/kiosk-web` 후 `/kiosk/`에서 시나리오 카드·확인 수준 문구 확인.

### C. 시연 v2 §3 모의 리허설 완주 (S)
`SIMPLELAY_THINQ_MODE=mock python -m rpi.simulator_main --port 8765`로 §3 절차를 화면(키오스크 웹·트윈·폰)까지 붙여 한 번 완주. 노트북은 HTTP 응답만 확인했다.

### D. 하드웨어 도착 시 (H0~H1)
[jog-cli devlog](devlog_2026-09-29-jog-cli.md) "하드웨어 도착 첫날 순서" 6단계. `SIMPLELAY_MOTION_MODE=serial`, `SIMPLELAY_MOTION_*` 기구 값은 팀원 실측값으로만 채운다. 모션 MCU 펌웨어는 아래 G.

### E. ThinQ 실물 (PAT·가전 확보 시)
`SIMPLELAY_THINQ_MODE=real`, `SIMPLELAY_THINQ_PAT`, `SIMPLELAY_THINQ_COUNTRY`, 기기 ID 환경 변수. `RealThinqClient`는 NotImplementedError 자리표시자다 — pythinqconnect 1.0.14 기준으로 구현하고, 기기 프로필을 덤프해 `rpi/services/thinq/bindings.py`의 속성 이름(현재 추측)을 확정한다. PAT는 로그·이력·저장소 어디에도 남기지 않는다(테스트 있음).

### F. 문서 정리 (S)
`CLAUDE.md` 상단 배너가 날짜별로 12줄 이상 쌓였다. 하나의 "현재 기준" 절로 합치고, `개발현황.md`를 9/29 기준으로 갱신. 문서 간 모순(Z축 방식, 제어기, RPi5↔RPi4 연결 서술)은 현재 설계(FIT0482 ×3, JMOD-MOTOR-1 ×2, 노드 경유)로 정리.

## 3. 운영 주의

- **API 키**: 616cf18부터 키가 없으면 LAN 요청은 401이다. 실기기 배포 시 `SIMPLELAY_API_KEY`를 설정하거나, 개발 중에만 `SIMPLELAY_ALLOW_UNAUTHENTICATED=1`.
- **ThinQ 기본 off**: `SIMPLELAY_THINQ_MODE` 미설정이면 시나리오 카드가 조용히 생기지 않는다.
- **L3 real 거절**: 실물 전력 센서 드라이버가 없어 `SIMPLELAY_L3_MODE=real`은 기동을 거절한다. 드라이버 작성 전까지 `mock`만.
- **펌웨어**: 게이트웨이 겸용 env 플래시 91.5%. `firmware-node/secrets.ini`(untracked)에 Wi-Fi·게이트웨이 MAC.
- **Windows**: pytest는 `--basetemp <ASCII 경로>` 필요. PlatformIO 코어 폴더는 `C:\.platformio`, 빌드 폴더 `C:\pio-build`.
