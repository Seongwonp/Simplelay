## 작업 기록과 보관

- [devlog/](devlog/) — 날짜별 작업 기록 `devlog_YYYY-MM-DD*.md`. 무엇을 바꿨고 무엇을 어떤 수준으로 확인했는지(수정 전 실패 확인·시험 수·실물 여부)가 여기 있다. 최신 인계는 [인계 2026-10-13 데스크톱](인계-2026-10-13-데스크톱.md).
- [archive/](archive/) — 지난 인계, 폐기된 시연 시나리오(v1~v3), 이미 반영한 옛 평가·계획, 개편 전 캡처. 2026-10-13 정리 때 삭제하지 않고 `git mv`로 옮겼다(이력은 `git log --follow`). 현행 기준으로 읽지 않는다.
