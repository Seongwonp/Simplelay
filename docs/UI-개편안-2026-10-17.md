# UI 개편안 — 쉬운 말과 화면 구조 (2026-10-17)

지도교수 의견: "UI 구조가 별로고 AI가 만든 느낌이 난다. 말투가 엔지니어 설명 같다 — 전문용어를 모르는 사람은 어떻게 하나."
폰 문구·키오스크/서버 문구·화면 구조를 따로 감사한 결과를 한 장으로 묶었다(감사 원문은 저장소 밖 작업 기록).
기준 문서: [UI 제품 앱·공개 레퍼런스](ui-product-app-references.md), [UI 참고 자료와 적용 기준](UI-참고자료와-적용기준.md), [결선 전 SW 보완 피드백](결선전-SW-보완-피드백.md).

## 1. 왜 그렇게 보이나 (감사 요약)

**말투**
- 한 물건을 여러 이름으로 부른다. 본체 = 허브·서버·키오스크·SimpleLay 본체·기기, 누름 장치 = 작은 팔·작은 팔 장치·누름 장치·모션 보드·모터 보드·구동 장치·노드, 쉬기 = 방해 금지·제안 잠시 쉬기·조용한 시간.
  앱이 스스로 "키오스크에서는 'SimpleLay 본체'라고 불러요"라고 해명하는 것이 그 증거다.
- 문장이 **결과가 아니라 판정 근거**를 설명한다 — 전력, 상태 재조회, 접수, 변경 명령, 모션 보드 응답, mA·dB·ms.
- 방어 문장을 겹친다 — "~않아요. ~않아요. ~않아요.", '—'·'·'·괄호로 이어 붙인 문장(폰만 대시 36개·가운뎃점 약 50개), 같은 경고("다시 시도하지 마세요")가 한 화면에 2~3번.
- 평가 지적을 **문장을 더해서** 고쳐 왔다 — 화면이 읽는 문서가 됐다(조용한 시간 설명 6줄, 공기 줄 '종합은 가전이 매긴 등급').

**구조·디자인**
- 모든 화면이 '제목 + 회색 설명 + 테두리 버튼' 한 가지 문법이다. 그림·숫자·배지 대신 문장이 정보를 나른다.
- 스마트홈의 중심인 **가전 상태가 화면 맨 위에 없다**(공기청정기 카드에 켜짐/꺼짐도 공기질도 없다).
- 같은 모양 버튼이 반복된다(홈 '실행하기' 4개, 루틴 '편집/실행하기' 6쌍, 행마다 '지우기').
- 토큰은 있는데 코드가 따르지 않는다 — 폰 글자 크기 15종(11~34), 간격 14종. 아이콘은 Material 기본 혼용(루틴 개념에 아이콘 3개).
- 키오스크 제안·실행·결과의 배치가 모두 다르다. 이 제품만의 그림인 '실제 가전 버튼판'이 실행 중 화면에만 나온다.

## 2. 말투 규칙

1. **한 화면 = 결과 한 줄 + 할 일 한 줄.** 근거·원리 설명은 '자세히'로 접는다.
2. **사람이 주어, 가전이 주어.** 시스템 내부(본체가 보냈다, 상태를 다시 읽었다)를 말하지 않는다.
3. **세 가지 결과 말로 끝낸다:** 됐어요 · 몰라요(봐 주세요) · 못 했어요. 확인 못 한 것을 됐다고 하지 않는다(안전 계약 유지).
4. '—', 괄호, 가운뎃점으로 문장을 잇지 않는다. 두 문장이면 마침표.
5. 같은 경고는 화면에 한 번. "~않아요"를 두 번 넘게 잇지 않는다.
6. 숫자·단위(mA, dB, ms, %, IP, 포트, HTTP 코드, 예외 원문)는 일반 화면에 내지 않는다.
7. 해요체, 짧게. 한 줄에 들어가면 한 줄.

## 4. 화면 구조 개편안

**공통**
- 화면당 주 버튼 하나(채움), 보조는 테두리, 취소는 글자. '지우기'는 행 버튼에서 빼서 ⋮ 메뉴나 상세로.
- 상태 배지 한 모양(아이콘 + 짧은 말 + 색): 보냄 · 받음 · 됐어요(확인) · 몰라요 · 멈춤 · 자동 켜짐/꺼짐/다시 허락 필요. 폰 기록·루틴·키오스크 결과가 같은 말.
- 정지는 늘 같은 자리(폰 실행 바 오른쪽, 키오스크 오른쪽 아래), 승인 없이 물리 버튼을 누르지 않음, 확인 수준을 높여 보이지 않음 — 그대로.

**폰**
- 탭 4개(홈·루틴·기록·설정). 개발자는 설정 맨 아래(개발 모드일 때만).
- 홈: ① 지금 할 일(제안 있을 때) → ② 확인이 필요해요(있을 때만, 설정 필요 가전·결과 확인) → ③ 오늘 예정(22:00 저녁 공기청정기 켜기 · 자동) → ④ 가전(카드에 상태 한 줄: LG 가전은 읽은 값일 때만 '꺼짐', 버튼식은 '작은 팔 준비됨/자리 맞추기 필요') → ⑤ 자주 쓰는 루틴 타일.
- 루틴: 세그먼트 [내 루틴 | 자동으로 하기]. 행당 버튼 하나, 편집·지우기는 ⋮. 자동 실행 카드는 언제·무엇을·최근 결과 + 스위치(켤 때는 지금처럼 확인 시트). 예시 루틴은 [+ 새 루틴] 안으로.
- 기록: 행 2줄 — 왼쪽 아이콘 = 누가(직접·루틴·자동·음성), 오른쪽 배지 = 결과. 긴 결과 문장은 상세로.
- 설정: 행 = 이름 + 오른쪽에 지금 값(조용한 시간 · 22:00~07:00 · 꺼짐). 설명은 상세 첫 줄로. IP·키·블루투스는 '설치하는 분용'으로 접기.

**키오스크**
- 대기: 시계 → 다음 할 일 → 집 공기·가전 상태 → 날씨. 위쪽 아이콘 5개 대신 상태 칩 하나('모두 정상' / 문제 있을 때만 '작은 팔 연결 끊김')와 메뉴. 가전은 큰 사각 타일(상태 줄 포함).
- 제안·실행·결과: **같은 가전 버튼판 그림을 같은 자리(오른쪽)** 에 — 누를 곳 → 누르는 곳 → 누른 곳. 글은 세 단계(제목·한 줄 이유·다음 할 일).
- 결과: 띠는 확인 수준, 제목은 본 사실(같은 말 두 번 금지). 확인 필요·실패 화면의 주 버튼은 골드가 아닌 중립색.

## 5. 디자인 기준 (초안)

- 폰 글자 5단계: 32 숫자 · 24 탭 제목 · 20 카드 제목 · 18 본문 · 16 보조(16 미만 금지). 간격 4의 배수(4·8·12·16·20·24·32).
- 키오스크(캔버스): 40 · 30 · 21 · 17 + 시계. 간격 8·12·20·28·36.
- 색: 강조 하나(주 행동에만) + 상태 셋(진행·됐어요·봐 주세요) + 정지 빨강. 초록 '됐어요'는 실제 확인일 때만, 폰·키오스크 같게.
- 아이콘: 한 세트(선형), 개념당 하나. 가전 그림을 홈·제안·키오스크 타일에 공통으로.
