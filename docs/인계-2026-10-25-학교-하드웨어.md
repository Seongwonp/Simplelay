## 10/25 낮 추가 — 확인할 것·바로 할 일

- **소리:** 화면 선을 뺐다 꽂은 뒤 RPi5 HDMI 소리 장치가 사라졌다(재생이 'Failed to drain stream: Timeout', 출력 장치가 `auto_null`). 데스크톱에서 재부팅으로 복구를 시도한 채 나갔다 —
  학교에서 켠 뒤 키오스크 제안(`POST /demo/suggest`)으로 딩동·음성이 나오는지 먼저 본다. 안 나오면 RPi5 `pactl list sinks short`에 hdmi 장치가 있는지 보고, 없으면 화면 선을 꽂은 채 재부팅.
  음성은 본체가 Supertonic(여자 1번 F1, 사용자 확정)으로 만들어 보드 소리 서버로 직접 튼다(`POST /tts/play`, 모델은 RPi5 데이터 폴더 `tts-models`).
- **용어·스위치 통일(사용자 승인, 이 노트북에서 진행):**
  1. 용어는 **루틴**(버튼 순서를 저장한 것)과 **자동 실행**(루틴이 정한 시각에 혼자 도는 것) 둘만. '저장된 동작'·'자동 루틴'·'자동으로 하기'를 없앤다.
     키오스크 가전 화면 '저장된 동작 N개' → '루틴 N개', 자동 실행 탭 배지 '자동 루틴' → 시각만('매일 오후 10:00'), 폰도 같은 말.
  2. 자동 실행 스위치는 루틴마다 **'자동 실행' 하나** + 아래 한 줄로 실제 동작("매일 오후 10시에 묻지 않고 공기청정기를 켜요" / 꺼짐 "시간이 돼도 하지 않아요").
     '실행 허용'과 '루틴 켜기'를 따로 두지 않는다(켰는데 안 도는 상태가 생긴다). 세부(묻고 실행)는 상세 화면으로.
  3. 폰 정지 줄: "다른 곳에서 시작한 동작 진행 중 · [정지]"(서버가 출처를 주면 "키오스크에서 시작한 동작 진행 중").
  4. 인덕션 안내 서버 문장 `GANTRY_ABSENT_REASON` → "누름 장치가 이 가전에 달려 있지 않아요" — 폰 `kGantryAbsentReason`이 글자 그대로 비교하므로 **서버·폰 같은 커밋**.
  - 순서: 촬영 먼저, 끝나고 적용. 시험·골든 갱신, 실패 확인 게이트는 평소대로.

## 오늘 할 일(순서)

1. **HW 담당에게 실제 업로드한 펌웨어 묶음 받기.** CLAUDE.md 규칙대로 ESP32 코드는 수정·재업로드하지 않는다. 받은 파일은 저장소 밖 인계 폴더에 두고, `rpi/controller/touchbridge_motion.py`가 대조한 줄 모양(JSON v2 `home·move_only·press·stop·status`, 상태 `RECEIVED/MOVING/POSITIONED/PRESSING/COMPLETED/STOPPED/ERROR_*`)과 달라진 곳이 있는지 먼저 본다. 다르면 어댑터를 맞추고 `rpi/tests/test_touchbridge_*.py`·시뮬레이터(`rpi/tools/touchbridge_sim.py`)도 같이 맞춘다.
2. **핫스팟 주소 맞추기.** 두 보드가 핫스팟에 붙으면 RPi5 env `SIMPLELAY_UART_PORT=socket://<RPi4 주소>:7000`, RPi4 env `SIMPLELAY_LINK_ALLOW_FROM=<RPi5 주소>` (바꾸기 전 `env.bak-날짜-이유` 백업). RPi4 재부팅 뒤 `systemctl start docker`.
3. **RPi4 모션 설정(실물):**
   ```
   SIMPLELAY_MOTION_MODE=serial
   SIMPLELAY_MOTION_PROTOCOL=touchbridge-v2
   SIMPLELAY_MOTION_PORT=/dev/serial/by-id/<보드를 꽂은 뒤 확인>
   SIMPLELAY_MOTION_BAUD=115200
   ```
   `SIMPLELAY_MOTION_SIMULATED`는 넣지 않는다(넣으면 결과가 연습으로 기록된다). `sh /mnt/rawdata/run_act.sh` 후 로그에 `motion MCU on … homed=` 확인.
4. **원점·버튼 좌표.** 개발자 모드(폰)로 원점 → 이동(한 번 5 mm 상한) → 전자레인지 '30초'·'시작'·'취소'(정지 버튼) 위치를 mm로 찾는다. 저장은 폰의 사진 매핑 또는 `PUT /appliances/microwave/mapping`(10/24에 쓴 방식: 가상 사진 1000×1000 모서리 + 프레임 mm + `buttons_px`, `stop_button`). 정식 보정이 아니면 개발자 직접 누름은 '보정이 끝나지 않은 가전'으로 거절된다 — 일반 실행(승인)으로 누른다.
5. **영상 전 실물 확인:** 실행 → 스위치봇 누름 → 결과(완료/눌렸는지 모름) · 실행 중 정지 → 다시 실행(10/24에 '정지 뒤 실행 거절' 결함을 고쳤다, 실물 첫 확인) · 정지 버튼 위 대기.
6. **끝나면:** 작업 기록, 보드 `sync; poweroff`.
