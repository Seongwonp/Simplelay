# 재사용 경계 (Reuse Boundary)

> 목적: SimpleLay가 어디까지 기존 자산(Touch Bridge)을 재사용하고, 어디부터 본 대회를 위한
> 신규 구현인지를 **처음부터 명확히 기록**한다.
> 이 문서는 임베디드SW경진대회 개발완료보고서의 "기존 자산 vs 신규 구현" 구분 근거가 된다.

---

## 왜 이 문서가 필요한가

임베디드SW경진대회를 포함한 다수 공모전은 **다른 대회에서 이미 진행·수상한 유사 프로젝트의
재사용을 감점 또는 평가 제외** 대상으로 본다. Touch Bridge는 ICT 한이음 드림업 프로젝트이므로,
SimpleLay가 그 하드웨어를 공유한다면 **"무엇이 재사용이고 무엇이 신규인지"를 스스로 투명하게
구분**해 두는 것이 정당성을 지키는 방법이다.

핵심 입장 (갱신):

> **XY 갠트리 자체도 Touch Bridge의 피니언/렉 레일 구조를 버리고 CoreXY 방식으로 새로
> 설계·제작했다 — 자세한 사유와 구조는 [docs/actuator-design.md](actuator-design.md) 참고.
> (2026-10-07 보충) Touch Bridge 쪽도 같은 시기에 자체적으로 CoreXY 재설계를 진행했다. 방식 이름은
> 같지만 기구·모션 구현 범위에서는 독립적으로 작업했다. 앱·통신 등 기존 자산 일부는 재사용했다. SimpleLay의 CoreXY 갠트리 설계와
> 운동학(`rpi/controller/kinematics.py`)·모션 펌웨어(`firmware-motion/`)는 이 저장소에서 새로 만들었다.
> 독립성 주장은 기구·모션 구현 범위에 한정한다. 원 프로젝트와 대조하지 않았으므로 재사용 비율은
> 확정하지 않는다. 승인·검증·제안 로직은 본 대회를 위해 새로 구현했다.**

## 경계 표

| 구성요소 | 재사용 / 신규 | 출처 | 비고 |
| --- | --- | --- | --- |
| **CoreXY 갠트리 (기구부)** | **★ 신규** | SimpleLay | 피니언/렉 레일 구조를 버리고 새로 설계·제작. Touch Bridge도 같은 시기 별도로 CoreXY를 재설계했으나 기구·모션 구현 범위에서 독립적으로 작업함. 사유·구조는 actuator-design.md |
| **모션 제어 펌웨어** | **★ 신규** | SimpleLay | 모션 MCU 미정(Arduino 또는 ESP32), 팀원 코드 수령 후 확정. 저장소 구현·컴파일까지, 실물 미검증 |
| **Z축 버튼 누름** | **방식 미정** | SimpleLay | 스위치봇 분해 모듈 또는 솔레노이드 후보. 팀원 확인·실측 후 확정 |
| ESP32 브릿지 (BLE ↔ Wi-Fi) | **재사용(확장)** | Touch Bridge | 통신 골격은 이어받았으나, 모션 명령 중계가 아니라 폰↔RPi5 브릿지 전용으로 역할 축소·재정의됨 — 실제 어느 정도가 원 코드 그대로인지는 확인 필요 |
| Flutter 앱 골격 | **재사용(확장)** | Touch Bridge | SimpleLay 상태/검증 UI는 신규 |
| 의도 해석 LLM 연동 | **재사용(확장)** | Touch Bridge (`prompts.py`) | 원래 특정 모델(Gemini) 직접 연동이었으나, 현재는 특정 벤더에 묶이지 않는 OpenAI 호환 엔드포인트 방식으로 재구현 — 패턴 학습 연계는 신규 |
| **라즈베리파이 검증 모듈 (verifier)** | **★ 신규** | SimpleLay | 전류·음향 센서 → 실행 검증 |
| **폐루프 컨트롤러 (controller)** | **★ 신규** | SimpleLay | 명령 → 검증 → 실패 시 재시도 |
| **사용 로그·시간대 패턴 감지 (intent)** | **★ 신규** | SimpleLay | 설정형 임계값·시간대, 주입식 시계 |
| **선제 제안·1회 승인 게이트 (intent)** | **★ 신규** | SimpleLay | 승인 전 실행 금지, 승인 후 기존 폐루프 연계 |
| **전류·음향 센서 하드웨어** | **★ 신규** | SimpleLay | 검증용 센서 추가 |
| **RPi4 ↔ 액추에이터 폐루프 연동** | **★ 신규** | SimpleLay | 결과 피드백 기반 재시도 (GRBL 아님 — 현재 기준: XY FIT0482 ×2, 모션 MCU·Z 방식 미정; 옛 "Arduino/BLE 버튼 장치" 서술 폐기) |
| **가전 등록·버튼맵 에디터 (app)** | **★ 신규** | SimpleLay | 사용자가 앱에서 새 가전을 직접 등록·조작 |

## 한 문장 설명 (심사·발표용)

> "SimpleLay는 앱·통신 등의 기존 자산 일부를 재사용했고, 승인·검증·제안 로직은 새로 구현했습니다.
> 기구·모션 구현은 독립적으로 진행했습니다. 누름 장치 전류로 L1 반응을 판정하고 대상 CT로 L3 동작
> 시작을 확인하는 구조이며, 실제 센서 통합·성능은 아직 미검증입니다."

---

## 갱신 규칙

- 새 기능을 구현할 때마다 이 표에 **재사용/신규를 즉시 기록**한다.
- 재사용 자산을 SimpleLay에 맞게 수정한 경우, "재사용(확장)"으로 표기하고 무엇을 바꿨는지 남긴다.
- 개발완료보고서 작성 시 이 표를 그대로 근거 자료로 사용한다.
