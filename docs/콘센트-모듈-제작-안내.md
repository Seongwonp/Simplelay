전자레인지가 실제로 전기를 쓰기 시작했는지·멈췄는지를 CT(전류 센서)로 재고, 비상정지 버튼으로 전자레인지 전원을 끊는 상자를 만드는 순서다.
**10/19 사용자 결정:** 10/28 제출 영상·서류는 이 모듈 없이 간다. **10/28~11/6 사이에 완성해 결선에서 가열 시작·종료 감지를 실물로 보이는 것이 목표**이고, 못 하면 결선에서 '설계·펌웨어 완료, 실측 전'이라고 말하고 그 장면은 연습으로 보인다([시연 v4 §0-A](본선-시연-계획-v4.md)).

- 펌웨어: [firmware-outlet/README.md](../firmware-outlet/README.md) — 컴파일까지만 확인, 보드에 올린 적 없음. 핀·보정값은 [`include/config.h`](../firmware-outlet/include/config.h)에 있고 **전부 자리표시자**다.

- 다 만든 뒤 시험 순서는 [하드웨어 복귀 날 절차](하드웨어-복귀-날-절차.md) §9, 기록은 [실측 기록표](실측-기록표.md) §6, 가격은 [활용성 숫자 기록지](submission/활용성-숫자-기록지.md) §1.

## 0. 안전 — 먼저 읽기

- **220 V 배선은 전기 작업 경험이 있는 분이 전원을 넣기 전에 확인한다.** 확인 전에는 벽 콘센트에 꽂지 않는다.
- **전자레인지 전원선은 절대 자르거나 벗기지 않는다.** 자르는 것은 새로 산 싼 1구 연장선뿐이다. 전자레인지 플러그는 그대로 상자 콘센트에 꽂는다.
- 상자 안을 만질 때는 **벽 플러그를 뽑는다.** 릴레이가 꺼져 있어도 상자 안에는 220 V가 있다(퓨즈·릴레이 앞, 5 V 전원 모듈).
- 한국 콘센트는 방향이 없어서 플러그를 돌려 꽂으면 L과 N이 바뀐다. 한 가닥만 끊는 릴레이·퓨즈는 경우에 따라 N 쪽에 걸린다 — 그래서 위 규칙(만질 때는 뽑는다)이 필요하고, 가능하면 **2극 릴레이·2극 비상정지로 두 가닥을 함께 끊는다**(권장).
- 220 V 쪽과 저전압 쪽(ESP32·ADS1115·CT 신호선)은 상자 안에서 **물리적으로 떼어** 배치한다(칸막이 또는 최소 수 cm 거리, 선끼리 묶지 않는다).
- 첫 전원은 **전등**으로 시험한다(§5). 전자레인지는 맨 마지막, 사람 입회, [런북](결선-운영-런북.md) §3-7 가열 안전 체크리스트를 통과한 뒤에만.

## 1. 구조

```
벽 콘센트
  └─ 플러그 코드: 새로 산 1구 접지형 연장선의 플러그 쪽 반토막 (전자레인지 선은 자르지 않는다)
       └─ 닫힌 상자(절연 케이스, 케이블 글랜드로 선 고정)
            ├─ 퓨즈 → (비상정지 전원 접점, 선택) → 릴레이 → CT(한 가닥만 통과) → 상자 콘센트
            ├─ 절연형 220 V → 5 V 모듈 (릴레이 코일 전원)
            └─ 저전압 칸: ESP32 + ADS1115 + 단자대, USB로 RPi4
                 └─ 상자 콘센트 ← 전자레인지 플러그 (그대로)
```

- **CT에는 한 가닥만 통과시킨다.** 두 가닥(L·N)을 함께 감싸면 전류가 서로 지워져 0에 가깝게 읽힌다. 상자 안에서 L 선만 따로 떼어 CT 고리에 넣는다(어느 한 가닥이면 측정값은 같다).
- **접지(PE)는 끊김 없이** 플러그 → 단자대 → 상자 콘센트 접지 단자로 잇는다. 릴레이·퓨즈·CT를 거치지 않는다. 금속 상자면 상자도 접지에 묶는다.
- 펌웨어는 CT 2채널(ch0 전자레인지·ch1 세탁기)을 받지만 **결선 시연은 ch0만 쓴다.** 하나만 만들면 `firebeetle32_1ct` 빌드로 올린다(§4).

## 2. 배선도 (글 그림)

```
               ┌──────────────────────── 닫힌 상자 ─────────────────────────────────┐
 벽 플러그 ─L──┼─[퓨즈]─┬─[비상정지 NC 전원 접점(선택)]─[릴레이 COM → NO]─(CT 고리)─┼─L─┐
 (연장선    N──┼──[단자대]─┼────────────────────────────────────────────────────────┼─N─┤ 상자 콘센트
  반토막)   PE─┼──[단자대]─┼────────────────────────────────────────────────────────┼─PE┘   ▲
               │          │                                                         │   전자레인지
               │     퓨즈 뒤 L·N                                                    │   플러그(그대로)
               │          └─[절연형 AC-DC 5 V]─ +5V/GND ─▶ 릴레이 모듈 VCC/GND        │
               │ ═══════════════ 여기부터 저전압 칸 (220 V 선과 떼어 둔다) ═══════════ │
               │  CT 출력(3.5 mm 잭) ─ 두 선 ─▶ ADS1115 AIN0 / AIN1                 │
               │                                AIN1 ← 1.65 V 바이어스(분압 + 커패시터)│
               │  ADS1115 VDD ← ESP32 3.3V · GND ─ GND · SDA ─ GPIO21 · SCL ─ GPIO22  │
               │          ADDR ─ GND (주소 0x48)                                      │
               │  릴레이 모듈 IN ◀─ GPIO26        (GND는 모듈 형식에 맞춰 — §3 릴레이) │
               │  비상정지 NC 신호 접점: 한쪽 ─ GPIO27, 다른 쪽 ─ GND                  │
               │  ESP32 USB ════════════════════════════════════════════▶ RPi4 USB   │
               └─────────────────────────────────────────────────────────────────────┘
 비상정지 버튼(머리 큰 래치형)은 상자 뚜껑 바깥, 손이 바로 닿는 자리에.
```

- 퓨즈는 플러그에서 들어온 **바로 다음**에 둔다(5 V 모듈도 퓨즈 뒤에서 전원을 받는다).
- 5 V 모듈은 릴레이 **앞**에서 받는다 — 릴레이가 열려도 ESP32·릴레이 코일 쪽 전원이 꺼지지 않게.
- 두 번째 CT(세탁기, ch1)를 달면 ADS1115 AIN2 / AIN3(+ AIN3 바이어스)에 같은 방식으로. 세탁기 플러그는 **릴레이를 거치지 않는다**(펌웨어 결정 10/6 — 모터 기동 전류).

## 3. 부품별 요구 사항과 펌웨어 대응

| 부품 | 요구 사항 | 펌웨어가 가정한 것(`config.h`) | 확인할 것 |
|---|---|---|---|
| 플러그 코드 | 새 1구 **접지형** 연장선을 잘라 플러그 쪽만 쓴다. 정격 250 V 16 A 표기 권장 | — | 정격 표기, 선 굵기(1.5 mm² 권장, 최소 1.0 mm²) |
| 상자 콘센트 | 상자에 고정하는 접지형 콘센트(연장선의 콘센트 쪽 반토막을 글랜드로 빼서 써도 된다) | — | 정격 250 V 16 A |
| 퓨즈 | L선(가능하면 두 가닥)에 퓨즈 홀더 + 퓨즈. 전자레인지 소비 전류보다 크게, 돌입 전류를 견디는 지연형 | — | 전자레인지 명판의 소비 전력·전류 → 퓨즈 정격 결정. **측정 필요** |
| 릴레이 | 접점 **250 VAC 10 A 이상(16 A 권장)**, NO 접점 사용. 가능하면 2극 | `PIN_RELAY 26`, `RELAY_ACTIVE_LEVEL HIGH`, NO 접점, 부팅 기본 꺼짐 | 모듈이 **활성 LOW(광커플러형이 흔함)** 면 `RELAY_ACTIVE_LEVEL`을 바꾼다. 재부팅 중 GPIO가 떠 있어도(High-Z) 릴레이가 **열린 채**인지 — 활성 HIGH면 IN에 외부 풀다운, 활성 LOW면 모듈 풀업. 코일 전압(5 V) |
| 비상정지 버튼 | **누르면 걸려 있는(래치) 머리 큰 버튼**, 돌리거나 당겨야 풀림. 신호용 **NC** 접점 필수. 전원 접점(250 VAC 10 A 이상 NC)이 하나 더 있으면 릴레이와 직렬로 넣어 ESP32와 무관하게 끊는다(권장) | `PIN_ESTOP 27`, NC 접점 → GND, 내부 풀업, 눌림 **또는 단선** = HIGH = 정지 | NO 접점을 쓰면 선이 빠져도 '정지 안 됨'으로 숨는다 — **NC만**. 펌웨어는 버튼이 풀려도 사람이 화면에서 확인하기 전에는 릴레이를 다시 켜지 않는다(래치가 재부팅을 넘어 남음) |
| 5 V 전원 | **절연형** 220 V → 5 V AC-DC 모듈(릴레이 코일 전류보다 여유 있게) | — | 아래 '전원 주의' |
| ESP32 | 콘센트 모듈 전용 보드(모션 보드와 따로) | 보드 `firebeetle32`, USB 시리얼 115200 → RPi4 | 실제 보드 이름이 다르면 `platformio.ini` 확인 |
| CT | **전압 출력형** 분할형 CT 권장(예: 30 A → 1 V). 전류 출력형이면 부담 저항이 반드시 필요 | SCT-013-030(전압 출력형, 30 A → 1 V rms), `CT_AMPS_PER_VOLT_CH 30` | 실제 모델명. 전류 출력형(예: 100 A : 50 mA)이면 부담 저항 값을 정하고 `CT_AMPS_PER_VOLT_CH`를 다시 계산. **부담 저항 없이 전류 출력형 CT의 출력선을 열어 두지 않는다**(고전압이 걸린다) |
| ADC | ADS1115 모듈(I2C) — 기본 빌드 | SDA 21 · SCL 22, 주소 0x48(ADDR → GND), ch0 = AIN0-AIN1 차동, ±2.048 V | 모듈 VDD를 3.3 V로(ESP32 핀 전압과 맞춤) |
| 바이어스 | AIN1(ch1이면 AIN3)을 VDD/2(약 1.65 V)에 묶는 분압 저항 2개 + 커패시터 | "VDD/2 바이어스(분압 + 커패시터)" — 값은 정하지 않음 | 저항·커패시터 값. 흔한 예시는 같은 값 저항 둘(수십 kΩ)과 10 µF 정도 — **추측, 확인 필요** |
| ADC 대안 | ADS1115 없이 ESP32 내장 ADC(잡음 큼, 시험용) | `firebeetle32_adc` 빌드: CT0 → GPIO36, CT1 → GPIO39, 다른 선 → 1.65 V 바이어스 | 쓸지 여부 |
| 단자대 | L·N·PE 분기용, 220 V 정격 | — | 나사 조임 뒤 선을 당겨 본다 |
| 전압 센서(선택) | 절연형 AC 전압 센서 모듈 | **지금 펌웨어는 전압을 읽지 않는다**(220 V로 가정 — `MAINS_VRMS_EST`) | 달면 펌웨어 수정이 필요하다 — 결선 전에는 넣지 않아도 된다 |

**전원 주의.** ESP32는 RPi4와 USB로 이어지고 그 USB에서 전원도 받는다. 5 V 모듈 출력을 ESP32의 5 V 핀에 **동시에** 넣으면 두 전원이 부딪칠 수 있다(보드의 전원 다이오드 여부 확인 전).
처음에는 **ESP32 = USB 전원, 5 V 모듈 = 릴레이 코일 전원만**으로 시작한다. 릴레이 모듈이 광커플러형이면 입력 쪽(IN·VCC)은 ESP32 3.3 V·GND, 코일 쪽(JD-VCC)은 5 V 모듈로 나눈다. 광커플러가 없는 모듈이면 5 V 모듈 GND와 ESP32 GND를 묶어야 IN 신호가 먹는다.
5 V 모듈은 반드시 **절연형**이어야 한다 — ESP32 GND가 USB를 거쳐 RPi4에 이어지므로, 비절연 전원이면 220 V가 RPi4까지 온다.

## 4. 펌웨어 맞추기 (만든 뒤, 올리기 전)

1. 위 표의 '확인할 것'을 채워 `firmware-outlet/include/config.h`의 자리표시자를 실제 값으로 바꾼다 — 핀, 릴레이 극성, CT 모델(`CT_AMPS_PER_VOLT_CH`), 채널 수. 보정값(`CT_CAL_GAIN_CH`·`CT_NOISE_FLOOR_A_CH`·`POWER_FACTOR_EST_CH`·`MAINS_VRMS_EST`)은 §5 측정 뒤에 채운다. 다 채우기 전에는 `OUTLET_CONFIG_PLACEHOLDER`를 0으로 바꾸지 않는다.
2. CT 하나면 `pio run -d firmware-outlet -e firebeetle32_1ct`, 둘이면 기본 env. 빌드·업로드 방법은 [펌웨어 README](../firmware-outlet/README.md) '빌드'.
3. RPi4 env(바꾸기 전에 `env.bak-날짜-이유`로 백업): `SIMPLELAY_OUTLET_PORT`(by-id 경로), `SIMPLELAY_OUTLET_CHANNELS`(CT 하나면 `microwave:0`), `SIMPLELAY_L3_MODE=real` — 모듈이 연결돼 있지 않으면 실행기가 시작을 거절한다. 규약은 [protocol.md](protocol.md) '콘센트 모듈 링크'.

## 5. 시험 순서 — 전등부터

각 단계에서 이상하면 멈추고 기록한다. 원본 로그는 저장소 밖에 두고 파일 이름만 적는다.

| # | 무엇 | 부하 | 통과 조건 |
|---|---|---|---|
| 0 | 220 V 배선 확인 | 플러그 뽑은 채 | 경험 있는 분이 배선·퓨즈·접지 연속(테스터 도통)·절연을 확인 |
| 1 | 저전압만 | 벽 플러그 뽑고 USB만 | `ready` 배너, `status` 응답, `cal: placeholder`. 버튼 누름 → `estop` 이벤트, 버튼 선을 빼도 정지로 읽힘 |
| 2 | 릴레이 | **전등**(백열등 또는 LED 스탠드) | `relay_on` → 켜짐, `relay_off` → 꺼짐. ESP32를 리셋하는 동안 전등이 **켜지지 않는다** |
| 3 | 비상정지 | 전등 | 버튼 → 즉시 꺼짐, 버튼을 풀어도 꺼진 채(`relay_on`은 `estop_latched`), `estop_reset` 뒤에만 다시 켤 수 있음. 전원 접점을 넣었다면 ESP32 USB를 뺀 상태에서도 버튼으로 꺼짐 |
| 4 | CT가 읽는지 | 전등 켜고 끄기 | `power` 이벤트 값이 켜면 오르고 끄면 내려간다. 0 근처에서 안 움직이면 CT가 두 가닥을 감싸지 않았는지·방향·바이어스를 본다 |
| 5 | 무부하 잡음 | 아무것도 안 꽂음, 몇 분 | 잡음 값을 기록 → `CT_NOISE_FLOOR_A_CH` |
| 6 | 보정 | 정격을 아는 저항 부하(전기 포트 등) + 클램프 미터 | 미터 값 대비 비율 → `CT_CAL_GAIN_CH` |
| 7 | 전자레인지 | 런북 §3-7 통과 뒤, 물 컵, 30초, 사람 입회 | [하드웨어 복귀 날 절차](하드웨어-복귀-날-절차.md) §9와 [실측 기록표](실측-기록표.md) §6 A·B·C1·C2·D |

|---|---|
| 무부하 잡음(A rms) | 측정 필요 |
| 기준 부하 미터 값 / 모듈 값 | 측정 필요 |
| 버튼 → 릴레이 차단 지연 | 측정 필요 |
