## 3. 다음에 할 일

### 데스크톱 (Flutter)
1. **폰 앱 개편:** UI 확정 §2대로 4탭 구조, 개발자 탭 조건부 표시, 가전 카드·상세(사진 패널)·루틴 녹화·루틴 편집·가전 추가 5단계.
   - 서버 API는 모두 준비돼 있다: `/routines*`, `/appliances/{id}/mapping`, `/verify-pass`, `/hub/location`.
   - 설정 → 허브에 "현재 위치로 설정"을 넣는다(폰 위치 권한 → `PUT /hub/location`).
   - 앱 설정 정보 화면에 날씨 출처를 표시한다("기상청 단기예보 조회서비스(공공데이터포털)", 이용허락 제1유형).
2. **키오스크 개편:** UI 확정 §3.
   - 평소 화면은 `/ambient`, `/connections`를 쓴다. 연결 문제는 "!" 배지를 누르면 모달로 연다.
   - 가전 줄은 4개씩 넘기고, 동작 중인 가전을 앞으로 올린다.
   - 동작 중 화면은 `hold_state`를 보여 준다.
3. 골든 이미지 갱신, 키오스크 웹 재빌드.

### 하드웨어 도착·통신
4. RPi5·RPi4 같은 LAN 통신 확인. RPi4에서 `socat`으로 TCP를 가상 시리얼로 바꾸고, RPi5는 `SIMPLELAY_UART_PORT=socket://<RPi4>:7000`으로 붙인다. `/twin`으로 확인한다. 이때 이 플랫폼 위에서 RPi4가 시리얼 포트와 마이크를 직접 열 수 있는지도 확인한다.
5. **Arduino 모션 펌웨어:** `firmware-motion/`(ESP32용)의 규약을 AVR 단일 루프로 옮긴다. 규약 표는 `firmware-motion/protocol_table.json`이다. Z는 시간 기반 누름이다.
6. **ESP32 콘센트 모듈 펌웨어:** CT 샘플링 → RPi4로 전력값 전송 → 버튼과 릴레이 비상정지. 서버 쪽 원격 전력 공급원도 붙인다(`rpi/controller/power_operation.py`).
7. RPi5 배포 환경에 기상청 키와 위치를 넣는다(`/etc/simplelay/environment`, 방법은 ambient devlog §2-4). API 키(`SIMPLELAY_API_KEY`)도 설정한다.
