# 실제 사용자 의견 받기 계획 (2026-10-10)

외부 조언에 따른 계획이다. 결선 전에 실제 사용자 1~2명에게 폰·키오스크 화면을 써 보게 하고, 막힌 곳을 고친다.
하드웨어가 없어도 할 수 있도록, 과업은 **폰·키오스크의 모의 화면만으로** 구성한다.

**지금 상태: 계획만 있다. 아직 아무도 참여하지 않았고 결과는 없다.**
결과가 나오기 전에는 보고서·발표에서 "사용자 평가를 했다"고 말하지 않는다.

## 1. 개인정보 원칙 (먼저 읽기)

- 이름·연락처·나이·장애 정보·얼굴 사진·음성 원본·동의서 원본은 **저장소에 넣지 않는다.**
  - 커밋·devlog·이슈·커밋 메시지·스크린숏 파일 이름 모두 해당한다.
- 동의서와 원본 기록(종이, 촬영·녹음 파일)은 팀 로컬에만 둔다.
  - 보관 기간: 대회가 끝날 때까지.
  - 기간이 지나면 폐기한다.
- 저장소에는 **익명 요약만** 넣는다.
  - 참여자는 `U1`, `U2`로만 부른다.
  - 특성은 "70대·저시력"처럼 넓은 범주로만 적는다. 기관·단체·지인 관계는 적지 않는다.
- 화면 캡처에 참여자 얼굴·손 외의 개인 물건·주변 환경이 찍히면 쓰지 않는다.
- 참여자를 소개해 준 사람·단체의 이름도 저장소에 넣지 않는다.

## 2. 대상

| 항목 | 내용 |
|---|---|
| 인원 | 1~2명 |
| 대상 | 고령자 또는 시각장애인. 작은 버튼·반복 메뉴 조작이 불편하다고 말하는 사람 |
| 모집 | 팀원의 지인 또는 단체를 통해 부탁한다. 보상과 조건은 미리 알린다 |
| 제외 | 동의 내용을 이해하기 어려운 경우. 이때는 보호자 동석과 보호자 동의 없이 진행하지 않는다 |
| 장소·시간 | 참여자가 편한 곳. 1인당 30분 이내(설명 5분, 과업 20분, 의견 5분) |
| 진행 | 진행자 1명(과업 안내만), 기록자 1명(관찰 기록표). 진행자는 정답을 알려 주지 않는다 |

## 3. 동의서 (초안)

참여 전에 소리 내어 읽어 주고, 서명 또는 구두 동의를 받는다. 구두 동의는 기록자가 날짜와 함께 종이에 적는다.

> **SimpleLay 화면 사용 의견 조사 참여 동의**
>
> 1. 이 조사는 학생 팀이 만든 가전 조작 보조 앱의 화면이 쓰기 쉬운지 알아보려는 것입니다. 실제 가전은 움직이지 않습니다. 화면은 모의(연습) 화면입니다.
> 2. 세 가지 과업을 해 보시고, 어려웠던 점을 말씀해 주시면 됩니다. 약 30분 걸립니다.
> 3. 언제든 이유 없이 그만두실 수 있습니다. 그만두셔도 불이익은 없습니다.
> 4. 이름과 연락처는 기록하지 않습니다. 결과는 "참여자 1"처럼 익명으로만 정리합니다.
> 5. 촬영·녹음 (선택, 각각 따로 고르세요)
>    - [ ] 화면과 손만 촬영해도 됩니다 (얼굴은 찍지 않습니다)
>    - [ ] 음성을 녹음해도 됩니다 (말씀을 받아 적는 데만 씁니다)
>    - [ ] 촬영·녹음 없이 메모만 해 주세요
> 6. 촬영·녹음 파일은 팀 컴퓨터에만 두고, 대회가 끝나면 지웁니다. 공개 자료에는 익명 요약만 씁니다.
> 7. 사진·영상을 발표에 쓰려면 따로 다시 여쭙겠습니다. 동의하지 않으시면 쓰지 않습니다.
>
> 날짜: ________  동의(서명 또는 구두 확인): ________

## 4. 준비

- **서버:** 전부 모의 등급 시뮬레이터 서버를 띄운다.
  - 절차는 [시연 v3](archive/본선-시연-시나리오-v3.md) §3-1~§3-3을 따른다. `uvicorn` 명령으로 띄우고, 가전 3종과 루틴 4개를 넣는다.
  - 비상정지 과업에 쓰는 모의 래치는 리허설 비상 버튼 `POST /demo/outlet-estop`으로 넣는다. 시뮬레이터 실행기에서만 된다(v3 §3-4 ⑤-c).
- **화면:** 폰은 실기기 또는 에뮬레이터 앱을 쓴다. 키오스크는 15.8형 패널을 쓰거나, 없으면 노트북 브라우저 `/kiosk/`를 쓴다.
- **표시:** 화면의 "모의" 표시를 가리지 않는다. 시작할 때 "실제 가전은 움직이지 않는다"고 다시 말한다.
- **시간:** 과업마다 스톱워치를 쓴다. 시작은 진행자가 과업을 다 읽은 때, 끝은 완료 화면이 보인 때 또는 포기한 때다.
- **상태 초기화:** 참여자가 바뀔 때마다 앞 참여자의 흔적을 지운다.
  - `DELETE /demo/inject-failure`
  - 래치를 해제한다.
  - 이력을 정리한다.

## 5. 과업 3개

과업 문장은 진행자가 그대로 읽는다. 버튼 이름이나 위치를 알려 주지 않는다.

| # | 과업(읽어 줄 문장) | 화면 | 성공 기준 | 보는 것 |
|---|---|---|---|---|
| T1 | "새 가전을 등록하는 화면을 찾아서, 첫 단계에서 무엇을 하라고 하는지 말씀해 주세요." | 폰 홈 → 가전 추가 1단계(조작부 사진) | 가전 추가 1단계를 열고 "사진을 찍으라"는 뜻을 말함 | 가전 추가 진입점을 찾는지. 단계 안내 문구를 이해하는지. 글자 크기 |
| T2 | "화면에 '아침 데우기'를 할지 묻는 카드가 나옵니다. 한 번은 실행해 보시고, 다음 카드는 이번에는 안 하겠다고 해 주세요." | 키오스크 루틴 카드(승인) → 폰 또는 키오스크 '다음에' | 첫 카드를 승인해 모의 실행 완료 화면을 봄. 둘째 카드를 '다음에'로 넘김 | 승인과 거절을 구분하는지. 승인 전에 누를 순서를 읽는지. "모의 실행 · 실제 조작 아님"을 어떻게 받아들이는지 |
| T3 | "실행 중에 멈추고 싶어졌습니다. 멈춰 보세요. 그다음 화면에 뜬 경고를 확인하고 다시 쓸 수 있게 풀어 주세요." | 실행 중 정지(화면 정지 버튼, 원하면 음성 "멈춰") → 모의 래치 띠·배너 → "확인하고 해제" | 정지를 요청함. 배너의 해제 확인까지 마침 | 정지 버튼을 바로 찾는지. 배너 문구를 이해하는지. 해제 전에 버튼을 풀어야 한다는 안내를 이해하는지 |

- T3의 래치는 시연 주입한 모의다. 실제 모듈·릴레이가 아니다.
  - 기록자가 참여자 몰래 `POST /demo/outlet-estop`으로 넣는다. "비상 버튼이 눌렸다"는 상황은 진행자가 말로 알린다.
- 시각장애 참여자에게는 폰 화면 읽기(TalkBack)를 켜고 진행한다.
  - TalkBack 전체 흐름은 아직 시험하지 않았다. 막힌 곳은 결함으로 기록한다.
- 한 과업이 5분을 넘으면 진행자가 도움을 주고 "도움 요청"으로 센다.

## 6. 관찰 기록표

참여자 한 명당 한 장. 저장소에는 아래 형식의 **익명 요약만** 옮긴다(원본 메모는 로컬).

|---|---|---|---|---|---|---|---|
| U1 | T1 | 예/아니오/도움 받아 | 【기입】 | 【기입】 | 【기입】 | 【기입】 | 【기입】 |
| U1 | T2 | | | | | | |
| U1 | T3 | | | | | | |
| U2 | T1 | | | | | | |
| U2 | T2 | | | | | | |
| U2 | T3 | | | | | | |

- **도움 요청:** 참여자가 묻거나, 진행자가 개입한 횟수다.
- **막힌 곳:** 10초 넘게 멈춘 곳을 화면 이름과 문구로 적는다.
- **한 줄 의견:** 참여자의 말을 짧게 옮긴다. 녹음했어도 문장 원본을 그대로 길게 옮기지 않는다.
- **끝난 뒤 질문:** 가장 쉬웠던 것, 가장 어려웠던 것, 집에서 쓰겠는지와 이유. 이 세 가지만 묻는다.

## 7. 결과 → 고친 것

발견마다 한 줄. 고친 것은 커밋까지 잇는다. 고치지 않기로 한 것도 이유를 적는다.

| 발견(참여자·과업) | 원인 추정 | 조치 | 커밋 | 다시 확인 |
|---|---|---|---|---|
| 【기입】 예: U1·T3 해제 전에 버튼을 풀어야 하는 줄 몰랐다 | 배너 문구 순서 | 배너 첫 줄을 바꿈 | 【해시】 | 다음 참여자 또는 팀 재시험 |

- 고친 화면은 수정 전후 캡처를 남긴다. 참여자가 찍히지 않은 화면만 쓴다.
- 고친 결과는 [피드백 전후](submission/피드백-전후.md) 10번 줄과 보고서 §6 "사용 편의" 칸에 옮긴다. 참여 인원과 과업 성공 수만 적고, 효과를 일반화하지 않는다.
- 접근성 기준은 [사용자 편의 가이드 체크리스트](사용자편의-가이드-체크리스트.md)와 대조한다.

## 8. 발표에서

- 결과가 있으면 이렇게 말한다. "N명에게 모의 화면 과업 3개를 부탁했고, 막힌 곳 k개 중 j개를 고쳤습니다."
- 결과가 없으면 "계획만 세웠고 아직 진행하지 못했습니다"라고 말한다.
- 1~2명의 결과로 "고령자가 쓰기 쉽다"고 일반화하지 않는다.
