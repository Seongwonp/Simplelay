### 2. 다중 노드 아키텍처 구현 (팀 작업, git pull)

`feat(multi-node)` + `feat(firmware)` 커밋에서 추가됨:
- `rpi/services/node_registry.py` — appliance_id → ESP32 노드 컨트롤러 매핑 (lazy 생성 + 스레드락)
- `rpi/services/esp_node_controller.py` — HTTP POST `/execute` → ESP32 (dev 모드)
- `rpi/services/aggregate_result.py` — 집계 결과(success/retry) → ExecutionResult 변환 공통 로직
- `rpi/api/router.py` — `/nodes` CRUD 엔드포인트 추가 (GET/POST/DELETE)
- `firmware-node/` — ESP32 펌웨어 스캐폴딩 완성:
  - `http_server.cpp`: `/execute` POST + `/alerts` GET 서버
  - `act_uart.cpp`: RPi4와 UART JSON 통신 (개행 구분)
  - `main.cpp`: HTTP↔UART 브리징, alert 상태 저장

**아키텍처 전환:**
```
[이전] RPi5 ─── UART ───▶ RPi4 (동일 하우징 가정)
[신규] RPi5 ─── HTTP ───▶ ESP32 ─── UART ───▶ RPi4 (가전마다 분산)
```
UART 포트 충돌 문제 자연 해소 (RPi5가 UART 직접 안 씀).

**경연장 대비 ESP-NOW 계획:**
- HTTP 모드: 개발/테스트 (현재)
- ESP-NOW 모드: 경연장 WiFi 혼잡 대비 (Phase 5, 10월 초)
- 구현: `EspNowGatewayController` + USB ESP32 동글 + `firmware-node` ESP-NOW 수신 추가
- `NodeRegistry(controller_factory=...)` 교체만으로 전환 가능

### 3. 폰 앱 개선 (오늘 직접 작업)

**`app/lib/services/rpi_api_service.dart`**
- `SensorReading` 모델 추가 (temperature, humidity)
- `RpiHealthData` 모델 추가 (ok, actuatorReady, dndUntil)
- `health()` — GET /health (DND 상태 + actuator 상태)
- `sensors()` — GET /sensors (DHT22 온습도)
- `setDnd(int minutes)` — POST /dnd
- `clearDnd()` — DELETE /dnd

**`app/lib/providers/rpi_api_provider.dart`**
- 기본 URL: `http://simplelay.local:8000` (첫 실행 시 자동 저장)
  → URL 입력 없이도 mDNS로 자동 연결 가능
- `RpiConnectionNotifier`: URL 로드 시 자동 연결 확인
- `sensorProvider`: `StreamProvider.autoDispose`, 60초마다 폴링
- `dndProvider`: `StateNotifierProvider`, set/clear/refresh 지원

**`app/lib/widgets/dnd_bottom_sheet.dart`** (신규)
- `showDndSheet(context)` — 바텀시트 표시
- 30분 / 1시간 / 2시간 / 해제 선택
- 현재 DND 남은 시간 표시
- `dndProvider.notifier` 통해 직접 API 호출

**`app/lib/screens/home_screen.dart`**
- 온습도 스트립 (`_SensorStrip`): 상단에 `16°C · 58%` 표시, 데이터 로딩 전 `AnimatedOpacity`
- DND 버튼: AppBar 우측 아이콘 (활성 시 warning 색)
- DND 배너: 활성 시 홈 상단에 "방해 금지 중 · X분 남음" + 인라인 해제 버튼
- RPi 연결 상태 카드 (`_RpiConnectionTile`): connected/checking/unreachable/unconfigured 4가지 상태 + 재시도 버튼
- BLE 카드: 미연결 시만 표시 (연결됐을 때 공간 차지 안 함)
- 빈 제안 상태: DND 활성 여부에 따라 아이콘/문구 변경
- AppBar 연결 chip: RPi online 여부 기준 (BLE만 / 연결됨 / 미연결)

**`app/lib/screens/settings_screen.dart`**
- 구조 개편: 일반 / 연결 / 고급(펼침) / 데모(debug)
- URL 입력: 기본값 숨김, "고급 설정" 펼쳐야 보임
- "기본값으로 초기화" 버튼 (`simplelay.local:8000`)
- BLE 스캔: 고급 섹션 내로 이동 (MAC 주소 표시 제거, rssi만)
- `_SettingCard` 공통 카드 컨테이너 도입

**`app/ios/Runner/Info.plist`**
- `NSAppTransportSecurity.NSAllowsLocalNetworking: true` 추가 → iOS에서 `simplelay.local` HTTP 접속 가능
- `NSCameraUsageDescription`, `NSPhotoLibraryUsageDescription` 추가
