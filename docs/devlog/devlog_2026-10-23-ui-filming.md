## 키오스크 후속 수정 (사용자 승인)

- 정지 요청의 실패 표시는 통신 예외·거절 등 여러 경우를 포함한다. 응답 유실만으로 미전송을 단정하지 않도록 ‘정지가 닿지 않았어요’를 ‘정지 요청 결과를 확인하지 못했어요’로 바꿨다. 실행·대기·결과 화면에 같은 기준을 적용했다. 정지 재요청·직접 확인 안내와 호출 동작은 유지한다.
