# 2026-11-02 키오스크 첫 환영 화면

사용자 요청: 처음 켠 본체가 일반 화면 대신 전체 화면 환영을 띄우고, 음성·글자로 안내하며, QR로 폰이 연결되면 일반 화면으로 들어간다.
커밋·배포 전 작업 트리 상태이며 실물 패널·스피커 확인 전이다.

## 바뀐 동작

- **환영 화면(키오스크):** 본체가 '연결된 휴대폰 0대'를 확인했을 때만 처음 화면 자리에 뜬다. 왼쪽에 환영·안내·'건너뛰기', 오른쪽 카드에 기존 QR과 6자리 코드.
  폰이 연결하면 '휴대폰이 연결되었습니다'와 체크 애니메이션을 4초 보인 뒤 일반 화면으로 간다. 폰 요청의 허락 단계는 카드 안에서 그대로 묻는다.
- **음성:** 뜰 때 1회, 연결될 때 1회. 음성 끄기·소리 끄기·조용한 시간을 따른다. 조용한 시간을 아직 모르면 알 때까지 기다리고, 조용한 시간이면 뒤늦게 말하지 않는다.
- **서버:** `GET /pair/phones`(허브 화면 전용) → `{"phones": n}`, 모르면 `null`.
- **키오스크 설정:** '설치용' 칸(콘센트 주소)을 숨겼다. `showInstallerSection`을 켜면 그대로 쓸 수 있고 코드는 지우지 않았다.
- **폰 설정:** 접힌 칸 제목을 '연결이 안 될 때만'으로 바꾸고, 그 칸을 가리키는 안내 두 줄도 맞췄다.

## 판단 근거: 왜 새 값이 필요했나

서버에는 폰 등록 기록이 없었다. 폰은 허브 키 하나를 함께 쓰고, 키오스크는 루프백이라 키 없이 지나가므로 인증 정보로는 폰 유무를 알 수 없다.
그래서 설정 칸 `paired_phones`에 수를 적는다. 다음 중 하나면 1대 이상으로 본다.

| 근거 | 이유 |
|---|---|
| `/pair/result`가 허락된 키를 건넸다 | 코드 연결. 같은 토큰으로 다시 물어도 한 대다. 코드만 넣었거나 허락만 한 상태는 세지 않는다 |
| 네트워크 쪽 요청이 허브 키로 통과했다 | 코드 연결이 생기기 전 폰, 연결 비밀번호를 직접 넣은 폰. 메모리 표시만 하고 인증 경로에 입출력을 넣지 않는다 |
| 값이 아직 없고 가전·루틴·실행 기록이 있다 | 이 기록이 생기기 전부터 쓰던 본체. 배포 직후 0대로 보여 환영 화면이 뜨면 안 된다. 값이 없을 때 한 번만 읽는다 |

저장소가 없거나 읽지 못하면 `null`이고, 키오스크는 null을 0으로 바꾸지 않는다. 떠 있는 동안 한 번 놓쳤다고 코드를 지우지 않도록 세 번 연달아 모를 때 닫는다.

## 구조

- `welcome_gate.dart`: 띄울지 정하는 규칙(화면 없는 작은 상태).
- `welcome_view.dart`: 그리기만 한다. 등장은 한 번 돌고 멈추며 흐림·셰이더는 없다. 기기가 애니메이션을 끄면 바로 다 보인다.
- `pairing_view.dart`: `embedded`를 더해 받기·허락·거절·만료 로직을 재사용한다. 카드에서는 시간이 지나면 새 코드를 스스로 받는다.
- 경로 전환은 `kiosk_screen.dart`의 처음 화면 분기에 넣었다. 실행·제안·정지 대기 화면이 앞서고, 비상 띠와 위험 경보는 위에 놓인다. 사람 감지 화면 쉬기는 이 화면을 덮지 않는다.

## 찾은 결함

위젯 시험에서 좁은 카드의 허락 단계 단추 두 개가 가로로 넘쳤다. 카드에서는 세로로 쌓고 허락 단추를 위에 둔다. 시험은 단추를 실제로 눌러 확인한다.

## 아직 확인하지 못한 것

- 실패널 표시와 등장 애니메이션 체감 속도, 실폰 QR 스캔 흐름.
- 실물 스피커 음성. 음성은 본체의 재생 경로가 만든 소리를 보드 소리 서버로 튼다. 이 경로의 실물 동작은 이번에 확인하지 못했고, 부팅 직후 음성 모델이 준비되지 않았으면 첫 안내가 늦거나 없을 수 있다.
- 화면 문구 '환영합니다'·'연결되었습니다'는 사용자가 정한 문구라 해요체 기준(R1)의 예외다.

## 빈 본체 시험에서 찾은 것

- 개발자 모드를 켠 본체에 내장 전자레인지·인덕션이 사용자 목록으로 보였다. 실물 조그 때문에 개발자 모드를 켜 두므로 목록 조건에서 뺐고, 리허설 런처에서만 보인다.
- 온습도 센서 선이 빠지면 읽기마다 4초가 넘게 걸리고, 호출이 잠금에 줄을 서 스레드풀을 막았다. 그 결과 `/connections`가 20초 넘게 걸려 키오스크가 '본체와 연결이 끊겼어요'를 띄웠다. 읽는 중에는 기다리지 않고, 다 실패하면 30초 쉬게 바꿨다.
