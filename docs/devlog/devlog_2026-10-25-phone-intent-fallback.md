# 폰 의도 이해 폴백

기존 음성 화면의 인식 문장 확인 후 실행이 명시적으로 422 ‘못 알아들음’ 응답을 받았을 때만 `/intent/understand`를 조회한다. 사용자가 입력한 텍스트도 같은 `_send` 경로를 따른다. 기존 `/execute`와 불확실한 전달 실패 처리는 바꾸지 않는다.

- 조회 중 ‘생각하고 있어요…’와 취소를 표시한다. 조회 시간 제한은 25초다.
- 후보를 받으면 서버 질문과 ‘아니요’/‘네’를 보여준다. 거절·닫기·취소·이탈·연결/선택 대상 변경 뒤 늦은 응답은 실행하지 않는다.
- ‘네’ 이후에만 기존 버튼·ThinQ·루틴 승인 경로로 보낸다. 같은 실행 요청 번호와 기존 상태/정지 추적을 사용한다. 실제 전송 후 답을 잃으면 재전송하지 않고 미확인 상태를 유지한다.
- 루틴은 먼저 읽기 전용 해석 응답의 지문과 기존 트리거 카드의 지문을 비교한다. 바뀌면 새로 고르도록 안내한다.
- 비활성·모름·추론 시간 초과·조회 실패·지원하지 않는 응답 종류는 기존 못 알아들음 안내와 대체 선택지를 남긴다. 추론 실패를 ‘실행됐는지 모름’으로 처리하지 않는다.
- 새 응답 모델은 정해진 세 동작 종류만 읽는다. 임의 실행 URL과 모델의 자유 텍스트는 받지 않는다.

관련 계약: [백엔드 기록](devlog_2026-10-25-closed-list-intent.md).

등록 가전의 기존 `/execute-for-appliance`가 기존 해석기 미설정임을 명시한 503 응답도 읽기 전용 폴백으로 이어간다. 일반적인 503 장애·준비 거절·전송 실패에는 적용하지 않는다. 기존 실행 API 동작은 변경하지 않는다.

새 위젯 시험 9건은 구현 전 모두 실패함을 확인했고, 기존 해석기 미설정 503 시험도 분기 추가 전 실패를 확인했다. 기본 화면의 모양은 바꾸지 않아 기존 골든은 갱신하지 않는다. 실기기 배포·모델 품질·실제 가전 조작은 이번 작업에서 검증하지 않는다.

최종 폰 비골든 전체 1,479건 통과(새 흐름 10건 포함), 골든은 갱신 없이 비교 79건 통과. analyze 오류·경고 0, 기존 info 5건. 잠금 파일·생성 플러그인 파일의 변경은 없으며 작업 명세 파일은 커밋하지 않는다. 보드 배포·원격 push는 하지 않았다.
