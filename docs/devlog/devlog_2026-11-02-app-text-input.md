# 2026-11-02 폰 '말로 하기' 글자 입력

## 바뀐 것

- '말로 하기' 화면 아래에 입력칸과 보내기 단추를 뒀다(`app/lib/widgets/voice_text_input_bar.dart`). 힌트는 "하고 싶은 말을 적어 주세요", 글자 수 상한은 본체 말 알아듣기와 같은 200자.
- 말·글자·후보 선택이 `_holdForConfirmation` 한곳으로 모인다. 적어서 보낸 문장도 음성의 최종 문장처럼 '이대로 할까요?'에 오르고, '이대로 하기'를 눌러야 기존 `_send`로 간다. 그 뒤(규칙 실행, 못 알아들으면 `/intent/understand`와 '네' 확인, 결과 표시)는 음성과 같은 코드다.
- 정지어("멈춰"·"그만"·"정지")를 적으면 확인 없이 바로 `_send`의 정지 분기로 보낸다. 멈추는 쪽이라 기다리게 하지 않는다.
- 듣는 중에 글자를 보내면 듣기를 멈추고 적은 말만 남긴다. 보내는 동안(`_sending`)은 전송이 잠기고 입력은 그대로 둔다.
- 마이크를 쓸 수 없는 기기: 안내 화면 아래에 입력칸을 두고, 적은 말의 확인·실패 안내가 있으면 그것을 먼저 보인다. 이 상태에서는 마이크·'다시 말하기'를 내주지 않는다. 안내 문구는 '이 폰에서는 마이크를 쓸 수 없어요. 글자나 버튼으로 해 주세요'로 바꿨다.
- 조작할 가전이 없으면 기존 분기대로 입력칸도 없다.
- 키보드가 올라오거나 큰 글씨로 자리가 모자라면 실행 단추를 고정하지 않고 본문과 함께 스크롤한다.

## 왜 보내기를 실행 동의로 치지 않았나

`/execute`는 본체 규칙에 맞는 문장을 확인 카드 없이 바로 실행한다. 이 화면에서 그 앞의 확인은 '이대로 하기'뿐이므로, 보내기를 곧장 `_send`로 이으면 물리 가전까지 확인 없이 실행된다. 대신 글자 입력은 보내기와 '이대로 하기'를 두 번 누른다.

## 그대로 둔 것

- 서버는 바꾸지 않았다. 적은 말도 `source: voice`로 기록된다.
- 승인·정지 규칙은 바꾸지 않았다.
