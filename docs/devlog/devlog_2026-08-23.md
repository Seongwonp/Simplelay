## 교차 리뷰(Codex) 반영 — Phase A 치명 4건 수리 완료

외부 모델 교차 리뷰를 코드 대조 검증한 결과 **오탐 거의 없음(수준 높음)**. 치명 4건을 즉시 수리:

1. **RPi4 실행 중 abort 수신 불가(#1)** — _on_execute의 await가 읽기 루프를 통째로 세우던 구조를 asyncio task 분리로 수리. "실행 도중 abort → SAFETY_STOPPED + 잔여 버튼 미눌림" 회귀 테스트 추가. **긴급 정지가 UART 경로에서 진짜로 성립하게 됨**
2. **ActClient sequence_id 미대조(#3)** — timeout된 이전 job의 늦은 응답이 다음 job 결과로 오인되던 결함. (id, future) 대조 + tombstone 폐기
3. **접수 직후 stop 유실(#5)** — stop 토큰 리셋 책임을 실행 시작 주체로 이전(execute 자동 clear 제거), begin/stop을 같은 락으로 직렬화
4. **완료 판정 추월 레이스(#4)** — 폰·키오스크·수동 3곳에서 last_job_id 최우선 판정 + 흔적 실종 N회 탈출

검증: pytest **397** · 폰 **119** · 키오스크 **12** 전부 통과.
