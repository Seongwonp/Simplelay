# 2026-10-27 데스크톱 의도 모델 실험

## 범위

- 발표 문구에서 측정 기록이 없는 실제 이동·버튼 누름·복귀·3일 습관 자동 실행은 `미검증`으로 바로잡았다.
- 본체 언어 모델과 대응하는 LG 공개 2.4B 모델을 확인했다. 공개 모델의 라이선스를 연구·평가·비상업 실험 범위에서 확인했으며 가중치를 배포하지 않았다.
- 실제 동작 목록에서 프롬프트를 만들고, 모델은 닫힌 목록의 **번호 하나만** 고르는 학습 예시 2,000개를 생성했다. 기존 평가 50문장과 새 평가 12문장은 정규화 완전 일치 및 문자 2-gram 유사도 검사로 학습에서 분리했다. 중복과 평가 문장 충돌은 모두 0건이었다.
- 별도 데스크톱 환경에서 4비트 QLoRA를 2에폭 학습하고 매 에폭 저장했다. 두 체크포인트를 병합·GGUF Q4_K_M 변환한 뒤 원본 공개 모델과 동일한 조건으로 재평가했다.

## 결과와 판단

자세한 설정·표·해석은 [언어 모델 평가 §11](../발표/언어모델-평가-2026-10-26.md#11-데스크톱-qlora-실험과-재평가2026-10-27)에 남겼다. 모델만의 기존 50문장 동작 맞힘은 원본 17/30에서 2에폭 24/30으로 올랐지만, 운영 경로인 **규칙+모델의 새 문장 동작 맞힘은 5/5에서 4/5로 하락**했다. 1에폭도 4/5였다. 따라서 **채택하지 않는다**. 실제 보드 지연, 기구 이동, 버튼 누름·복귀는 이번 실험에서 측정하지 않았다.

데이터·가중치·체크포인트·GGUF·평가 결과는 저장소 밖 `C:\Temp\lora\`에만 보관했다. 보드에는 읽기 전용으로 파일 이름만 확인했고 파일 변경이나 모델 배포를 하지 않았다. 비공개 플랫폼 자료는 저장소에 복사하거나 인용하지 않았다.
