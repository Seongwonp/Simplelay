# 2026-10-25 (학교·노트북) — 사람 감지·맡기기 단계·학습 근거

학교 실물 연결 날, 누름 장치가 HW 작업 중인 동안 SW 쪽에서 '먼저 알아서 하기'를 보강했다. 근거는 외부 모델 검토(Codex)와
공개 논문 요약(Amershi 외 2019 인간-AI 상호작용 가이드라인, Horvitz 1999 혼합 주도, Huang·Cakmak 2015, Ur 외 2014).

## 안전 경계(그대로)

- 사람 감지는 **언제 말을 걸지**에만 쓴다. 실행·승인·누름은 이 신호로 하지 않는다. 감지기가 죽으면 '모름' — 화면을 끄지도 제안을 막지도 않는다.
- 맡기기는 낮은 위험 LG 가전 동작만. 물리 누름은 매번 확인(열 나는 가전은 계속). 열 안 나는 물리 가전은 CT 상태 확인·사람 있음 조건으로 결선 전 검토(미구현).
- 자주 승인해도 저절로 맡기지 않는다 — 사람이 확인 칸에서 눌러야 한다.

## 검증 수준

- 시험 조건: 서버 새 시험(사람 감지 판단·인사·카메라 끄기·이름·습관 맡기기·10분 전·쓴 날·버튼 학습), 키오스크 맡기기·절전·인사, 폰 쓴 날 표시.
- 실물: 본체에서 온디바이스 사람 감지(공개 사전학습 검출 모델, CPU 한 장 약 0.8초) 동작·카메라 끄기/켜기 확인. 키오스크 화면 절전·인사·맡기기는 **아직 실패널 미확인**(다음 배포 뒤).
- 감지 프로그램·빌드 도구 묶음은 플랫폼 SDK를 쓰므로 저장소 밖 로컬 폴더에 둔다.

## 남은 것

- 용어 통일(루틴/자동 실행) 서버 문구 — 폰 문구와 같은 커밋으로(보류 중, 작업본은 저장소 밖에 보관).
- 감지기 부팅 자동 시작, 시험용 짧은 시간 값(5초·10초·30초) 원래대로 되돌리기.
- 열 안 나는 물리 가전 맡기기(CT 상태 확인·사람 있음).
