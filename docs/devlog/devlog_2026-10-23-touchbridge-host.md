# 2026-10-23 — HW 원본 유지, RPi4 인계 도구와 호스트 어댑터

## 확정한 책임

사용자 결정: HW 코드는 HW 담당자만 수정한다. ESP32 스케치·헤더·핀·PID·모터 제어식은 읽기 전용으로 참고하고 앱·RPi5·RPi4의 SimpleLay 통신 어댑터를 기존 규약에 맞춘다. 이번 작업은 펌웨어 변경·업로드 없이 진행했다. 받은 단독 원본 파일 3개의 SHA256은 작업 전후 동일하다.

운영 안전 정책의 추가·종합 검증은 수동·사진 매핑 뒤 마지막 개발 단계에 둔다. 연결/반복 조작에 숨은 home을 추가하지 않는다. 전체 순서는 [통합 재설계 계획](../통합-재설계-실행계획-2026-10-23.md).

## 1. 인계 준비

- RPi4만으로 실행하는 [USB 콘솔](../../rpi/tools/touchbridge_console.py)과 [Docker 런처](../../deploy/touchbridge-console.sh)를 추가했다. 호스트에는 Python이 없어 기존 이미지의 Python·pyserial을 사용한다.
- 자동 전송 없이 입력한 원본 명령 한 줄만 보낸다. 하나의 읽기 스레드가 비동기 `DONE`·`FAULT`·`PRESSED`까지 기록한다. `OK`만 받고 수신을 끝내지 않는다.
- 새 콘솔 종료 때 시리얼을 먼저 닫으면 pyserial 읽기 스레드가 `TypeError`로 끝나는 것을 실기기에서 발견했다. 읽기 종료를 먼저 기다리도록 수정하고 재확인했다.
- USB 열기 때 보드가 부팅되어 일회용 조회를 놓칠 수 있어 명령 전 부팅 대기를 뒀다. 부팅 문구를 사용자가 보낸 명령의 응답으로 간주하지 않는다.
- 인계 자료는 로컬 전용 폴더와 RPi4의 지정 폴더에 복사했다. 최신 3파일과 이전 전체 zip을 구분하고 원본 해시·현재 바이너리의 출처를 적었다. 구체 접속 정보와 원본 파일은 공개 문서에 넣지 않았다.
- 실제 원본 `P` 상태 응답을 읽었다. 운영 실행기는 중지·자동 재시작 꺼짐 상태로 유지했다.

사용 안내는 [RPi4 하드웨어 인계](../RPi4-하드웨어-인계-2026-10-23.md). HW 담당자가 검증한 최신 전체 펌웨어 묶음은 아직 확정받지 못했다. 인계 준비 완료와 HW 검증 완료는 구분한다.

## 2. 원본 규약의 호스트 어댑터

- [Touch Bridge 어댑터](../../rpi/controller/touchbridge_motion.py)를 추가했다. `SIMPLELAY_MOTION_MODE=serial`에 `SIMPLELAY_MOTION_PROTOCOL=touchbridge-v2`를 선택한다. 기존 기본값 `line-json/v0`는 유지한다.
- mm를 원본 `move_only`의 `target`으로 보낸다. 같은 command ID의 도착 좌표·위치 토큰을 보관해 다음 `press`에 한 번 사용한다. 카운트 변환·PID를 호스트에서 중복 적용하지 않는다.
- 단일 읽기 스레드가 command ID로 상태·이동·정지 응답을 라우팅한다. 늦게 처리된 이전 상태가 더 새로운 도착 좌표를 덮지 않도록 수신 순번을 사용한다.
- `RECEIVED`와 `COMPLETED`만 보고 누르지 않는다. 같은 이동의 `POSITIONED`·유효한 토큰·도착 좌표가 필요하다. Bot 결과 오류는 실제 눌림 성공으로 바꾸거나 자동 재누름하지 않는다.
- 읽기 오류가 나면 대기자를 깨우고 연결 끊김을 알린다. 상태 조회와 재연결에 물리 home을 끼워 넣지 않는다.
- [공통 모션 인터페이스](../../rpi/controller/motion_port.py)를 통해 RPi4 실행기·개발자 서비스에 연결했다. Touch Bridge의 mm 상태를 기존 어댑터의 A/B 카운트로 합성하지 않는다.
- `act_info.motion`은 `serial`을 유지하고 `motion_protocol`을 추가해 RPi5가 기존 개발자 연결 계약을 그대로 사용한다. 실제 RPi5↔RPi4 프레임 구현을 연결한 시험을 plain·signed 양쪽에서 실행했다.
- 원본 `status`에는 물리 정지 검증용 엔코더 정보가 없으므로 정지 확인은 `mcu_ack`까지만 표시한다. 기존 정지 전달은 연결하되 운영 정책의 확대 검증은 뒤 단계에 둔다.
- 직전 작업의 임시 bench 자동 home 코드는 정리했다. 반복 조그가 숨은 home을 전송하지 않는 것을 시험한다. 시간 조그·좌표 등록 UI는 다음 P2 작업이다.
