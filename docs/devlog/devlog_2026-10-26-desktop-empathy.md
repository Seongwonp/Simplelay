## 2. 온디바이스 LLM 실측(10/25 밤, RPi5, 인터넷 없이)

플랫폼 클라우드 AI 에이전트는 다시 시험해도 LG 사내 클라우드 접속 오류(8초 만에 실패) — 결선 데모에 쓰지 않는다. 대신 플랫폼에 들어 있는 **기기 안 언어 모델 서버**(llama.cpp 방식)에 LG 공개 언어 모델을 올렸다(공개 모델 그대로 — 학습 없음).

| 모델 | 말 알아듣기(정해진 동작 목록에서 번호 고르기) | 문장 만들기 | 속도 |
|---|---|---|---|
| 1.2B(Q4) | 한국어 지시 6개 중 2개 | 반말·엉뚱한 문장 | 3~5초 |
| 2.4B(Q4), 한국어 지시 | 6개 중 5개 | 지어낸 내용 섞임 | 6초 / 30~44초 |
| **2.4B(Q4), 영어 지시 + 동작 설명** | **8개 중 8개**("공기가 텁텁하네"·"방이 너무 답답해" → 공기청정기 켜기, "우유 조금만 데워 줘" → 30초 데우기, "오늘 날씨 어때" → 해당 없음) | 꽤 자연스러우나 영어 단어 섞임 | 6~8초 / 24~33초 |

결론: **말 알아듣기는 실전에 쓴다**(정해진 목록 중 하나만, 실행은 늘 사람 '네'). 문장 만들기는 실시간에 쓰지 않고 밤사이 미리 만들어 검사(영어·기록에 없는 숫자면 버림)한 것만 보인다. 표본 8~11개 — 정확도는 측정 필요.

같은 웹캠 영상을 둘로 나눠 16×12 흑백 한 장만 덮어써(얼굴을 알아볼 수 없는 크기) 평균 밝기를 잰다. 실측(1회): 불 켬 130~170, 불 끔(모니터 빛 있음) 100~120 — 카메라 자동 노출이 차이를 줄인다. 30초 평균 + 기준선 두 개(115/135)안, 웹캠이 모니터를 등지게 두면 차이가 커진다. 값은 추측/측정 필요. 기본값 '자동'으로 설정 3단(밝게/어둡게/자동)은 아직 미구현.

## 5. 별도 작업 폴더에서 진행 중 (AI 도구 사용)

1. 말 알아듣기: `POST /intent/understand` + 폰 '생각하고 있어요…' → 확인 '아니요/네'(브랜치 `codex-llm-intent`).
2. 습관 판단 개선: 고정 시간대 대신 시각이 가까운 것끼리 묶기(45분, 자정 넘김), 퍼짐(30분 이내면 '오후 10시쯤', 아니면 '이맘때'), 거절 두 번이면 3일 쉼, 실제 승인 시각 쪽으로 ±30분 옮김(브랜치 `codex-habit`).
결과는 검토·수정 뒤 main에 합친다. 남은 순서: 키오스크 말 알아듣기, 밤사이 생활 요약('알게 된 것' 화면), 자동 다크 모드, 사람 감지 시험값 되돌리기.
