## 3. B~F

- **B 발견 2 [높음] 모션 걸림 → '눌림 확인 실패'로 보고.** 원인은 `ClosedLoopController`가 어댑터 오류를 전부 재시도 오류로 보고 `continue`한 것. 이제 `motion_abort_reason`(모션 오류가 스스로 밝힘: `motion_alarm: stall`·`motion_reset`·`motion_timeout`·`motion_not_ready`·`motion_position_mismatch`, 시리얼 `OSError`는 `motion_link_error`)이 있으면 즉시 안전 정지하고 결과에 원인·실제 시도 수(1)를 싣는다. 사용자 정지 중이면 종전 정지 경로. RPi4 결과 프레임 `abort_reason`(없으면 필드 없음 — 옛 RPi5 호환) → RPi5 `/status` `last_abort_reason`·`/history` `abort_reason`(종료 사유 `motion_aborted`, DB 열 추가). 폰 상태·기록과 키오스크 완료 화면은 "모터가 걸려 멈췄어요. 다시 누르지 않았어요. 장치를 확인해 주세요." 계열이고 **다시 시도 버튼을 내걸지 않는다**(시험). 원점 전·재시작 뒤 누름 거절은 `MotionNotReady`(MotionRefused 하위)로 나눴다 — jog 도구 표시는 종전 '거절 MotionRefused'.
- **C 발견 3 [중간] 키오스크가 이전 결과 화면에 머물고 0.45 s 실행·정지를 놓침.** 평소 화면은 `running`이 보일 때만 이어받았고, 완료 화면은 서버를 보지 않았다. 이제 서버 `last_job_id`가 반영한 값과 다르면(켜기 전 결과 제외) 그 결과를 완료 화면으로 띄우고, 완료 화면에서도 2초마다 새 실행·새 결과를 본다.
  - C2: `/status` `last_auto_run`(마지막 자동 실행 결과: 대상·설정·값·확인 수준·실행 환경)을 더했다. 키오스크는 새 job일 때 한 번, **평소·완료 화면 위에 줄을 더하는 띠**로만 알린다(실행·동작 중 화면에서는 그리지 않음 — 정지 버튼·실행 상태를 가리지 않는다). 확인됨 "공기청정기 풍량을 강으로 바꿨어요", 미확인 "공기청정기 설정이 바뀌었는지 확인하지 못했어요", 모의면 같은 줄에 " · 모의 실행(실제 조작 아님)". 자동 실행 job은 완료 화면 대신 이 한 줄로만 알린다.
- **D 발견 1 [높음] RPi4가 USB 재열거 뒤 죽은 포트를 붙잡음.** `ReopeningLineTransport`가 쓰기·읽기 `OSError`에서 포트를 닫고 끊김으로 표시한 뒤 예외를 올린다. 끊긴 동안은 죽은 포트에 쓰지 않고 바로 오류다. `MotionLinkWatch`(RPi4 실행기 감시 스레드)가 **설정 경로 그대로** 0.5→1→2→4→8초 백오프로 다시 열고 `connect()`까지 한다. 그동안 `not_ready_reason()` → execute `motion_not_ready`. 다시 붙어도 이번 실행의 자동 재홈·재누름 차단은 그대로(사람의 다음 요청에서만 풀림). 시작 때 포트를 못 열면 종전대로 기동 실패. `SIMPLELAY_MOTION_PORT`가 `/dev/serial/by-id/`가 아니면 시작 로그 경고, 런북 §3-4·§5-3.
- **E 발견 4·5 [중간] 접근성.** 글꼴 1.5배 이상이면 승인 화면 고정 영역에 실행(·다음부터도 자동으로)·다음에만 두고, 안내 줄·30분 쉬기·바꾸기·다시 받지 않기는 본문 끝으로. 360×780·2.0에서 고정 영역 35% 미만(시험, 시험 글꼴에서 약 16%). 홈 루틴 큰 카드·행마다 이름·부제를 제 Semantics 노드로, 제안 카드 버튼 이름 "아침 데우기 실행하기"·"아침 데우기 다음에".
- **F 발견 7 [낮음] 줄바꿈.** `keepWordsTogether` — 같은 낱말 안 한글·숫자 사이에 U+2060(기존 숫자·단위 방식 확장). 홈 루틴 부제·가전 타일 상태 줄에만(접근성 이름은 원문). 골든에서 "연결을 확인해 / 주세요"로 낱말 경계에서 꺾이고 글자 사이 폭은 그대로인 것을 확대해 봤다.
- **발견 8 [낮음] 조그 중 정지 2회**(사용자 정지 + 조그 실패 뒤 어댑터 정지): 둘 다 확인돼 해가 없어 **기록만** 남긴다. 고치지 않았다.
