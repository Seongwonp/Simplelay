# 2026-10-27 2차 언어 모델 데스크톱 실험

- 학습 전에 30문장 보류 평가셋을 고정했다. 기존 50+12문장을 포함한 세 평가셋과 학습 예시 사이의 완전·근접 중복을 검사했다.
- 조용히·수면·약풍 요청을 끄기와 구분하는 학습 예시 2,000개를 생성했다. 중복·평가셋 충돌은 0건이었다.
- 1·2에폭 체크포인트를 각각 병합·Q4_K_M 변환하고 원본과 같은 데스크톱 조건에서 모델만/규칙+모델을 비교했다. 상세 수치와 해시는 [평가 문서 §12](../발표/언어모델-평가-2026-10-26.md#12-2차-데스크톱-qlora-실험2026-10-27)에 기록했다.
- 미리 정한 새 12+30문장 합산 기준에서는 2에폭이 원본보다 나쁘지 않았다(동작 15/20→17/20, 목록 밖·부정 오수락 1/17→0/17). 그러나 기존 12문장 동작은 5/5→4/5로 회귀했다. **GGUF는 후보 파일로만 보관하며 운영 채택은 보류**한다.
- 데이터·모델·체크포인트·로그는 저장소 밖에만 보관했다. 보드에 올리거나 사용자용 요청 경로를 호출하지 않았고, 보드 지연·실제 기구 동작은 미검증이다.
