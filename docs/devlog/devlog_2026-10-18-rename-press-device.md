# 2026-10-18 — '작은 팔' → '누름 장치' 이름 바꾸기

사용자 결정(10/18): 누르는 장치의 이름을 바꾼다.

- **화면(폰·키오스크·서버/RPi4가 보내는 사용자 문장·음성 문장):** '작은 팔' → **'누름 장치'**. 받침이 사라지므로 조사도 맞췄다('작은 팔이' → '누름 장치가', '은/을/과/으로/이고/이라' → '는/를/와/로/고/라'). 옛 '작은 팔 장치'도 '누름 장치'.
- **현재 상태를 말하는 문서(README, docs/submission/*, 본선 시연 계획 v4, UI 개편안, UI 남은 손볼 점, 코드 구조, 구성도 SVG):** '버튼 누름 장치'. 각 문서에서 처음 나올 때 '버튼 누름 장치(CoreXY 갠트리 + 솔레노이드)'. 화면 글자를 그대로 인용한 곳은 화면 말('누름 장치가 멈췄어요').
- **바꾸지 않은 곳:** docs/devlog/·docs/archive/·지난 인계, 10/15 날짜 계획 문서(키오스크 문구 개선 계획·키오스크 디자인 규격 계획)는 당시 기록이라 그대로. UI 개편안 §1의 문제 서술(한 물건을 여러 이름으로 부른다)과 10/17 결정 기록도 그대로 두고 10/18 변경을 덧붙였다. 키 이름·골든 파일 이름·코드 식별자 그대로.
- **문자열 비교:** 서버와 폰·키오스크 사이에 '작은 팔'을 글자로 비교하는 곳은 없었다(grep 확인).
