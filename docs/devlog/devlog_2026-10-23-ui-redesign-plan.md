# 2026-10-23 — 사용자 승인, UI 전면 재설계 계획과 비교 샘플

사용자가 기존 UI 변형 금지와 기존 탭·팔레트 고정 제약을 해제하고, 반복된 복잡함·가독성 피드백에 따라 전면 재설계를 요청했다. CLAUDE.md 맨 위 현재 기준에 승인을 기록했다. 과거 평가·UI 확정 문서는 이력으로 유지한다.

- [새 실행계획](../UI-전면-재설계-계획-2026-10-23.md): 정보 구조, 루틴/자동 실행 구분, 화면별 주·보조 행동, R0~R8 구현 순서, 이관·회귀·사용성 기준을 정리했다.
- 구조 후보: 홈/가전/자동 실행/기록, 설정은 상단에서 접근. ‘할 일 먼저’와 ‘가전 먼저’ 두 안을 같은 예시 데이터로 비교한다. 선택 전 후보이며 사용자가 세부 UI까지 승인한 것은 아니다.
- 대화에서 누를 수 있는 로컬 디자인 샘플을 만들었다. 샘플은 실제 가전 연결 없음 표시가 있으며 네트워크 요청·실제 실행은 없다. 시연용 상태를 실제 기기 상태라고 보고하지 않는다.
- 로컬 헤드리스 브라우저로 승인/대상 유지/실행/다른 탭에서도 정지/자동 실행 끄기/오늘만 건너뛰기/연결 끊김 차단을 확인했다. 320·390·736px, 글씨1배/2배, 두 안의12조합에서 가로 넘침 검사, JS 예외0. 기본 샘플 렌더도 열어 확인했다. 이는 Flutter·실폰·TalkBack·실제 사람 사용성 시험이 아니다.
- 제품 Flutter 코드·백엔드·HW 펌웨어·기기 env는 변경하지 않았다. 실기기 배포·골든 갱신 없음. 실제 앱 재설계 완료라고 보고하지 않는다.
- 다음은 샘플 방향 선택 후 R1 공통 화면틀과 R2 홈·가전 동선. 모션·하우징의 기존 미완료 작업을 이 UI 작업 때문에 완료 처리하거나 삭제하지 않는다.
