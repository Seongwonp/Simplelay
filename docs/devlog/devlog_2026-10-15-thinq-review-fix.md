# 2026-10-15 ThinQ 화면 외부 검토 반영 (폰·키오스크)

[ThinQ 실물 첫 연동](devlog_2026-10-15-thinq-real.md)에서 넣은 폰 '지금 상태' 카드·직접 조작과
ThinQ 관련 문구를 외부 검토가 짚은 대로 고쳤다. **폰·키오스크만** 고쳤다 — 서버 쪽 지적(직접 ThinQ 명령의
비상 정지 잠금, 배포·계정 연결 방식)은 따로 다룬다. UI 동결(10/14) 뒤 사용자 요청 예외(ThinQ 카드)의 결함 수리다.

실가전에서 본 사실(같은 날): 공기청정기가 꺼져 있으면 상태에 미세먼지 칸(`airQualitySensor`)이 아예 없고,
켠 직후에도 한동안 비어 있으며 풍량이 약풍으로 돌아간다. 이 모델 프로필은 풍량 약·중·강·자동, 운전 모드 청정·수면·자동.

## 1. 반영한 지적

| 항목 | 전 | 후 |
|---|---|---|
| M1 시간 초과 문구 | 연결 오류·시간 초과를 모두 "바꾸기를 보내지 못했어요" | 요청이 이미 허브에 닿았을 수 있으므로 "요청 결과를 확인하지 못했어요. 상태를 다시 읽어 확인해 주세요." + 상태를 다시 읽는다. 폰 HTTP 라이브러리로는 '보내기 전 거부'와 '보낸 뒤 응답 없음'을 믿을 만하게 가를 수 없어 둘 다 이 문장(5xx도 같음) |
| M1 두 번 누름 | 요청 중에도 다른 칩을 누를 수 있었다 | 묻기부터 응답(또는 실행 상태 화면에서 돌아옴)까지 칩과 '다시 읽기'를 잠근다 |
| 거절 문장 | 409는 늘 "다른 작업이 실행 중이에요" | 409·412·422·423은 허브가 준 이유를 그대로(비상 정지 잠금 등). 영어 '실행 중' 문장·빈 이유만 우리말로 |
| M2 전원 꺼짐 | 꺼져 있어도 풍량·운전 모드 칩을 내걸었다 | 전원 줄(켜기 누를 수 있음)만 두고 "전원이 꺼져 있어요. 켠 뒤 풍량·운전 모드를 바꿀 수 있어요." 스스로 켜지 않는다 |
| M2 미세먼지 칸 없음 | 줄을 조용히 뺐다 | 꺼짐이면 "전원이 꺼져 있어 미세먼지 값을 받을 수 없어요", 켜짐이면 "미세먼지 값을 아직 받지 못했어요(켠 직후에는 잠시 걸려요)" |
| 읽은 시각(사용자 요청) | "ThinQ에서 09:12:05에 읽었어요" | "09:12 업데이트"(모의면 " (모의)"). 낭독은 "ThinQ 상태 09시 12분에 조회" |
| M3 연결 화면 첫 문장 | 확인 중·확인 실패도 "아직 ThinQ 계정이 허브에 연결되지 않았어요" | 확인 중 "연결 상태를 확인하는 중이에요." · 실패/허브 없음 "ThinQ 연결 상태를 확인하지 못했어요 — 허브 연결을 확인해 주세요." · 허브가 ThinQ 끔(404)일 때만 "허브에 ThinQ 계정이 아직 연결되지 않았어요(설치 때 설정해요)." 설정 줄 부제도 같은 셋(확인 중 / 연결 상태 확인 못 함 / 계정 연결 전) |
| M3 가전 있음 문장 | "누를 버튼이 없어 목적(말)과 루틴으로 맡겨요" | "가전 상세에서 지금 상태를 보고 바꿀 수 있어요. 루틴에도 넣을 수 있어요." |
| M4 찾은 가전 안내 | "실행할 때는 언제나 확인을 거쳐요"(허용한 자동 실행과 어긋남) | "직접 바꿀 때는 한 번 확인해요. 사용자가 허용한 자동 실행은 따로 켜고 끌 수 있어요." |
| L1 오늘 사용 | ThinQ 조작도 "버튼 직접 누름" | 목적이 없는 ThinQ 기록은 허브가 남긴 결과 문장(예: "강풍으로 바꿨어요"), 없으면 "ThinQ 직접 조작" |
| L1 키오스크 ThinQ 안내 | "누를 버튼이 없어요" + "휴대폰에서 말로 맡겨 주세요" | "이 가전은 ThinQ로 조작해요." + "휴대폰의 가전 화면에서 지금 상태를 보고 설정을 바꿀 수 있어요. 제안이 오면 여기서 승인해도 돼요." 폰 버튼 조작 화면의 둘째 줄도 가전 상세를 가리키게 |
| L2 키오스크 가전 줄 | 배지 없음, ThinQ 작업 중에도 "동작 중" | 아이콘 옆 'ThinQ' 경로 배지(상세와 같은 배지, 줄 높이 그대로), 작업 중이면 "설정 변경 중"(허브가 설정을 보냈을 뿐 가전 동작을 본 게 아니다). 읽는 이름에 "경로 ThinQ" |
| L3 칩 읽는 이름 | "자동"이 풍량인지 운전 모드인지 갈리지 않음 | "풍량 자동"·"운전 모드 자동"·"전원 켜기" 등 줄 이름을 붙이고, 선택 상태는 칩이 그대로 알린다 |

폰 서비스 변경: `RpiApiService.thinqOverview`는 404만 null, 그 밖의 오류 응답·연결 오류는 예외로 올린다(연결 화면이 셋을 가르기 위해).
목록만 쓰는 화면(설정 가전 묶음)은 예전처럼 `valueOrNull`로 본다.
