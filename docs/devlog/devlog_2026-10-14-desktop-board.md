## 2. 실물 확인 (인계 §8 항목별)

| § | 항목 | 결과 |

| 1 | M1 자동 실행(두 보드 근거) | 설정: RPi4 리허설(모의 모션·콘센트 없음), RPi5 `SIMPLELAY_UART_REHEARSAL=1`·`SIMPLELAY_THINQ_MODE=mock`. 가열 종료 주입 → 카드 → 폰 "다음부터도 자동으로" → 확인 시트 → 규칙 생성(첫 실행은 모의 상태 확인 '성공'). 두 번째 주입 → 자동 실행 **`sent`**("허용한 조건이라 승인 없이 보냈어요"). 주입 응답 **`injected_in: rpi4_uart`**, 같은 때 링크 기록에 `clock_ref`가 있었다. 끝난 뒤 두 보드 설정을 원래대로 되돌렸다 |
| 2 | 걸림 알람 | 모터 A 엔코더 C1을 빼고 실행. 이동 **1회** 뒤 0.36 s에 `stall` → 정지 → 실행 끝(`retry: 0`). 재이동·재누름 없음. `/status`는 `last_abort_reason=motion_alarm: stall`, `last_retry_count=0`, 즉석밥 `attempts 1`. 폰은 "모터가 걸려 멈췄어요. 다시 누르지 않았어요. 장치를 확인해 주세요."(칩 '안전 정지'), 키오스크는 같은 문장에 '다시 시도' 없음(k01). 10/13 결함(걸림이 '눌림 확인 실패·3회'로 보임)이 실물에서 고쳐진 것을 확인했다 |
| 3 | 키오스크 짧은 실행·정지 | 키오스크를 걸림 결과 화면에 둔 채 폰에서 실행하고, 약 0.5 s 뒤 정지했다. 정지는 **누르는 도중**(`press_start` 뒤)에 들어갔고 누름은 `stopped`로 끝났다. 정지 응답은 15.3 ms. 키오스크는 결과 화면 → 실행 중(정지 버튼) → "실행을 멈췄어요"로 이어졌고, 정지 줄 **"멈춘 것을 확인했어요 (모션 보드 응답 17 ms)"**가 실패널에 처음 보였다(k02). 폰도 17 ms |
| 3 | 자동 실행 한 줄(C2) | 키오스크 평소 화면 위에 한 줄이 떴고, 실행 중 화면에는 그려지지 않았다(k03). **문구는 아래 발견 1** |

## 5. 발견

1. **[중간] 키오스크 자동 실행 한 줄이 결과를 단정한다.** 서버 기록은 `unconfirmed`("명령을 보냈지만 바뀐 것을 확인하지 못했어요")인데, 키오스크는 "마지막 작업이 끝까지 되지 않았어요"라고 보였다. 실패로 단정하지 말고 '확인하지 못했어요'로 맞춘다.
2. **[높음, 고침] 재열거 뒤 다시 열기가 컨테이너에서 막힘.** `ce37b81`.
3. [낮음] 모의 공기청정기가 이미 '강'일 때 '강'으로 바꾸라는 자동 실행은 '바뀐 것을 확인하지 못함'으로 남는다. 이미 목표값이면 "이미 강이에요" 같은 구분이 필요한지 정한다.
4. [낮음] 걸림 결과 문장 아래 '물리 버튼 · 확인 근거 없음' 줄은 여전히 시스템 용어다(키오스크).
5. [낮음] 긴 제안 큰 글씨 골든에서 가전 이름이 '에어 / 컨'으로 갈린다.
6. [운영] RPi4 케이스 팬이 GPIO 5V에 안 꽂혀 돌지 않았다. 핀 4(5V)·6(GND)에 다시 꽂았다. 온도 50.1 ℃ → 43~45 ℃. 5V 핀이라 OS를 꺼도 어댑터가 꽂혀 있으면 돈다.
7. [운영] 전원 구성 권고(사용자 질문):
   - 12 V 어댑터 하나 → 5.1 V 5 A 감압(RPi4)과 6 V 감압(모터)으로 나눈다.
   - 솔레노이드는 12 V를 직접 쓴다.
   - GND는 한 점에 묶고, 비상정지는 모터·솔레노이드 줄에만 둔다.
   - 결선에서는 멀티탭에 어댑터 두 개를 쓰는 편이 가장 안전하다. 솔레노이드 전압과 모터 전류는 HW 담당에게 확인한다.
