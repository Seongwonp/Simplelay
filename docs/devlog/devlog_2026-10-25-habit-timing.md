# 습관 시각 군집과 응답 적응

작성일: 2026-10-25

## 설계

- 목적·가전별 실제 직접 성공 기록만 모아 24시간 원에서 가장 큰 간격을 자르고,
  이웃 간격이 45분 이하인 기록을 묶는다. 시간대 이름은 중심 시각의 표시용이다.
- 원형 절대 거리 합을 최소화하는 중앙값과 중앙절대편차(MAD)를 계산한다.
  MAD 30분 이하면 평소 시각 10분 전부터, 그보다 넓으면 관측 창 시작부터 묻는다.
  명시적으로 선행 시간을 끈 기존 설정은 확실한 습관의 시간대 전체 노출을 유지한다.
  확실한 카드의 응답 창은 관측 끝 또는 중심 30분 뒤까지이며 마지막 분을 포함한다.
- 학습 상태와 후보에 평소 시각, 퍼짐, 창 시작·끝, 확신 여부, 질문 시각·이동량,
  쉬는 기한·사유를 더한다. 기존 필드는 유지한다. 루틴 초안 시각은 종전처럼 5분 단위로 내린다.
- 기존 영속 응답 기록에 중심 시각을 함께 남긴다. 목적·가전·가까운 중심으로 응답을 연결하며,
  서로 다른 군집을 합치지 않는다. 이틀 연속 거절하면 두 번째 거절 시점부터 72시간 쉰다.
  다시 시작해도 같은 기록으로 같은 기한을 복원한다. 시스템 철회·만료는 거절이 아니다.
- 하루 한 표본으로 승인 또는 카드 노출 뒤 실제 직접 사용 시각을 모은다.
  세 표본 이상이 같은 방향이면 기본 질문 시각 대비 중앙값만큼 옮기되 30분 이내로 제한한다.
  조정값에 반복 가산하지 않는다. 불확실한 습관은 관측 창 밖으로 옮기지 않는다.
- 승인·맡기기·조용한 시간·부재·억제 정책은 유지한다. 표시 시간대를 넘어 먼저 묻는 경우에도
  직접 완료한 동작은 새 카드와 기존 카드 승인을 막는다. 자동 실행 허용은 만들지 않는다.

## 명세 해석과 기존 기대 변경

17:10·18:00·20:30은 간격이 45분을 넘으므로 세 개의 미성립 군집이다.
불확실한 창 시험은 17:10부터 19:50까지 40분 간격의 다섯 사용일로 검증한다.
자정 양쪽 기록은 같은 밤을 두 사용일로 세지 않도록 군집 기준 날짜를 쓴다.

기존 시험 세 곳의 이유 문구만 시간대 표현에서 `오전 8시쯤 하셨어요`로 갱신했다.
실행·승인 기대는 바꾸지 않았다.
