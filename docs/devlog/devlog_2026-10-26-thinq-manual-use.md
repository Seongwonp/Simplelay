# 2026-10-26 — LG 앱·리모컨으로 바꾼 것도 직접 사용으로 기록

[10/26 데스크톱 devlog](devlog_2026-10-26-desktop-empathy.md) §7 심사 추천 ④.

- **무엇:** 공기청정기를 LG 앱·리모컨·가전 버튼으로 켜고 끄거나 바람 세기를 바꾸면, 그것도 습관 근거(직접 사용)로 남긴다. 전에는 SimpleLay에서 보낸 명령만 기록됐다.
- **어떻게:** 새 클라우드 호출은 없다. 이미 도는 공기질 판독(기본 120초)이 읽은 상태를 바로 앞 판독과 견준다(`rpi/services/thinq/manual_use.py`, 배선은 `rpi/api/air_quality_wiring.py`). 바뀐 값이 대응표 목적 문장(예: '공기청정기 켜줘')과 같을 때만 적어서 습관 판단·루틴 초안이 그대로 쓴다. 운전 모드·바람 세기 '중'처럼 대응표에 없는 변화, 꺼진 채 바뀐 설정은 적지 않는다.
- **두 번 세지 않기:** SimpleLay가 그 가전에 명령을 보낸 시각(실행기 시작·끝)이 바로 앞 판독 뒤이거나 10분 안이면 그 변화는 빼고 기준만 옮긴다. 10분은 **추측/측정 필요**(실제 클라우드 상태가 늦게 바뀌는 시간을 재지 않았다).
- **기록 모양:** 성공·직접 사용, 시각은 변화를 본 판독 시각(실제로 바꾼 때는 두 판독 사이). 실제 클라이언트일 때만 REAL, 모의·모의 클라우드·연습 기기는 MOCK이라 습관이 되지 않는다. 첫 판독은 기준만, 실패·빈 판독은 기준을 지우지 않는다. 사용 기록 표에 '앱에서 바꿈' 표시 칸은 늘리지 않았다(로그에만).
- **검증:** `rpi/tests/test_thinq_manual_use.py` 12건(모의). 실제 공기청정기에서 앱으로 바꿔 기록되는 것은 아직 확인하지 않았다 — 다음 보드 날.
