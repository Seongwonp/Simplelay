## 1. API·권한 계약 (`rpi/api/dev_router.py`)

| 조건 | 응답 |
|---|---|
| `SIMPLELAY_DEV_MODE` 꺼짐 | 모든 `/dev/*` 404 `dev_mode_disabled` |
| 켜졌지만 `SIMPLELAY_DEV_TOKEN` 16자 미만 | 503 `dev_token_not_configured` (fail closed) |
| 토큰 없음 / 틀림 | 401 / 403 — 실패는 클라이언트별로 적립 |
| 실패 한도(10회/60초) 도달 | 창이 지날 때까지 **맞는 토큰도** 429 |
| mock이 아닌 매니저 | 503 `real_adapter_not_allowed` |
| 끝난 세션의 id | 410 `session_expired` (비밀값 검사보다 먼저) |
| 비밀값 없음 / 다른 클라이언트 | 401 / 403 `not_session_owner` |
| 다른 세션 · 일반 실행 중 · 정지 정리 중 | 409 `session_conflict` · `execution_busy` · `stopping` |
| 정지 미확인 잠금 | 423 `fault` / `stop_unconfirmed` |
| 명령 빈도(20/s) · heartbeat(10/s) · 시작(5/10s) | 429 `rate_limited` |
| 같은 `request_id` 재전송 | 409 `duplicate_request` — 한 번만 실행 |
| 종료 중 | 503 `shutting_down` |

정한 것과 이유:

- **개발자 토큰은 일반 API 키와 별개이고 루프백도 면제하지 않는다.** 키오스크
  보드에 닿았다고 기계를 직접 움직일 권한까지 생기지는 않는다.
- **세션 비밀값은 시작 응답에서 한 번만.** 서버에는 sha256만 두고, 상태·기록
  응답에는 싣지 않는다(테스트가 응답 본문에 비밀값·"secret" 문자열이 없음을
  확인한다).
- **410이 403보다 먼저다.** 끝난 세션의 옛 비밀값에 403을 주면 화면이 '권한
  문제'로 오해해, 실제로 필요한 행동(새 세션 시작)을 안내하지 못한다.
- **정지는 어떤 제한도 받지 않는다.** 빈도·중복 검사 예외. 토큰이 없는 경우를
  위해 일반 `POST /stop`도 개발자 세션을 멈춘다(Phase 1 배선).
- **매니저 거절에 기계용 code를 붙였다**(`DevResult.code`,
  `DevSessionConflict.code`). 화면이 사람용 문장을 잘라 쓰면 문구가 바뀔 때
  조용히 깨진다. 표시용 상태 스냅샷 `state()`는 fault > stopping > active >
  execution_busy > idle 순서로 국면을 정한다 — 판정에는 쓰지 않는다.
- 엔드포인트는 전부 동기 함수라 스레드풀에서 돈다 — 매니저의 락·어댑터
  호출이 이벤트 루프(SSE 등)를 막지 않는다.

## 3. 최소 폰 화면 (`app/lib/screens/developer_console_screen.dart`)

설정 > 고급 설정 > 개발자 도구. 조이스틱·자유 입력 콘솔 없이 버튼만 둔다:
대상 가전 · 서버 국면(아이콘+문장) · 상태/홈/센서/jog 1mm 탭/등록 버튼
누르기 · 정지 · 기록.

- "모의 제어 — 실제로 움직이지 않음" 배너 상시. 서버가 `mock=false`이거나
  mock 필드가 없으면 조작 전부 잠금.
- 정지는 세션이 없어도 항상 누를 수 있고, **확인 못 한 정지를 완료처럼
  말하지 않는다**("정지를 확인하지 못했어요 — 기기가 잠겼습니다").
- heartbeat는 TTL의 1/3 주기로 비밀값과 함께. 410이면 세션 종료를 알리고 명령
  잠금.
- **화면 이탈(dispose)에서 세션 종료 요청 + heartbeat 중단**, 앱이
  hidden/paused/detached가 되면 세션 종료. inactive(알림창 등)만으로는 끊지
  않는다.
- 세션 비밀값은 기기에 저장하지 않는다. 개발자 토큰은 일반 API 키와 따로
  저장하고, 없으면 클라이언트를 만들지 않는다(화면은 토큰 입력만).
- 명령마다 `request_id` — 재전송이 두 번 실행되지 않는다.

폰 테스트 17건: 서비스 6(헤더 분리·본문·거절 code·불통·정지 미확인·mock 필드
없음=비모의), 화면 10, 설정 진입 타일 1.

  메모리에 산다. 현재 배포는 단일 uvicorn 워커다.
- 네트워크 지연 중 화면 이탈, 실기기 백그라운드 전환 타이밍, TalkBack 낭독.

- 토큰 전송 구간 보호 — 평문 HTTP다(공유 Wi-Fi에서는 토큰이 보일 수 있다).
  결선 현장 네트워크 구성과 함께 정한다.
