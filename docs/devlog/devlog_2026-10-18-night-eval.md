## 고친 것(요약)

- **정직성:** '켜졌어요'는 전력 실측 때만(근거 줄 '전기를 쓰기 시작한 걸 확인했어요'), 연습 장치를 '준비됐어요'라 하던 연결 문구, 실제 공기청정기 골든에 연습 문구가 나오던 데이터, 사용 방법의 실물 미확인 음성 정지 문구를 낮춤, 경보 화면은 보호자에게 실제로 보내지 않으므로 '가족에게 알렸어요' 대신 '위급하면 119'.
- **이름:** '작은 팔' → 화면 '누름 장치', 제출 문서 '버튼 누름 장치'(사용자 결정). '작은 팔'은 금지어 시험으로 막음.
- **인덕션·연습 세탁기:** 누름 장치 대상 가전을 `SIMPLELAY_GANTRY_APPLIANCES`(기본 microwave)로 — 인덕션은 '설정이 필요해요'(본체에서는 중립 '가족이 설정해요'). RPi5 env `SIMPLELAY_THINQ_PRACTICE_DEVICES=washer`로 연습 세탁기(실제 클라우드로 보내지 않음, 결과·기록 '연습').
- **안전 흐름:** 눌렸는지·켜졌는지 모르는 결과는 '움직였어요 / 안 움직였어요'로 사람이 답하게, '안 …' 뒤에만 '한 번 더 하기'(확인 창, 토글 버튼이면 꺼질 수 있다는 경고). 폰 루틴 '지금 하기'는 확인 시트를 거침.
- **보호자 폰:** 루틴 줄에서 자동 실행 켜기·끄기, 기록 '못 한 일만'·멈춘 까닭, 원격 보호자 말('집에서 확인이 필요해요'), 연습 가전 구역 분리, 사용 방법 화면.
- **본체:** 사용 방법 메뉴, 제안 자동 닫힘 40초 + 만지면 연장 + '시간 더 주기', 완료 화면 남은 초, 조용한 시간에 글자 대비 유지, 연결 끊김 줄·비상 안내 크게, 실행 중 누를 순서를 위로.
- **문서:** 제출 초안·README 정합(어긋남 28건), 새 구성도, 과업 '30초 → 시작' 통일, 보고서 본문 【기입】 0개(남은 31칸은 체크리스트).
