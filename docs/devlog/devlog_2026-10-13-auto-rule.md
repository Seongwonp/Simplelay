## 2. 흐름

1. RPi4가 전자레인지 CT 채널 사이클 끝을 보내면(`appliance_done`, `heat_complete`) 서버는 같은 사건인지·규칙이 있는지 본다.
2. 켜진 규칙이 없으면 카드 "공기청정기 강풍으로 바꿀까요?"(근거: 콘센트 전력으로 확인, 모의면 '(시연 주입)'·'(모의 입력)').
3. 폰 카드: **[이번만 실행] [다음부터도 자동으로] [안 할래요]**. 두 번째는 아래에서 올라오는 시트(새 화면 아님):
   "이번에 실행하고, 다음부터 자동으로 실행할까요? / 조건: 전자레인지 조리 완료가 확인됐을 때 / 동작: <공기청정기 이름> 풍량을 강으로 변경
   / [허용하고 이번에도 실행] [취소]". 허용하면 카드가 보여 준 내용의 지문을 실어 이번 실행(종전 승인 경로)과 규칙 저장을 한 번에 한다.
   빈 루틴 폼은 없다 — 카드 내용이 그대로 규칙이다.
4. 다음 조리 완료가 오면 승인 없이 그 동작 하나를 보낸다. 결과 알림은 장치별로 확인된 것만: "데우기가 끝났어요 (콘센트 전력으로 확인)",
   "<공기청정기> 풍량을 바꿨어요 (상태 재조회로 확인)", 미확인이면 "명령을 보냈지만 바뀐 것을 확인하지 못했어요 — 자동으로 다시 보내지 않아요".
   모의면 "— 모의 실행 · 실제 조작 아님". 공기 상태(깨끗함)는 말하지 않는다.
5. 루틴 탭 '내 루틴' 위에 규칙 줄: 조건·동작·'자동 실행 켜짐/꺼짐'·꺼진 이유·마지막 결과, [자동 실행 끄기]/[다시 허용](확인 시트)·
   [설정값 바꾸기](바꾸면 꺼지고 바뀐 내용으로 다시 허용을 묻는다)·[지우기].
