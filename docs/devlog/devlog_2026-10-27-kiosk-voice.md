# 키오스크 말하기 (2026-10-27)

키오스크 처음 화면에 `🎤 말하기`를 더했다. 5초 동안 본체 마이크로 듣고, 호스트의 whisper.cpp가 한국어를 알아들은 뒤 기존 휴대폰 `말로 하기`와 같은 의도 이해·확인 질문 흐름에 넣는다. 알아들은 말만으로 실행하지 않으며, 기존 확인 카드에서 반드시 `네`를 눌러야 실행 접수가 시작된다.

호스트 서버는 루프백에서만 요청을 받고 한 번에 하나만 녹음한다. 녹음 뒤 RMS 음성 구간 검사를 먼저 거쳐 무음의 짧은 환각을 버리며, 모든 임시 WAV 파일은 응답 전에 삭제한다.

보드 실측(10/27): 4초 녹음 → 약 8초 인식(base), 무음 환각은 VAD로 거름(미측정)

배포 때 RPi5에서 `deploy/run_stt.sh`를 실행하고, 필요하면 모델과 마이크 입력을 환경 변수로 지정한다. 백엔드는 로컬 STT 서버가 꺼져 있거나 닿지 않으면 한국어 안내와 503을 돌려준다.
