# 2026-10-07 — 실행 중 음성 "멈춰" 정지 (인계 4차 §1)

[인계 4차](../archive/인계-2026-10-07-노트북-4.md) §1. 9/30 결정대로 실행 중·정지 대기 중에만 듣고, 짧은 정지 말이면 화면 정지 버튼과 같은 경로를 탄다. **음성으로 실행 시작은 하지 않는다.**

## 어디서 듣는가 — 폰

보드 플랫폼에서 앱 권한으로 쓸 수 있는 음성 인식 서비스를 찾지 못해 폰 음성 인식으로 정했다. 홈 '말로 조작하기'가 쓰던 폰 음성 인식 엔진(`VoiceService`)을 그대로 다시 쓴다. 새 의존성은 없고 `pubspec.lock`도 바뀌지 않았다. 서버도 바꾸지 않았다(기존 `POST /stop`).

## 동작

| 상황 | 동작 |
|---|---|
| 실행 중(정지 줄이 보이는 단계: 요청 보냄·실행 중·재시도·확인 불가) | 듣는다. 탭 shell의 정지 줄 위와 실행 상태 화면의 정지 영역 위에 "듣는 중 · '멈춰'라고 말하면 멈춰요" 한 줄 |
| 정지 버튼 위 대기(`hold_state == hovering_stop`) | 듣는다. 실행은 끝났으므로 같은 `POST /stop`을 부르고, 서버가 정지 버튼 누름으로 넘긴다 |
| 그 밖(대기·완료·실패·정지 중 `stopping`) | 듣지 않는다. 끝난 세션에서 늦게 온 인식 결과도 버린다 |
| 정지 말 인식 | 실행 중이면 `ExecutionStatusNotifier.emergencyStop()`(화면 정지 버튼과 같은 호출). 별도 정지 경로 없음 |
| 실행 문장("즉석밥 데워줘" 등) | 아무것도 안 한다. 이 듣기는 정지 말만 본다 |
| 정지 말 반복 | **폰에서 한 번만 보낸다**: 보내는 중이면 무시하고, 보낸 뒤에는 그 실행(듣기 구간)이 끝날 때까지 듣기를 닫는다. 서버의 멱등성에 기대지 않는다. 더 멈추고 싶으면 정지 버튼이 그대로 있다 |
| 인식 오류 | 조용히 다시 듣는다(못 알아들음·침묵). 연속 5번이거나 권한 거부·엔진 없음이면 그 실행 동안은 접는다. 화면 안내 없음, 정지 버튼은 그대로 |
| 앱이 뒤로 감 | 마이크를 놓는다. 돌아오면 조건을 다시 본다 |

- 정지 말: "멈춰"·"정지"·"그만"과 가까운 변형("멈춰줘"·"멈춰요"·"정지해"·"그만해"·"스톱"·"스탑" 등). 공백·문장부호를 뺀 뒤 **이 말들만으로** 이루어져야 한다("멈춰 멈춰"는 되고 "전자레인지 멈춰 있어"·"그만 데워줘"는 안 된다). 부분 인식 결과에서도 본다 — 말이 끝나기 전에 "멈춰"까지만 들려도 정지를 보낸다(정지는 안전 쪽이라 이쪽을 택했다).
- 홈 '말로 조작하기'와 엔진을 나눠 쓴다. 엔진 계약에 `SpeechRecognizer` 인터페이스를 두고, `listen`에 "다른 호출자가 이 세션을 끊었다"(`onInterrupted`)를 더했다. 음성 화면이 마이크를 쥐는 동안 정지 듣기는 비켜 주고, 놓으면 다시 듣는다. 음성 화면의 마이크 버튼은 그 화면이 듣는 중일 때만 '끄기'로 동작하게 고쳤다(정지 듣기가 엔진을 쥐고 있을 때 눌러도 시작된다).
- 정지 대기 상태는 비상정지 걸림을 읽는 `/status` 조회(5초 주기)에서 같이 읽는다. 대기가 시작되고 듣기까지 최대 5초 늦을 수 있다.

## 시험

- 먼저 시험을 쓰고 아무것도 안 하는 뼈대로 돌려 **10건 실패**를 확인했다: 정지 말 받기, 실행 중 "멈춰" → 정지 한 번, 실행이 끝나면 듣기를 놓음, 실행 중 "즉석밥 데워줘" → 무시하고 계속 들음, 중복 "멈춰" → 한 번, 권한 거부 뒤 정지 버튼 동작, 못 알아들으면 다시 듣기, 다른 화면이 마이크를 가져갔다 놓으면 다시 듣기, 정지 버튼 대기 중 `POST /stop` 한 번, "듣는 중" 표시. 나머지 3건(실행 문장·긴 문장 거절, 대기에서 "멈춰" 무시, 엔진 예외)은 뼈대에서도 통과하는 부정 시험이고 구현 뒤에도 통과한다.
- 구현 뒤 폰 `flutter analyze` error·warning 0(info 4, 모두 기존), `flutter test --exclude-tags screenshot` **564** 통과(551 + 13), 골든 `--tags screenshot` **55** 비교 통과(갱신 없음 — 시험 화면들은 듣지 않는 상태라 그림이 같다).

## 한계

- **실물 마이크 인식률은 실측 필요.** 시험은 가짜 인식기다. 시연장 소음에서 "멈춰"를 얼마나 알아듣는지, 다른 말을 정지 말로 잘못 듣는지는 모른다.
- 안드로이드 음성 인식은 한 세션이 침묵(5초)이나 오류로 끝나면 다시 열어야 한다. 기기에 따라 다시 열 때마다 알림음이 나거나, 바로 다시 열면 바쁘다고 거절할 수 있다(추측 — 실기기에서 확인 필요). 재시작 간격 0.4초·오류 뒤 1.2초는 정한 값이지 잰 값이 아니다.
- 폰 음성 인식은 기기 설정에 따라 네트워크 인식을 쓸 수 있다. 오프라인에서 동작하는지는 기기에서 확인 필요.
- 정지 대기 감지는 5초 주기 조회라 늦을 수 있다. 조회가 실패하면 마지막 값을 그대로 둔다.
- 폰 화면에는 정지 버튼 대기 전용 정지 버튼이 아직 없다. 음성 정지만 대기 중에 `POST /stop`을 부른다.
- 모든 확인은 모의다. 실제 가전·누름 장치에서 음성 정지가 멈춘 것을 본 적은 없다.
