# 2026-10-08 데스크톱 — 인계 5차(외부 평가 64점 후속)와 합격 평가

[인계 5차](인계-2026-10-08-노트북-5.md)를 순서대로 진행했다. 끝난 뒤 서브에이전트 평가를 합격이 나올 때까지 돌렸다. 모든 실행은 모의 모션이고, 실물 누름은 여전히 0건이다.

## 인계 항목

1. **음성 정지 HTTP 실패를 성공으로 처리(HIGH)**
2. **키오스크·루틴에서 시작한 실행을 보지 못함(MEDIUM)**
3. **"듣는 중" 표시·부분 인식(LOW)**
   - 1~3 수리: `06469c9`([devlog](devlog_2026-10-08-voice-stop-fix.md))
4. **재배포와 v3 결속 확인**
   - 노트북 수리분을 포함해 RPi5·RPi4에 재배포했고, 모의 왕복은 성공했다.
   - RPi4 env에 v3 실물 결속(`home_mw:0,washer:1`, 인터폰 L3 없음)과 가짜 콘센트를 잠시 넣어 로그로 확인했다.
     - 전자레인지는 CT 채널 0, 세탁기는 1, 인터폰은 L3 판정 없음으로 결속됐다.
     - 전자레인지는 릴레이가 기본 꺼짐이라 "시작 전력 상승 미확인"으로 멈췄다. 정상적인 안전 동작이다.
     - 세탁기는 자기 채널로만 확인됐다(모의).
     - 확인 뒤 env를 원래대로 되돌렸다.
   - 폰 새 빌드를 에뮬레이터에 설치했다. 키오스크는 코드 변경이 없어 1.8.2 그대로다.
5. **RPi4 앱 계정 증거**
   - RPi4에 우리 앱 패키지를 설치해 앱 계정을 만들었다.
   - 그 계정 UID로 플랫폼 시스템 서비스 읽기 호출 1건을 성공시켰다. RPi5와 같은 조건부다(`0ea04c5`, 증거 대장).

## 서브에이전트 평가(합격 기준: 소프트웨어 HIGH·MEDIUM 0건, 문서 과장 0건)

| 회차 | 판정 | 점수 | 지적 → 수리 |
|---|---|---|---|
| 1 | 불합격 | 58 | 아래 4건 |
| 2 | **합격** | 59 | LOW 3건. 2건은 수리, 1건은 실기기 확인 필요로 기록 |

1회차 지적과 수리:
- MEDIUM: 긴 대기 중 침묵 종료가 오류로 쌓여 음성 정지가 조용히 꺼짐 → `60c7a8a`
- LOW: abort 쓰기 실패 시 CancelledError가 샘 → `17514db`
- LOW: 모의 BLE 정지를 성공으로 셈 → `60c7a8a`
- LOW: 정지 표시가 다음 실행으로 넘어감 → `60c7a8a`

2회차 지적과 처리:
- LOW: 늦게 실패한 옛 링크 쓰기가 새 링크를 끊음 → `8b70fff`
- LOW: 상태 조회 한 번 실패로 같은 실행에 정지가 중복됨 → `c08b0ea`
- LOW: 긴 실행 중 인식 세션을 계속 다시 엶 → 기록만. 실기기에서 시작음·배터리 확인 필요

평가자는 점수의 남은 감점을 모두 실물 검증 0건, L2 운영 경로 미연결, 당사자 평가 부재로 꼽았다. 소프트웨어 결함으로는 더 깎지 않았다.
