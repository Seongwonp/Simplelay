# 2026-10-27 본체 언어 모델 보드 시험

2차 2에폭 Q4_K_M 후보를 RPi5에서 원본과 같은 평가 문장으로 비교했다. 공간이 부족해 쓰지 않는 날짜 태그 `1025c`의 옛 백엔드 이미지를 정리했지만 공유 계층이라 공간이 늘지 않았다. 원본 GGUF를 저장소 밖 작업 폴더에 복사하고 해시를 맞춘 뒤 보드에서 옮겼으며, 새 GGUF도 복사 전후 SHA-256을 확인했다. 설정은 날짜 백업을 남기고 모델 파일 값 하나만 바꿨다.

규칙+모델의 학습 분리 새 42문장 전체 정답은 원본 30/42에서 새 파일 38/42로 올랐고, 목록 밖·부정 오수락은 2/17에서 0/17로 줄었다. 새 파일이 실제 모델을 부른 31건의 시간은 가운데값 9.8초·90% 10.2초였고 시간 초과는 없었다. 미리 정한 세 조건을 모두 만족해 새 파일을 유지했다. 사용자용 요청 경로와 실제 가전 실행은 호출하지 않았고, 백엔드·키오스크·다른 보드는 바꾸지 않았다. 자세한 표와 한계는 [언어 모델 평가 §13](../발표/언어모델-평가-2026-10-26.md#13-2차-2에폭-gguf-보드-시험2026-10-27)에 남겼다.
