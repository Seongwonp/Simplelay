# 2026-10-14 데스크톱 — 조용한 시간(정책 b '건너뛰기')

사용자 승인(10/14) 5번. 매일 정해진 시간대(사용자 설정)와 기존 '제안 잠시 쉬기'(30분·1·2시간)를 서버의 한 판정(`is_quiet`)으로 묶었다. 앞선 4번 기록: [습관 제안 → 루틴 초안](devlog_2026-10-14-habit-routine.md).

> **검증 수준: 모의까지.** 모의 ThinQ 공기청정기·리허설 가열 종료 사건·위젯 시험으로만 확인했다. 실가전·실제 CT 판정·실패널·실폰은 쓰지 않았다.

## 0. 일정 판단(4번을 끝낸 뒤, 착수 전)

- 4번과 추가 확인 3건을 마친 뒤 남은 범위를 다시 봤다: 서버(설정 저장·판정·자동 실행 건너뛰기), 폰 설정 '알림' 구획 한 줄, 키오스크 표시 두 곳과 소리 두 곳. 보드·배포·제출 서류와 겹치는 일은 없고, 자동 실행 경계는 판단·전송 직전 재검사에 조건 하나를 더하는 것이라 기존 경계(전송권·정지 세대·사건 나이)를 고치지 않는다.
- **같은 날 검증까지 가능하다고 판단해 구현했다.** 다만 경보 소리 정책은 정하지 않았다(§3 — 사용자 확인 필요).

## 1. 정책 — 무엇을 쉬고 무엇을 그대로 두나

| 구분 | 조용한 시간(매일 시간대·잠시 쉬기 모두) | 강제 자리 |
|---|---|---|
| 새 제안 카드(습관·환경·시나리오·루틴 시각/다가옴/끝난 뒤) | 만들지 않는다 | `ProactiveSuggestionService.is_quiet` — 생성 경로 전부 |
| 떠 있던 제안 카드 | **내린다**(기록 `withdrawn / quiet_hours`). 시간이 끝나도 다시 띄우지 않고 쌓인 제안을 한꺼번에 알리지 않는다 | `_withdrawal_reason` |
| 아직 시작하지 않은 자동 실행 | **건너뛴다.** 기록 `blocked` "조용한 시간이라 자동 실행하지 않았어요". 사건은 처리한 것으로 남아 끝난 뒤 같은 사건이 다시 와도 `duplicate`(재실행 0회). 판단 뒤 보내기 전(시작 게이트·전송 직전 재검사·전송권)에 조용한 시간이 시작돼도 보내지 않는다 | `AutoRuleEngine._try_run`·`guard`(메모리 판정만, 입출력 없음). 판정에 실패하면 보내지 않는 쪽 |
| 일반 안내 소리 | 키오스크의 제안 도착 낭독·자동 실행 결과 낭독을 내지 않는다(화면 카드·한 줄은 그대로) | 키오스크 `_toSuggestion`·`_trackAutoRun` |
| 사용자가 직접 요청한 실행 | **그대로** — 직접 실행(`/execute`·버튼판·ThinQ 명령), 루틴 '지금 실행' 카드와 그 승인 | 루틴 '지금 실행'은 `user_started` 카드라 만들고 내리지 않는다 |
| 정지 조작 | 그대로 | 정지 경로는 조용한 시간을 보지 않는다 |
| 이미 진행 중인 작업 | 중단하지 않는다 | 시험: 조용한 시간이 켜져도 정지 호출 0회, 작업은 성공으로 끝남 |
| 실패·정지 상태의 화면·기록 | 그대로 남긴다 | 바꾸지 않음 |
| 사용자가 실행한 결과 낭독(폰·키오스크) | 그대로(직접 요청한 실행의 결과) | 바꾸지 않음 |

화면 문구는 실제 범위만 말한다: 서버 `scope` "새 제안과 일반 안내 소리만 쉬어요. 아직 시작하지 않은 자동 실행은 건너뛰고 나중에 다시 하지 않아요." + 폰 "직접 실행·정지는 그대로예요." **'모든 알림이 조용해진다'고 쓰지 않는다**(시험으로 고정). 잠시 쉬기 문구도 같은 범위로 바꿨다(폰 "몇 시간 동안 새 제안과 자동 실행을 쉬어요", 키오스크 "새 제안과 자동 실행을 잠시 쉬어요").

## 2. 설정·표시

- 서버: `GET /quiet-hours`·`PUT /quiet-hours`(`enabled`·`start`·`end`, 일부만 보내도 됨, 잘못된 값 422). 기본은 **꺼짐·22:00~07:00**. DB 설정 `quiet_hours`에 영속(재시작 뒤 유지, 시험). `/health`의 `quiet`가 `/quiet-hours`와 같은 모양이라 폰과 키오스크가 같은 상태를 본다(시험).
- 폰: 설정 → '알림' 구획 안 '조용한 시간' 한 줄(새 탭 없음) — 요약("매일 22:00~07:00 · 지금 조용한 시간이에요"/"· 꺼져 있어요"), 범위 문장, 켜기 스위치(48 높이), 줄을 누르면 시작·끝 시각을 차례로 고른다. 허브가 없으면 "허브와 연결되면 설정할 수 있어요."·스위치 잠금.
- 키오스크: 평소 화면 위 줄의 방해 금지 자리에 매일 시간대 안이면 "조용한 시간 / 07:00까지"(잠시 쉬기가 켜져 있으면 그쪽이 먼저). 방해 금지 창에 "매일 22:00~07:00 조용한 시간 · 바꾸기는 폰 설정에서"(보여 주기만).

## 3. 경보 소리 정책 — **사용자 확인 필요**(기존 동작 유지)

비상정지·실패 경보를 한 묶음으로 정하지 않고 사건을 나눴다. **아래 '지금 동작'은 이번에 바꾸지 않았다.** 조용한 시간에 소리를 낼지는 사용자가 정한다.

| 사건 | 예 | 지금 동작(유지) | 조용한 시간 | 결정 |
|---|---|---|---|---|
| 사용자가 직접 멈춤 | 정지 버튼·음성 "멈춰" | 결과 화면·결과 낭독 | 그대로(직접 조작의 결과) | 사용자 확인 필요 |
| 통신 때문에 결과 모름 | 링크 끊김·ThinQ 상태 재조회 실패(`unconfirmed`) | 주의 화면·결과 낭독(직접 실행일 때) | 그대로 | 사용자 확인 필요 |
| 실제 위험 신호 | 콘센트 모듈 E-STOP 래치, 모션 걸림·안전 정지, 위험 신호음 감지 | 키오스크 경보 화면·낭독(`kEstopSpoken`·위험 신호음 안내·동작 중 고장 안내) | 그대로 | **사용자 확인 필요** — 기본안 제시 없음 |
| 일반 실패 | 눌림 확인 못 함·준비 안 됨(412) | 실패 화면·결과 낭독(직접 실행일 때) | 그대로 | 사용자 확인 필요 |

- 자동 실행은 조용한 시간에 시작하지 않으므로 '자동 실행의 실패 소리'는 생기지 않는다. 조용한 시간 전에 시작해 그 안에 끝난 자동 실행의 결과 낭독은 쉰다(화면 한 줄은 남는다).
- 안부 확인(보호자 알림)은 별개 설정('안부 확인 쉬기')이고 이번에 건드리지 않았다.

## 5. 시험

- 수정 전 실패 확인: 서버 새 시험 11건은 HEAD에서 실패(설정 모듈 없음 — 1건 실패·10건 준비 단계 오류). 폰 새 위젯 시험 3건, 키오스크 새 시험 4건(위젯·모델 3건은 컴파일 실패, 제안 도착 무음 1건 실패)도 HEAD `lib`에서 실패.
- 변형 확인: 자동 실행의 조용한 시간 검사 두 곳을 끄면 필수 시험(끝난 뒤 재실행 0회)·판단 뒤 시작·잠시 쉬기 3건이 실패, 전송 직전 검사만 끄면 '판단 뒤 시작' 1건이 실패, 떠 있던 카드 내림을 끄면 '다시 띄우지 않음' 1건이 실패하는 것을 확인하고 되돌렸다.
- **필수 시험 결과:** 조용한 시간에 온 가열 종료 사건 → 기록 `blocked`(조용한 시간), 모의 클라우드 제어 0건 → 시간이 끝난 뒤 같은 사건 재수신 → `duplicate`, 제어 0건(**재실행 0회**), 카드 0장 → 끝난 뒤의 새 사건은 평소대로 1회 보냄.
- 기존 자동 실행 경계 시험(전송권·정지 세대·사건 나이·이미 목표값·교차 시험)은 고치지 않고 모두 통과.
- 전체(ASCII 임시 worktree, 이 변경만 얹음): 백엔드+rpi4 **2,999 통과·13 건너뜀**(문서 링크·repo guard 포함), 폰 **814**(`--exclude-tags screenshot`, 811에서 +3), 키오스크 **336**(332에서 +4), analyze error·warning 0(기존 info 4·1).
- 골든: 폰 **55**·키오스크 **44** 비교 통과(갱신 뒤 재비교). 바뀐 장면 4장은 렌더를 이미지로 확인하고 갱신했다 — 폰 `settings`·`lt_settings`('알림'에 '조용한 시간' 줄이 들고, 잠시 쉬기 부제가 "몇 시간 동안 새 제안과 자동 실행을 쉬어요"로. 골든 환경엔 허브 응답이 없어 "설정을 불러오지 못했어요."·스위치 잠김), 키오스크 `dnd_large`·`kiosk15_dnd`(부제 "새 제안과 자동 실행을 잠시 쉬어요", 큰 글씨에선 두 줄).

## 6. 미검증·남은 것

- 실폰·실패널(15.8형)에서 보지 않았다. 시각 고르기(시간 선택 창)는 시험하지 않았다(켜기/끄기 저장만 시험).
- 경보 소리 정책(§3)은 사용자 확인 필요 — 확인 전까지 기존 동작이다.
- 키오스크·RPi5 백엔드는 다시 배포하지 않았다. **다음 보드 날 RPi5·폰·키오스크를 같은 커밋으로 배포**해야 키오스크가 `quiet`를 읽는다(옛 서버면 키오스크는 조용한 시간을 모른 채 종전대로 낭독).
- 시간대 판정은 서버(RPi5)의 현지 시각 기준이다. 서버 시계가 틀리면 시간대도 틀린다.
