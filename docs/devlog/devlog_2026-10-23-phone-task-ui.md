# 10/23 폰 과업 중심 UI — 1차 구현

사용자가 ‘할 일 먼저’ 샘플을 승인했고, 한 파일에 모두 넣지 말고 구조화할 것을 추가 요청했다. 이후 에뮬레이터에서 직접 확인하고 화면별 색을 일관되게 맞추라는 요청을 반영했다.

## 구현 범위

- 실제 경로를 홈 / 가전 / 자동 실행 / 기록으로 변경. 설정은 접근성 이름과 48dp 영역을 가진 톱니바퀴로 push한다. 설정에서는 탭을 숨기고 뒤로 가면 원래 화면·스크롤로 복귀한다.
- 설정과 저장 동작 관리 같은 탭 밖 화면에도 진행 중·결과 미확인 작업의 정지 수단을 유지한다.
- 홈에서 제안·저장 동작이 환경·예약보다 먼저 나온다. 제안이 없을 때만 첫 적격 저장 동작을 강조한다. 승인·실행 서비스는 기존 경로를 재사용한다. 사용 빈도나 추천 근거를 새로 만들어내지 않는다.
- 가전 목록은 홈과 같은 실제 준비 판정을 공유한다. 가전 선택은 상세 화면을 여는 탐색이며 명령을 보내지 않는다.
- 자동 실행은 시간 루틴과 조건 규칙을 함께 표시한다. 기존 켜기/끄기·다시 허용 확인·오늘 건너뛰기를 재사용한다. 연결할 루틴을 찾지 못한 시각 규칙도 남긴다. 새 조건 목록 조회는 실패를 ‘조건 없음’으로 숨기지 않는다.
- 폰 공통 강조색은 청록. 배경·카드·버튼은 공통 테마를 사용하며 경고·정지·연습의 의미 색은 유지한다. 연습은 별도 파랑과 글자로 구분한다. 검토용 라이트/다크 이미지는 서로 다른 화면 테마를 섞어 적용한 것이 아니다.

## 구조

- 홈 메인 파일의 2천 줄 이상 UI를 `screens/home/`의 역할별 부품으로 먼저 분리했다. 동작 보존 시험 46개 통과 후 독립 커밋했다.
- 저장 동작/자동 실행은 `screens/routines/` 아래 표시 문장·행·조건 조작·터치 제어·초안 카드·생성 시트·자동 실행 화면으로 분리했다.
- 설정 진입은 `widgets/settings_action.dart`, 탭 밖 정지 화면틀은 `screens/standalone_task_frame.dart`로 공유한다.
- 알림 주의 판정은 `models/care_attention.dart`로 옮겨 홈·설정 아이콘이 같은 기준을 사용한다. 상태·통신은 기존 provider/service를 재사용한다.

## 검증과 설치

- 실제 경로 새 시험이 수정 전 ‘가전’ 탭 없음으로 실패하는 것을 확인했다.
- 전체 비골든 시험 **1,437개 통과**. 별도 새 팔레트 시험은 라이트/다크 각각 홈·가전·자동 실행·기록·설정의 배경·카드·주요 색이 같은 공통 테마인지 확인한다.
- 렌더 76장(새 과업 화면 9장 포함)을 갱신 전에 검토했다. 큰 글씨·주 행동·연습·결과 미확인·정지 문구가 남는지 확인했다. 새 렌더가 없는 경우도 검토할 수 있도록 골든 비교기의 로컬 출력 도구를 추가했다. 공개 골든은 합성 데이터만 사용한다.
- 의도한 기존 52장 변경·9장 추가 후, 갱신 없는 골든 재비교 **76장 통과**. 나머지 15장은 변경되지 않았다.
- analyze는 error/warning 0. 기존 info 4개(차트 deprecated 2, 불필요 import 1, 시험 wildcard 1)는 이번 단계에서 변경하지 않았다.
- 에뮬레이터 앱은 기존 데이터 삭제 없이 디버그 빌드 4002로 교체했다. 설치된 이전 버전이 4001이라 기본 빌드 번호 1의 설치가 거절되어 빌드 번호만 올렸다.
- 에뮬레이터에서 본체 연결됨, 홈 → 자동 실행 → 기록 → 설정 → 뒤로 기록 복귀를 직접 확인했다. 설정에서 하단 탭이 없는 것과 같은 라이트 팔레트를 확인하고 홈으로 돌려놓았다.
- 모터·SwitchBot 실행 명령, 펌웨어 수정, 보드 백엔드·키오스크 배포는 하지 않았다. 앱의 본체 연결 확인을 RPi4·ESP32 실제 이동 검증으로 확대 해석하지 않는다.

## 남은 작업

이번 구현은 R1·R2 기반과 R4 통합 표시의 첫 단계다. 저장 동작 관리의 예전 세그먼트/용어, 가전 상세·승인·실행 결과·기록·설정·개발자 작업 화면의 전면 재배치는 아직 남았다. 키오스크는 폰 개편 뒤 별도로 설계한다. 실폰·TalkBack·실물 누름은 이번 UI 시험으로 검증되지 않았다.
