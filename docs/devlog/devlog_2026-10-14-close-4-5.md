## 2. 잠시 쉬기 적용 방식 — **'새로 켤 때부터 적용'**(추가 코드 없음)

- 업데이트 배포는 서버를 다시 띄운다. 잠시 쉬기는 서버 메모리에만 있으므로 **업데이트 전에 켜 둔 잠시 쉬기(옛 의미: 제안만 쉼)는 재시작과 함께 끝난다** — 새 의미(자동 실행도 쉼)로 조용히 이어지는 경우가 생기지 않는다(시험 `test_pause_set_before_an_update_does_not_survive_the_restart`).
- 업데이트 뒤 새로 켜는 잠시 쉬기는 켜는 화면에 이미 새 범위가 적혀 있다(폰 "몇 시간 동안 새 제안과 자동 실행을 쉬어요", 키오스크 "새 제안과 자동 실행을 잠시 쉬어요").
- '기존 활성 잠시 쉬기를 끝까지 두고 안내'안은 잠시 쉬기를 영속하는 새 저장과 이행 표시가 필요해 더 복잡하고, 지금은 이어질 상태 자체가 없다 — 고르지 않았다.
- 남는 점(종전과 같음): 배포·정전·재시작이면 사용자가 켠 잠시 쉬기도 끝난다. 화면은 서버 상태를 다시 받아 '꺼짐'으로 보인다(거짓 '쉬는 중' 없음). 매일 조용한 시간 설정은 DB에 남는다.

**끝 시각 표시(최소 추가, UI 동결의 사용자 요청 예외):**

| 자리 | 전 | 후 |
|---|---|---|
| 폰 홈 배너 | 방해 금지 중 · 1시간 20분 남음 | 방해 금지 중 · **23:30까지** · 1시간 20분 남음 |
| 폰 설정 '제안 잠시 쉬기' 줄(켜졌을 때) | 지금은 새 제안과 자동 실행을 쉬어요 | **23:30까지** 새 제안과 자동 실행을 쉬어요 |
| 키오스크 방해 금지 창(켜졌을 때) | 새 제안과 자동 실행을 쉬고 있어요 | **23:30까지** 새 제안과 자동 실행을 쉬고 있어요 |
| 키오스크 위 줄 칩 | 방해 금지 / 1시간 20분 | 그대로(칩 너비 고정 — 바꾸지 않음) |

시각은 그 기기의 현지 시각(서버는 오프셋 붙은 ISO 시각을 준다). 골든 장면은 모두 잠시 쉬기 꺼짐 상태라 바뀐 장면이 없다(§5).
