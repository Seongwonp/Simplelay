# 2026-10-18 밤샘 — 교수 의견 대응 UI 개편과 반복 평가

## 0. 계기

10/17 밤 지도교수 의견은 네 가지였다. UI 구조가 별로이고, AI가 만든 느낌이 강하고, 디자인이 부족하고, 말투가 엔지니어 설명 같다는 것이다("전문용어 모르는 사람은 어떻게 하냐").
계획은 [UI 개편안](../UI-개편안-2026-10-17.md)에 적었다. 정한 순서는 쉬운 말 사전 → 말투 규칙 → 구조 → 디자인 토큰이다.

사용자가 정한 것:
- 기기 이름은 **본체**, 누르는 장치는 **작은 팔**, **루틴**은 그대로 둔다.
- 범위는 말투·구조·디자인 전부다.
- 고치고 다시 평가받는 일을 90점이 될 때까지 되풀이한다.

## 2. 찾아서 고친 실제 결함

UI 평가 중에 잡은 것이다. 문구 결함이 아니라 동작 결함이다.

- **키오스크 상태 칩:** 본체 연결 상태를 보지 않았다. 그래서 본체에 닿지 않아도 지난번 연결 목록대로 '모두 정상'이 나올 수 있었다. 이제 칩·연결 목록 창·연결 창이 같은 표시용 목록을 쓴다(`1c4258e`).
- **폰 시각:** 에뮬레이터 시간대가 UTC라 루틴 시각이 9시간 밀려 보였다. 본체 시각 기준(`hubWallClock`)으로 고쳤다(`63d317a`). 평가 캡처용 에뮬레이터는 한국 시간대로 맞췄다.
- **키오스크 결과 화면 정지 제목:** 정지 확인 기한이 지나 `stop_level=sent`로 확정된 것을 결과 화면이 '멈추는 중이에요'로 그렸다(끝났는데 진행 중처럼 보임). 결과 화면 제목은 '작은 팔이 멈췄어요'(verified)와 '작은 팔이 멈췄는지 몰라요'(그 밖) 둘로만 쓴다. 보고를 기다리는 동안(최대 약 5초)만 '멈추는 중이에요'를 띄우고 단추를 숨긴다(`b9b1e83`).
- **시험:** 조용한 시간 복원 시험이 01:00~01:30 고정이라 그 시각에 돌리면 깨졌다. 12시간 뒤 시간대를 쓰도록 고쳤다(`c3eca02`).

## 3. 배포

- 실제 패널 키오스크와 에뮬레이터 폰에 7차까지 올렸다. 키오스크는 `1c4258e`, 폰은 `f19f739`다.
- 8차 수리: 10/18 오전 백엔드(RPi5·RPi4, `02db959`, 되돌리기 `simplelay-backend:1018b`)와 폰 APK에 올림. 키오스크는 날씨·LG 가전 실행 화면 작업과 함께 올린다.
- 보드 재부팅 뒤 키오스크가 안 뜬 일(10/18 아침): 끌 때 컨테이너를 `docker stop`으로 멈춰 unless-stopped가 다시 올리지 않았다. 다음부터는 `sync; poweroff`만 한다.
- 키오스크 설치 도구는 터미널(TTY)이 없으면 설치에 실패하고 옛 앱이 그대로 남는다. 7차 첫 캡처에서 이 문제가 나왔다. 설치 응답에 성공 문구가 있는지 꼭 확인한다.
- 5시 10분쯤 RPi4·RPi5를 안전하게 껐다(컨테이너 멈춤 → 디스크 쓰기 → 전원 끄기, ping으로 꺼짐 확인).

## 4. 남은 것

- 9차 평가 남은 감점(다음에 할 것):
  - 폰 홈 전자레인지 칸의 '자리 확인을 했는지 몰라요'와 '준비됐어요'가 어긋난다.
  - 키오스크 연습 대기 화면 문구가 어긋난다.
  - 설정의 '확인 못 했어요'·'연결됐는지 몰라요'에 까닭이 없다.
  - 루틴 편집 '그다음' 줄이 한 글자만 줄바꿈된다.
  - 기록 '봐 주세요'에 까닭 한 줄이 없다.
  - 정지 대기 띠와 제목이 같은 말을 되풀이한다.
  - 큰 글씨 결과 화면 단추 순서가 기본 화면과 다르다.
  - 마침표 규칙이 섞여 있다.
- 시험 수(10/18, 골든 제외): 폰 1,063 · 키오스크 759(골든 폰 61·키오스크 65). 백엔드는 이번 밤 서버 수정 뒤 전체를 다시 돌리지 않았다(바뀐 시험 파일 두 개만 34건 통과).

- 8차 수리의 실제 패널·폰 확인은 보드를 다시 켠 뒤에 한다(지금은 골든·시험 조건만).
- 서버 기록에 루틴 출처 필드가 없다. 그래서 '지금 하기'와 '정해진 시각 카드를 허락함'을 화면에서 가르지 못한다.
- 같은 버튼 두 번 누름(R1)은 화면 안내만 더했다. 재시도 정책 자체는 그대로다.
