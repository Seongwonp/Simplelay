# 승인된 폰 홈·알림함 적용 — 2026-10-23

## 사용자 요청과 범위

사용자가 선택한 민트 배너·큰 가전 그림·‘무엇을 할까요?’ 집중 카드 시안을 실제 폰 앱에 적용하고, 설정 옆 종에 안 읽은 알림 수를 표시한다. HW·백엔드 규약·실제 조작 명령은 변경하지 않는다.

## 구현

- 배너, 터치 심볼, 가전 그림, 알림 버튼은 역할별 파일로 분리했다. 그림은 Flutter 벡터이며 일곱 가전 종류와 기타 대체 아이콘을 지원한다. 등록된 종류만 사용하고 가전 이름으로 종류를 추측하지 않는다.
- 홈은 첫 실행 가능한 저장 동작 한 장을 강조하고 전체 동작 목록 진입은 유지한다. 시간 지정 동작만 있어도 전체 목록을 열 수 있다. 실제 저장 동작이 없으면 임의 동작을 만들지 않는다.
- 기본 글씨에서는 음성·종·설정을 같은 상단 줄에 두고, 큰 글씨에서는 음성 버튼을 별도 줄에 유지한다. 큰 글씨에서 반복 브랜드 배너만 생략한다. 연결 이상과 실행 경고는 숨기지 않는다.
- 종은 기존 `careEventsProvider`의 실제 읽음 상태를 공유한다. 알림함 열기 → 새 목록 조회 → 읽음 처리이며, 화면을 떠난 뒤에는 읽음 후속 작업을 하지 않는다. 설정 기어의 중복 배지는 제거했다.
- 0건이면 숫자 없음, 1–99건 실제 수, 초과는 `99+`와 전체 수 음성 안내. 조회 실패는 `!` 또는 이전 알림 수와 실패 안내를 유지하여 0건으로 단정하지 않는다.
- 홈·가전·자동 실행·기록에서 종으로 같은 알림함을 연다. 알림함에서도 실행 중·미확인 작업의 정지 경로를 유지한다.
- 주 동작의 기존 승인 화면, 실제/연습 구분, 장치 상태 표현을 보존했다. 중요 경고는 배너보다 앞, 설정 보조 안내는 가전 목록 뒤에 둔다.

## 검증

- 수정 전 새 종 테스트 4건이 실패함을 확인한 뒤 구현했다.
- 폰 비골든 최종 전체 1,445건 통과. 알림 전용 8건은 0·3·101건, 읽음 감소·신규 증가, 조회 실패·캐시 유지, 실행 중·미확인 정지 유지를 포함한다.
- 골든 77건 렌더를 확인하여 의도한 홈·종·가전 그림 변경을 갱신했고 비교 77건 통과했다. 기본·다크·큰 글씨·알림 3건 표본을 포함한다.
- analyze 오류·경고 0, 기존 info 4건만 남았다. debug 빌드 4003 성공.
- 저장소 가드·문서 링크 8건 통과. 새 문서는 추적 목록에 추가한 뒤 링크를 다시 검증했다.
- 에뮬레이터 저장 공간 부족으로 debug APK 설치가 실패했다. 앱 데이터는 지우지 않고 캐시 정리 후 작은 x86_64 release 빌드 4003으로 업데이트에 성공했다. 홈 → 종 → 실제 알림 목록 → 뒤로 홈 복귀를 확인했으며 실행 버튼은 누르지 않았다. 설치 설정과 등록 가전은 유지했다.

## 남은 범위

앱 전체 개편 완료가 아니다. 저장 동작 관리 세그먼트, 키오스크 화면 설계, 앱 런처 아이콘 교체는 별도 작업이다. 실제 모터나 SwitchBot은 이 작업에서 실행하지 않았다. 실제 기기 화면과 사용자 자료는 커밋하지 않는다. 원격 push는 별도 승인 전 수행하지 않는다.
