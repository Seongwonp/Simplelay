## 게이트웨이 확인에서 알게 된 것

- 파이썬 기본 User-Agent(`Python-urllib`)는 앞단 방화벽이 **403 · error code 1010**으로 막는다.
  User-Agent를 지정하면 401(키 없음)로 게이트웨이까지 닿는다 — 키 없이 두 요청을 비교해 확인.
  같은 문제가 기존 의도 해석 HTTP 클라이언트에도 있어 함께 고쳤다.
- 키 인증·모델 목록 조회는 성공. 사진 요청은 **402(이번 달 크레딧 소진)** 로 거절됐다.
  크레딧 조회 API 기준 월 한도를 넘겨 남은 양이 0이고, 갱신일은 **2026-10-01**이다.
- 그래서 **실제 모델이 사진 입력을 받는지, 좌표 축 순서가 요청대로인지, 정확도는 어떤지 모른다.**

## 완료의 경계

- **실제 인식 서비스 응답으로 검증하지 않았다.** 모델이 `[x_min, y_min, x_max, y_max]`가 아닌
  순서(y 먼저)로 주면 격자가 틀어진다 — 코드는 뒤집힌 좌표를 버리지만 축이 바뀐 좌표는
  구별하지 못한다. 10/1 이후 스크립트 출력의 격자를 사진과 눈으로 대조한다.
- 폰 편집기에서 이 API를 부르는 화면은 없다.
- 기준점(사진 좌표 ↔ 갠트리 mm)을 **어떻게 얻을지**는 정하지 않았다(프레임 모서리 표식 등, 하드웨어와 함께).
- 지도교수 방침("AI 고도화 금지")과의 관계는 팀이 확인한다 — 코드는 선택·기본 꺼짐으로 둔다.
