# 학교 연결 확인과 온도 조언

## 보드 연결

- 두 보드 모두 같은 핫스팟에서 SSH 접속을 확인했다. RPi4의 와이파이가 아니라 Docker 데몬이 꺼져 있었다.
- 실행기의 허브 허용 주소가 현재 허브 주소와 맞고, 모션 규약·USB 장치가 보이는 것을 확인한 뒤 Docker를 시작했다.
- RPi5 상태 API에서 `actuator_link_up:true`, `running:false`, `estop_latched:false`를 확인했다.
- 이동·원점 설정·누름 요청은 보내지 않았다. Docker 부팅 자동 시작은 disabled 상태이며 이번에 바꾸지 않았다.

## 온도 조언 수리

- 기존 환기 조건은 실내외 온도 차만 검사해 실내 21℃·바깥 13℃에서도 ‘더워요’라는 이유를 만들었다.
- 온도 경로는 실내 기준과 온도 차를 함께 만족해야 한다. 제품 기본값은 실내 28℃ 이상·실내외 차이 3℃ 이상이다.
  기존 환경 제안의 온도 기본값과 같으며, 쾌적성의 공인 기준이나 개인 체감 판정으로 주장하지 않는다.
  `SIMPLELAY_CONTEXT_VENT_MIN_INDOOR_C`로 조정할 수 있다.
- 이유는 ‘실내 온도는 29도예요’처럼 측정값으로 안내한다. 습도 때문에 환기를 권하는 별도 경로는 유지한다.
- 실내 21/20/26/27℃와 더 낮은 바깥 온도 조합의 억제, 높은 실내 온도 경로의 문구 등 5건이 수정 전 실패했다.
- 관련 환경·상황 제안 시험 97건 통과, 종료 코드 0. 노트북 코드만 수정했으며 보드 배포는 하지 않았다.
