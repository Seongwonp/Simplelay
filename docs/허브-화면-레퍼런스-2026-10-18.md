# 허브·가전 화면 레퍼런스 (2026-10-18)

작성일: 2026-10-18 · 모든 출처 확인 날짜: **2026-10-18**

[UI 제품 앱·공개 레퍼런스](ui-product-app-references.md)가 폰 앱 중심이라면, 이 문서는
**벽·책상·주방에 놓고 1~2 m 거리에서 보는 상용 허브·가전 화면**을 공개 자료로 조사한 기록이다.
SimpleLay 15.8형 키오스크(어르신 포함 가족)와 폰 홈·루틴·기록을 다듬는 근거로 쓴다.

**읽는 법과 한계**

- 공개 자료(제조사 공식 페이지·지원 문서·보도자료·리뷰·커뮤니티)만 봤다. 로그인·유료·비공개 자료는 보지 않았다.
- 각 항목 끝 `[S번호]`는 맨 아래 출처 표를 가리킨다. 출처 표에 **본문 확인**(페이지를 직접 읽음)과
  **검색 요약**(검색 결과 요약으로만 확인)을 나눠 적었다. 검색 요약만 있는 항목은 실제 화면과 다를 수 있다.
- 리뷰·커뮤니티 글은 제조사 입장이 아니다. 출시 연도가 오래된 자료는 지금 화면과 다를 수 있다.
- 화면·아이콘·문구를 복사하지 않는다. 정보 우선순위·상태 표현·자동화 흐름만 본다.
- 상용 제품과는 **설계 차이**로만 비교한다. SimpleLay가 더 낫다는 성능 주장을 하지 않는다.

## 1. 제품별 요약

### 1.1 LG — 스탠바이미·스탠바이미 Go·화면 냉장고·ThinQ ON·TV 홈 대시보드

- **스탠바이미(2021):** TV용 웹OS를 바탕으로 이 제품 전용 화면을 만들었고, 리모컨과 손가락 터치를 함께 쓴다. 가전 작동 상태를 확인·조작하는 기능이 언급된다. [S5]
- **스탠바이미 Go:** 화면을 아래로 쓸면 밝기·음량·전원, 위로 쓸면 처음 화면으로 돌아간다. 음성으로 앱 실행·소리 조절·검색. [S6]
- **처음 화면 위젯·상시 시계:** 스탠바이미 계열의 대기 화면 구성은 공개 자료로 **확인 못 함**.
- **화면 냉장고(CES 2025, Smart InstaView):** 오른쪽 위 문의 투명 OLED가 터치 화면 겸 안이 보이는 창. 카메라로 식품을 알아보고 요리 제안·유통기한을 챙긴다. [S3] 리뷰는 사진·애니메이션 표시와 같은 망의 기기 조작도 된다고 쓴다. [S4]
- **ThinQ ON(IFA 2024):** 원통형 스피커 모양 허브로, 공식 보도자료에서 화면은 **확인 못 함**(리뷰는 LED·물리 버튼을 언급 [S2]). 일상 말투로 대화하듯 시키고, 세탁 끝·고장 같은 일을 **먼저 알려 주며**, 루틴으로 가전을 자동화한다. [S1]
- **TV 홈 대시보드:** 웹OS 처음 화면의 바로가기로 열고, 가전은 폰 ThinQ 앱에서 먼저 등록해야 붙는다(제품 설명 사이트). [S7] LG 보도자료는 TV 화면에 세탁·냉장고 상태 알림을 띄운다고 설명. [S8]
- **어르신·접근성 모드, 루틴 건너뛰기, 실패 문구:** 공개 자료로 **확인 못 함**.

### 1.2 삼성 — Family Hub 냉장고·SmartThings Station

- **SmartThings 위젯:** Family Hub에는 하나만 둘 수 있고, 등록 기기 전부가 들어가지만 **한 번에 몇 개만** 보여 주고 화살표로 넘긴다. 카드를 누르면 조작, 이름을 누르면 상세 설정. 장면(Scene)은 아이콘으로 실행만 되고 **위젯에서 설정은 못 바꾼다**. 보일 기기·장면은 길게 눌러 고른다. [S9]
- **처음 화면:** 위젯 위치·크기·겹치기·추가 화면을 사용자가 고친다. [S10]
- **Now Brief(2025~2026):** 날씨·가족 일정·요리·집 정보(예: 세탁기 남은 시간)를 묶어 보여 주고, 맞는 냉장고에서는 **문을 열고 닫을 때 저절로 뜬다**고 한다. 단계적 배포. [S11][S12]
- **접근성:** 음성 안내(화면을 보지 않고 쓰기), 고대비(어두운 바탕에 밝은 글), 글자 크기·밝기, 일부 모델은 글과 화면을 키우는 표시 모드. [S13]
- **SmartThings Station(CES 2023):** 화면 없는 허브. 위의 버튼 하나로 앱에서 만든 루틴을 실행(짧게·길게·두 번 누름 구분은 리뷰). [S14]
- **루틴 실패 알림:** 공식 문서로 **확인 못 함**. 커뮤니티에는 "루틴이 실행됨"만 오고 무엇을 했는지 없다는 불만과, 메뉴의 기록에서 실제 실행 여부를 찾는 안내가 있다. [S15]

### 1.3 Google Nest Hub

- **한 화면 대시보드:** 조명·카메라·TV 등을 한 곳에서 보고 조작, 사진 액자, 주변 빛에 맞춰 화면 밝기·색을 바꾸는 센서. [S16]
- **제스처:** 위에서 아래로 쓸면 가정 조작 쪽 화면, 아래에서 위로 쓸면 빠른 설정(밝기·음량). [S17][S18]
- **거리에 따라 바뀌는 화면(2019~):** 멀리 있으면 **큰 글씨·버튼 없음·정보 줄임**, 가까이 오면 자세한 내용과 버튼. 저시력 어르신이 기기 앞까지 걸어와 읽는 것을 보고 만들었다고 공식 블로그가 밝혔다. 감지는 기기 안에서 처리. [S19] 지원 문서도 멀리 있으면 타이머가 큰 글씨로 보인다고 쓴다. [S20]
- **루틴 한 번 건너뛰기:** **확인 못 함.** 커뮤니티 안내는 루틴을 잠시 끄고(활성화 끔) 나중에 다시 켜는 방식. [S21]

### 1.4 Amazon Echo Show·Echo Hub

- **새 Echo Show 8·11(2025):** 다가오면 알아보고 인사·필요한 정보를 보여 주며, 거리에 따라 화면이 바뀐다고 설명. 전체 화면 스마트홈 대시보드(카메라·즐겨찾는 기기·기기 상태, 집·외출·밤 모드 한 번에 바꾸기). [S22] 리뷰는 전체 화면 광고가 남아 있다고 지적. [S23]
- **Echo Hub(벽걸이 8형, 2023 발표):** 사용자 맞춤 대시보드, 사람이 다가오면 화면이 깨어난다. [S24] 2026년 6월 화면 재설계로 대시보드 구역 재배열·더 세밀한 조작이 들어갔다는 업계지 보도(단일 출처). [S25]
- **접근성:** 화면 돋보기(두 손가락으로 확대·세 번 눌러 켜고 끄기), 색 반전·색 보정. 설정 → 접근성. [S26]
- **루틴:** 루틴 상세의 '사용' 토글로 끄고 켠다는 제3자 안내. 한 번만 건너뛰기는 **확인 못 함**. [S27]

### 1.5 Apple Home(홈 앱)

- **상단 상태 요약(iOS 16 개편, 2022):** 맨 위에 분류 단추(냉난방·조명·보안·물·스피커/TV)를 두고 각 단추가 **요약 숫자**(켜진 조명 수, 잠긴 문 수, 온도 범위)를 보여 준다. 누르면 방별로 펼친다. [S28][S29]
- **주의가 필요한 것 먼저:** 상단 요약은 주의가 필요하거나 중요한 상태 변화가 있는 액세서리를 모아 보여 준다(iOS 14 시절 해설). [S30]
- **응답 없음:** 기기에 연결이 안 되면 '응답 없음'을 따로 표시하고, 지원 문서가 재시작·같은 Wi-Fi 확인·다시 추가·제조사 문의 순서의 복구 안내를 준다. [S31]
- **자동화:** 시간·위치·센서·기기 동작을 조건으로 장면을 실행. [S32] 여러 자동화를 한꺼번에 잠시 끄는 쉬운 길이 없다는 사용자 불만이 있다(커뮤니티). 한 번만 건너뛰기는 **확인 못 함**.

## 3. SimpleLay에 바로 적용할 것

안전 계약 기준: 정지 우선(정지는 늘 보이고 기다리지 않음), 확인 수준 구분(보냄 ≠ 확인), 자동 재누름 금지 방향(R1),
조용한 시간에 건너뜀, 실측 전 수치를 사실로 쓰지 않음. 새 하드웨어(거리 센서·카메라)가 필요한 안은 넣지 않았다.

### 3.1 키오스크 처음 화면

1. **'멀리 보기'와 '가까이 보기' 두 단계.** 아무도 만지지 않으면 시계·다음 루틴·이상 한 줄만 크게, 화면을 한 번 만지면 가전 타일·예보 상세·건너뛰기 단추가 펼쳐지고 일정 시간 뒤 다시 접힌다.
   *왜:* Nest Hub는 멀리 있을 때 버튼과 세부 정보를 빼고 큰 글씨만 둔다 [S19]. 우리는 거리 센서가 없으므로 **터치를 '가까이 왔다'는 신호로 대신**하는 설계 차이. *안전:* 충돌 없음 — 단, 실행 중·정지 대기 중에는 접지 않고 정지 단추를 늘 보인다(Nest가 멀리서 버튼을 빼는 것과 반대로 둔다).
2. **'오늘은 건너뛰기'를 진짜 단추로.** 지금의 작은 회색 굵은 글자는 1~2 m에서 눌러도 되는 것인지 알기 어렵다. 다음 루틴 줄 오른쪽에 테두리 있는 보조 단추(터치 영역 48dp 이상), 누른 뒤엔 같은 자리에 '오늘은 건너뜀 · 되돌리기'.
   *왜:* 조사한 제품들은 루틴을 끄고 켜는 토글만 확인되고 한 회차 건너뛰기는 확인 못 했다 [S21][S27]. 우리만의 기능이라 처음 보는 사람이 알아보게 모양이 단추여야 한다. *안전:* 충돌 없음(건너뛰기는 실행을 줄이는 쪽).
3. **상태 알약은 이상이 있을 때만 말을 바꾸고, 누르면 그 목록.** '모두 정상' 대신 문제 있을 때 '확인 필요 1'처럼 숫자와 낱말, 누르면 무엇이 왜인지.
   *왜:* Apple 홈은 맨 위 요약에 주의가 필요한 것만 모으고 숫자로 보여 준다 [S28][S30]. *안전:* '모두 정상'이 확인 안 된 것까지 정상처럼 보이지 않게, 확인 못 한 가전이 있으면 '정상'을 쓰지 않는다.
4. **가전 타일은 한 화면에 들어가는 만큼만, 나머지는 'N개 더'.** 가전이 늘어도 처음 화면이 스크롤되지 않게.
   *왜:* Family Hub 위젯은 기기 전부를 넣되 몇 개만 보여 준다 [S9]. *안전:* 확인 필요한 가전은 앞쪽에 고정(뒤로 밀리지 않게).
5. **조용한 시간에 화면 밝기 낮추기(밤 화면).** 조용한 시간 동안 처음 화면을 어둡게·정보 더 줄이기, 만지면 평소 밝기.
   *왜:* Nest Hub는 주변 빛에 맞춰 밝기를 바꾸고 불을 끄면 화면도 꺼진다는 리뷰가 있다 [S16]. 우리는 조도 센서 없이 이미 있는 조용한 시간 설정을 쓰는 설계 차이. *안전:* 충돌 없음 — 실행·정지·실패 화면은 어둡게 하지 않는다. 밝기 값은 실패널에서 측정 필요.

### 3.2 키오스크 실행·결과 화면

6. **결과는 사라지지 않고 처음 화면에 '지난 일' 한 줄로 남기기.** 실패·확인 못 함은 사람이 '확인'을 누를 때까지 처음 화면 위쪽에 남긴다(성공은 짧게 남기고 접어도 됨).
   *왜:* ThinQ ON은 끝·고장을 먼저 알리고 [S1], Family Hub의 요약은 사람이 다가올 때 뜬다 [S12]. 1~2 m 떨어져 있던 가족이 결과 순간을 놓쳐도 보게. *안전:* '눌렸는지 모름'·'확인 못 함'이 시간이 지나 사라지면 안 된다는 기존 원칙과 같은 방향.
7. **'확인 못 함'에 복구 순서 2~3단계.** 예: '공기청정기 전원·Wi-Fi 확인 → 폰 ThinQ 앱에서 상태 보기 → 다시 하려면 [다시 확인]'. 자동 재시도 단추는 두지 않는다.
   *왜:* Apple 홈은 '응답 없음'을 성공·실패와 다른 상태로 두고 지원 문서가 재시작·같은 Wi-Fi·다시 추가 순서를 준다 [S31]. *안전:* 버튼 누름 장치는 '다시 확인'만, 다시 누르기는 사람이 새로 승인(R1 방향 — 토글 버튼 자동 재누름 금지).
8. **실행 중 화면은 하는 일 한 문장 + 큰 정지, 나머지는 접기.** 멀리서도 '무엇을 하고 있는지'와 '멈추는 법' 두 가지만 읽히게.
   *왜:* Nest의 멀리 보기는 타이머 같은 핵심 하나만 크게 둔다 [S19][S20]. *안전:* 정지는 기다리지 않고 늘 보임(정지 우선). Nest와 달리 버튼을 빼지 않는다.

### 3.3 폰 홈·루틴·기록

9. **홈 맨 위 요약 줄: '켜짐 N · 확인 필요 N · 오늘 자동 N'.** 누르면 해당 목록.
   *왜:* Apple 홈 상단 분류별 요약 숫자 [S28]. *안전:* '켜짐'은 실제로 읽어 확인한 가전만 센다(보냄만 한 것은 넣지 않음).
10. **루틴 탭에서 '루틴 켜기/끄기'(계속)와 '오늘은 건너뛰기'(한 번)를 다른 모양으로.** 토글은 스위치, 건너뛰기는 날짜가 붙은 단추('10/18 22:00만 건너뜀').
    *왜:* Google·Alexa는 끄고 켜는 토글만 확인되고 사용자가 이를 '잠시 쉬기'로 대신 쓴다 [S21][S27]. 둘이 섞이면 '건너뛰었는데 내일도 안 하나?'를 헷갈린다. *안전:* 충돌 없음.
11. **기록은 '실행됨' 한 마디로 끝내지 않고 단계·확인 수준을 같이.** 예: '22:00 저녁 공기청정기 켜기 · 자동 · 켜짐 확인'.
    *왜:* SmartThings 커뮤니티의 대표 불만이 '실행됨'만 오고 무엇을 했는지 없다는 것 [S15]. *안전:* 확인 수준(보냄·보드 응답·상태 확인·확인 못 함) 표기를 기록에서도 그대로.
12. **편집은 폰, 키오스크는 실행·건너뛰기·정지만 — 지금 원칙 유지.**
    *왜:* Family Hub 위젯도 장면은 실행만 되고 설정은 못 바꾼다 [S9], LG TV 대시보드도 가전 등록은 폰 앱에서 [S7]. *안전:* 키오스크에서 자동 실행 허용 범위를 넓히는 단추를 만들지 않는다.

### 3.4 접근성(키오스크·폰 공통)

13. **고대비 켜기(어두운 바탕·밝은 글·상태색은 낱말과 함께)를 큰 글씨 옆에 두기.**
    *왜:* Family Hub는 음성 안내·고대비·글자 크기를 [S13], Echo Show는 돋보기·색 반전·색 보정을 [S26] 접근성 설정에 둔다. 우리 키오스크는 큰 글씨·음성 안내만 있다. *안전:* 충돌 없음 — 경고색만으로 상태를 말하지 않는 기존 원칙과 같다.

### 3.5 가져오지 않을 것

- 카메라·Wi-Fi 감지로 사람을 알아보기(Echo [S22][S23]) — 새 하드웨어·개인정보 부담, 결선 범위 밖.
- 처음 화면 광고·추천 콘텐츠(Echo 리뷰 [S23]) — 가족 키오스크의 정보 우선순위와 반대.
- 처음 화면 위젯 자유 배치(Family Hub [S10]) — 어르신이 실수로 옮기면 복구가 어렵다. 배치는 고정.
- 대화형 AI 말투 확장(ThinQ ON [S1]) — 지도교수 방침(AI 고도화 금지). 말투는 쉬운 한 문장만.
