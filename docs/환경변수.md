# 환경 변수 (`SIMPLELAY_*`)

코드가 읽는 `SIMPLELAY_*` 환경 변수의 **이름·보드·기본·읽는 곳** 목록이다(2026-10-15, 기준 커밋 `55d2a06`).
**값은 적지 않는다** — 키·토큰·주소 같은 실제 값은 보드의 env 파일(저장소 밖)에만 둔다.

- **세는 법:** `rpi/`·`rpi4/`·`deploy/`의 추적 중인 코드(시험 제외)에서 이름을 모았다. 구체 이름 **190개**(기준 커밋 189개 + 10/15 저녁
  `SIMPLELAY_THINQ_MOCK_AIR_SENSOR_ALWAYS`) + 이름을 조립하는 형식 4개
  (`SIMPLELAY_CYCLE_<가전>_<항목>` 등). 그중 **52개**는 이 문서 말고는 어떤 추적 문서(md)에도 이름이 나오지 않는다(표의 '다른 문서' 칸 **없음**).
  대부분 센서 판정 기준값·모션 기구값·D-Bus 이름·키오스크 감시처럼 코드 머리말에만 설명이 있는 것이다.
- **보드:** RPi5 = 허브 백엔드(`rpi/main.py`), RPi4 = 실행기(`rpi4/act_main.py`), 양쪽 = 두 보드 env에 같이 둔다.
  `rpi/controller`·`rpi/verifier`의 값은 폴더가 `rpi/`여도 **RPi4 실행기가 읽는다**([코드 구조](코드-구조.md) §0).
- **기본:** 코드에 적힌 기본값. `—`는 고정 기본이 없다는 뜻이다 — 비우면 그 기능이 꺼지거나(모의·기록 안 함), 실물 경로가 필요한 값이면
  그 동작을 거절한다(예: 모션 기구값은 전부 `None`으로 시작해 실측 전에는 이동·누름을 거절). 정확한 처리는 '읽는 곳'의 코드를 본다.
- **읽는 곳:** 값을 읽는 줄 또는 이름 상수를 정의한 줄(`파일:줄`, 기준 커밋). 줄 번호는 코드가 바뀌면 어긋난다 — 이름으로 다시 찾는다.
- **배포:** env 파일 위치·백업 규칙은 [deploy/README](../deploy/README.md)와 [결선 운영 런북](결선-운영-런북.md).
  운영 주의(키 없음 → LAN 401, 링크 키 없음 → 기동 거절, `SIMPLELAY_L3_MODE=real`은 콘센트 모듈 필요)는 작업 규칙 문서와 같다.
- **측정 필요:** 센서 판정 기준(§ 센서 판정 기준)과 모션 기구값의 기본은 **설계 초기값**이고 실측값이 아니다.

이 표는 손으로 만든 목록이라 코드와 어긋날 수 있다. 다시 만들 때는 `rpi/`·`rpi4/`·`deploy/`에서
`SIMPLELAY_[A-Z0-9_]+`를 찾아 시험 폴더를 빼고 대조한다.

## 이 목록에 넣지 않은 것

- 시험 코드만 읽는 이름, 펌웨어 빌드 비밀(`firmware-node/secrets.ini`, 추적 안 함).
- 컨테이너 안에서만 쓰는 비-`SIMPLELAY_` 변수(예: `deploy/run_act.sh`의 `LINK_ALLOW_FROM` — `SIMPLELAY_LINK_ALLOW_FROM`에서 옮겨 담는다).
- 폰·키오스크 앱 설정(앱 안 저장소에 둔다 — 허브 주소·API 키는 폰 연결(`/pair`)로 받는다).
