# 결선 데모 시나리오 v1 (2026-08-23 초안)

> 원칙: **데모의 성패를 운에 맡기지 않는다.** 모든 장면은 리허설 API로 원할 때
> 재현 가능하고, 각 장면에 실패 시 대응 카드가 붙는다. 심사위원 ~10명이 멀리서
> 보는 조건(입체 배치·큰 화면·소리)을 전제로 구성한다.
> 실기기 검증 후 v2에서 실측 수치(성공률·재시도 통계 = `GET /history` 데이터)를 넣는다.

## 무대 배치 (교수님 피드백: "평면은 안 보인다")

- 전자레인지 + SimpleLay 갠트리를 **관객 방향으로 비스듬히(3/4 뷰)** — 버튼 누르는
  Z축 동작이 측면에서 보이게
- 키오스크(7")는 관객 쪽으로 세우고 **큰 글씨 모드 ON** + TTS ON — 화면이 안 보여도
  소리로 장면이 전달된다
- 폰 화면은 미러링(가능하면) 또는 발표자가 들고 시연 후 키오스크로 시선 유도
- 전용 공유기 지참(경연장 Wi-Fi 불신), 백업: BLE 폴백·시연 영상

## 사전 준비 (셋업 타임에 실행)

```bash
curl -X DELETE http://<rpi5>:8000/demo/inject-failure   # 잔여 주입 제거
curl http://<rpi5>:8000/health                          # 연결·actuator 확인
```

- 키오스크 설정(우하단 dot 3탭): 음성 안내 ON, 큰 글씨 ON
- 폰: 서버 연결 확인(홈 카드 초록), 음성 안내 ON

## 장면 구성 (총 ~6분)

### ① 음성 명령 → 물리 실행 (기본기, ~1분)
폰에서 "우유 데워줘" → 갠트리가 해동→시간→시작을 실제로 누름 → 키오스크·폰이
동시에 같은 진행 표시 → 완료 TTS.
말할 것: *"기존 가전을 그대로 두고, 말 한마디가 물리 버튼 시퀀스가 됩니다."*
- 대응 카드: STT 오인식 → 별칭 21종이 흡수("우유 좀 데워줘" 등). 재시도 1회 후
  안 되면 키오스크 수동 조작으로 전환(장면 성립).

### ② 선제 제안 — 공감지능 (~1분)
셋업 때 `POST /demo/suggest` (기본: 우유 데워줘) → 키오스크가 TTS로 먼저 말 걺:
*"우유 데워줘, 지금 실행할까요?"* → 탭 1회 승인 → 실행.
말할 것: *"사용 패턴(SQLite 이력)에서 나온 제안입니다. 부재 중에는 제안을 보류하는
공간 게이트도 있습니다."* → 폰 실행 기록 화면을 잠깐 보여주며 근거 제시.
- 대응 카드: 제안이 안 뜨면 `POST /demo/suggest` 재호출(멱등).

### ③ 실패 → 자가 회복 (하이라이트, ~1.5분)
```bash
curl -X POST http://<rpi5>:8000/demo/inject-failure -d '{"button_index":0,"attempts":1}' -H 'Content-Type: application/json'
```
실행 → 첫 버튼 검증 실패 → **갠트리가 스스로 좌표 보정 후 재시도 → 성공** →
키오스크에 "시도 2회" 표시 → 폰 실행 기록에 **"재시도 1회 후 성공" 배지**.
말할 것: *"전류·음향 센서가 '실제로 눌렸는지'를 확인하는 폐루프입니다. 실측
성공률/재시도 데이터가 전부 기록됩니다."* (v2: 실측 수치 슬라이드)
- 대응 카드: 주입은 1회용·자동 해제 — 실패해도 다음 실행은 정상. 하드웨어가 진짜
  실패하면 그것대로 폐루프가 동작(오히려 정직한 장면).

### ④ 긴급 정지 (안전, ~40초)
5분 조리 실행 중 → 키오스크 긴급 정지 탭 → **버튼 경계에서 실제로 멈추고**
SAFETY_STOPPED가 양쪽 화면에. 말할 것: *"UI가 아니라 폐루프 자체가 멈춥니다.
물리 E-STOP은 별도로 최종 권한입니다."*
- 대응 카드: 정지 요청 실패(통신) 시 30초 탈출 타이머가 화면 고착을 방지 — 물리
  E-STOP 시연으로 전환.

### ⑤ 위험소리 감지 (공간 안전, ~40초)
화재경보음 샘플 재생 → RPi4 감지 → **키오스크 즉시(SSE) 전면 경보 + TTS**:
*"위험 신호음이 감지되었습니다."* 말할 것: *"클라우드 왕복 없이 온디바이스에서
처리합니다 — 네트워크가 끊긴 순간에도 안전 기능은 살아 있습니다."*
(→ inference-boundary 슬라이드로 연결)
- 대응 카드: 마이크 감지 실패 시 경보 상태를 UART/mock으로 주입하는 백업 스위치
  (실기기 검증일에 준비), 최후엔 사전 촬영 클립.

### 마무리 멘트 (~30초)
*"오늘 보신 다섯 장면 — 음성·선제 제안·자가 회복·긴급 정지·위험 감지 — 이
전부가 가전 교체 없이, 기존 가전 위에 얹은 레이어 하나로 동작했습니다. 구형
가전이 많은 집일수록, 이 레이어가 그 공간 전체를 스마트하게 만듭니다."*

## 예상 질문 대비 (기술 Q&A)

- 전력: 전력 버짓 문서(10월 작성)로 답 — 12V 별도 전원+퓨즈
- 범용성: 앱 그리드 에디터 + 사진 오버레이 등록 → 인덕션·에어컨 예시 즉석 시연 가능
- 온디바이스/클라우드 경계: inference-boundary.md 요약 슬라이드
- 오차 보정: 폐루프 재시도(장면 ③이 곧 답) + 실측 데이터
- 접근성: 국가표준 3종 체크리스트 + 협회 자문 사진
