  - 다음에 → 평소 화면으로 복귀

  - 폰(에뮬레이터) 기록 탭: "재시도 1회 후 성공"
- **발견해서 고친 것:**

  - 폰 기록의 모의 행도 같은 기준으로 맞췄다.
- **설계상 그대로 둔 것:** API(폰)로 승인한 실행은 키오스크가 동작 중·완료로 따라가지 않는다. 키오스크는 자기가 시작한 작업만 따라간다.

## 4. 보드 점검(board_probe, 읽기 전용 기본 모드) (`7d8f053`)

- 설정과 원시 결과는 저장소 밖 로컬 폴더에만 둔다. 커밋하지 않는다.
- 실행 위치는 RPi5 백엔드 컨테이너와 RPi4 실행기 컨테이너다.
- **발견해서 고친 것:** D-Bus 자동 기동 금지 플래그의 이름이 틀려서(`NO_AUTO_START` → 실제는 `NO_AUTOSTART`) D-Bus 점검이 전부 미측정이었다. 테스트의 가짜 플래그도 같은 틀린 이름이라 결함이 가려져 있었다. 실제 라이브러리의 이름을 확인하는 시험을 더했다.
- **수리 뒤 결과:**
  - 측정됨: 서비스 존재·introspection, 파이썬 모듈 import, 웹 `/health`·`/status`
  - RPi4: 모듈 import, `socat`, 가상 시리얼 노드 존재
- **미확인으로 남은 것:**
  - "앱 권한" 칸은 **실패**로 나온다. root 실행은 앱 권한으로 인정하지 않는 설계 때문이다.
