# FIT0482 사용자 제공 사양

2026-09-27 사용자가 디바이스마트 제품 상세 페이지에서 옮겨 제공한 설명·외형 도면의 기록이다. 이번 기록에서 제조사 원문을 별도로 검증하지 않았으며, 공급받을 실물의 버전·라벨과 대조해야 한다. 개발 구성 기준은 FIT0482 3개(A/B/Z), JMOD-MOTOR-1 2장이다. 드라이버는 [JMOD-MOTOR-1 제어 검토](JMOD-MOTOR-1-제어-검토.md)를 참고한다.

## 엔코더 해석 보류

제공된 소개는 신형 Hall 센서가 7 pole pairs이고, 회전당 출력이 `7 × 2 × 50` 펄스라고 설명한다. 산술값은 700이지만 다음은 아직 확인되지 않았다.

- A/B 채널 파형·위상차, 신호 전압·출력 회로와 핀 배치.
- 700이 어느 채널의 어떤 에지 계수를 뜻하는지, 실제 실물 버전도 같은지.
- 구현할 디코딩 방식(x1/x2/x4)으로 출력축 1회전당 실제 누적되는 카운트.

따라서 `counts_per_output_revolution=700` 또는 그 값에 추가로 2·4를 곱한 값을 제어 코드에 확정하지 않는다. 계수 방식이 정해지고 출력축 회전과 실제 카운트를 대조한 뒤 설정한다.

## 제공 이미지

외형 도면은 단위가 mm이며 장착 구멍·축 치수를 보여준다. 텍스트의 축 길이 설명과 도면의 10.0·9·21.5 REF 등은 서로 다른 치수 구간일 수 있으므로 혼용하지 않는다. 기구 제작에는 원본 고해상도 도면을 대조한다. 다른 한 이미지는 어두운 배경에서 핀 이름·설명 글자를 판독할 수 없어 배선 근거로 사용하지 않았다. 첨부 이미지는 저장소에 복사하지 않았다.

## 시뮬레이션·제어에 남은 입력

벨트 피치·풀리 톱니 수·추가 감속비·XY 이동 범위, Z 회전→직선 기구와 스트로크, 원점/복귀 센서, 드라이버 사양·배선·공급전압이 필요하다. 이 정보 전에는 mm 이동량·정지 거리·Z 누름 힘을 확정하지 않는다. 현재 화면의 재생 시간은 설명용이며 위 RPM으로 보정된 모터 동역학이 아니다.
