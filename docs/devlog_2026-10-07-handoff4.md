# 2026-10-07 데스크톱 — 인계 4차 실행

[인계 4차](인계-2026-10-07-노트북-4.md)를 순서대로 진행했다. 노트북의 리뷰 후속 커밋 3건(전류 스레드 세대·통신 오류 뒤 재누름 차단·관측 시작 Z 직전)을 받은 뒤 시작했다. 모든 실행은 모의 모션이고, 실물 누름은 여전히 0건이다.

## 1. 음성 "멈춰" 정지 (`1b947ce`)

- 보드 플랫폼에서 앱 권한으로 쓸 수 있는 음성 인식 서비스를 찾지 못했다. 그래서 폰 음성 인식으로 정했다.
- 실행 중이거나 정지 대기 중에만 듣고, 그동안 화면에 "듣는 중"을 띄운다.
- 정지 낱말만으로 된 말을 들으면 화면 정지 버튼과 같은 `/stop` 경로를 한 번만 부른다.
- 실행 문장과 대기 중의 말은 무시한다. 상세는 [devlog](devlog_2026-10-07-voice-stop.md)에 있다.
- 실물 마이크 인식률은 실측 필요다.

## 2. 가산점 (1) 증거 (`e30d94c`)

- RPi5에서 키오스크 앱 계정과 같은 UID로 플랫폼 시스템 서비스 읽기 호출 1건을 성공시켰다.
  - 조건부다. 보안 레이블은 실제 앱과 다르지만, 이 메서드는 기본 정책이 모든 계정에 허용한다.
- RPi4에는 우리 앱이 설치되지 않아 앱 계정 증거가 없다.
- 원본 결과와 설정은 저장소 밖에만 둔다.
- 앱을 다시 설치하면 앱 계정 UID가 바뀐다(5009→5010).

## 3. ESP32 콘센트 모듈 USB 확인 — 보류

- 연결할 USB 선이 없어 하지 못했다. 하드웨어를 받은 뒤에 한다(사용자, 10/7).
