# 폰·키오스크 독립 UI 평가 (2026-10-23)

평가 대상: `62d2feb2` 위의 [촬영 전 UI 수정](devlog/devlog_2026-10-23-ui-filming.md) 작업 트리. 폰과 키오스크를 별도 검토자가 읽기 전용으로 평가했다. 폰 골든 12장·키오스크 골든 15장을 직접 열고 코드를 추적했다. 새 사용자 시험·실폰 조작·실패널·TalkBack 낭독·실제 하드웨어 시험을 한 것은 아니다. 아래 점수는 주관적인 UI 평가이며 결선 총점·사용성 측정값이 아니다.

사용자가 전달한 실제 사람의 ‘폰 앱이 너무 복잡하다’는 피드백을 검토의 출발점으로 삼았다. 그 피드백의 표본·과업·측정 시간은 확인하지 않았으며 정량 연구 결과로 쓰지 않는다.

## 판단

- **폰 73/100:** 미감은 일관되지만 처음 사용자가 실행할 곳·자동 실행을 끌 곳을 찾는 비용이 크다. 말투 개선만으로 복잡도가 해결된 것은 아니다.
- **키오스크 79/100:** 실행·결과·정지의 위계는 분명하다. 연습과 실제 문맥을 공유하는 안내, 관찰 질문의 중복이 남아 있다.
- ‘AI스럽다’는 인상은 디자인 판단이다. 새 장식보다 정보 우선순위·같은 상태의 설명 반복을 줄이는 편이 우선이다.

## 촬영 전 우선순위

1. 연습 비상 해제의 상단 전원 지시를 문맥에 맞추기. 실제/연습 위젯과 골든으로 고정.
2. 폰 상세 카드의 기본 글씨 줄바꿈 수리. 작은 변경으로 관찰 가능한 결함을 해소.
3. 홈에서 실행할 루틴을 빨리 찾도록 정보 순서 조정안을 확인. 제안 우선·경고·4탭은 유지.
4. 루틴의 오늘만 건너뛰기와 앞으로 자동 실행 끄기를 팀 밖 한 사람이 설명 없이 찾는지 확인. 실패하면 구획 이름/중복 표시부터 조정.
5. 실패널과 실폰에서 제안 → 실행 → 결과 미확인 → 정지 → 비상 해제를 촬영 거리·큰 글씨로 확인.

이 문서는 평가 기록이다. 위 발견 사항의 추가 수리를 완료했다는 보고가 아니다. 새 기능·팔레트 전면 교체·4탭 개편은 권고하지 않는다.
