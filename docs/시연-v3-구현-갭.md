# 시연 v3 구현 갭 (2026-10-06, 기준 커밋 `c75b2d5`)

[본선 시연 시나리오 v3](본선-시연-시나리오-v3.md)(전자레인지·세탁기·인터폰, "한 사람의 하루", 6분)를 실물 등급으로 올리는 데 모자란 것을
장면별로 적는다. **이 문서는 목록이다 — 여기 적은 것은 아직 하나도 고치지 않았다.** 다음 코딩 세션이 위에서부터 집어 가면 된다.

근거는 2026-10-06 모의 서버 실행(§3 of v3)과 코드 읽기다. 실물 검증은 여전히 0건이다(README "검증 수준(2026-10-05)").

## 5. 다음 코딩 세션 권장 순서

1. **S2**(모의 리허설에서 등록 가전이 바로 돌게) → **S1·S4**(v3에 없는 가전 정리, 템플릿 맞춤) → **S6·S7**(인터폰 종류, 세탁기 ID).
2. **S3**(가짜 모듈 비상 버튼) → **S10**(보드 배포) → 부분 실물로 ⑤ 리허설.
3. 결정 D2·D3가 나오면 **S8** 또는 **M1·M2**.
4. **S5**(키오스크 안내 한 줄)와 **S11**(화면 확인)은 Flutter 작업이라 데스크톱에서 묶어 한다.
5. 끝나면 v3 §3-4를 같은 명령으로 다시 돌려 결과 열을 갱신하고, **S12** 문서를 고친다.
