# 화면 용어와 문구

폰과 키오스크는 같은 표현을 쓴다. 해요체로 쓰고, 행동 버튼은 결과를 알 수 있게 이름 붙인다.

| 대상·행동 | 표현 |
|---|---|
| 집 안의 연결 중심 | 허브 |
| 버튼을 누르는 장치 | 누름 장치 |
| 가전의 전력을 읽는 장치 | 플러그 |
| 실행 승인 / 제안 미루기 / 실행 중단 | 실행 / 다음에 / 정지 |
| 버튼 눌림을 확인한 결과 | 버튼을 눌렀어요 |
| 가전 동작을 확인한 결과 | 켜진 것을 확인했어요 |
| 눌림만 확인하고 동작은 확인하지 못한 결과 | 눌렀지만 켜졌는지 확인하지 못했어요 |
| 누름 장치 응답만 받은 결과 | 누름 장치가 응답했어요. 켜졌는지 가전을 확인해 주세요. |

모의 결과는 반드시 모의라고 밝힌다. 응답만으로 실제 눌림이나 조리 종료를 단정하지 않는다.
모르는 결과를 실패로 단정하거나 다시 실행하도록 유도하지 않는다.

오류 문구는 **생긴 일 → 확인된 이유 → 다음 행동** 순서로 쓴다.
이유를 알 수 없으면 추측하지 않는다. 예: “허브에 닿지 않아요. 같은 와이파이에 연결하고 다시 확인해 주세요.”
실행 결과의 공통 문구는 두 앱의 `models/command_result.dart`에서 관리한다.
