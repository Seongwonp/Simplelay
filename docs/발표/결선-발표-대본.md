## 2. 시간이 밀릴 때 자르는 순서

1. 장면 ⑦ 조언 → 뺀다.
2. 장면 ⑤ '알게 된 것' → 질의로("질의 때 보여 드리겠습니다").
3. 장면 ⑧ → 뺀다(한계 슬라이드에서 한 줄).
4. **자르지 않는 것:** 장면 ② 알아듣기, ③ 습관 카드(실제든 연습이든 밝히고), ④ 맡기기 확인 칸, ⑨ 끄기, 한계 슬라이드.

## 3. 하지 않는 말

- "AI가 학습한다", "사람을 이해한다"고 단정하기 — "실제 쓴 기록을 세는 규칙"이라고 말한다.
- "사람이 있을 때만 움직인다" — 사람 감지는 묻는 때를 고르는 데만 쓴다. 안전은 '열 나는 가전은 매번 확인'으로 말한다.
- "거절하면 물러선다" — 정확히는 "연달아 두 번 거절하거나 답이 없으면 7일 쉬고, '이미 했어요'는 그날 다시 묻지 않는다".
- "8개 중 8개 정확", "정확하게 알아듣습니다" — 최신 보드 규칙+모델 평가의 고정 50문장에서는 동작 맞힘 29/30, 목록 밖·부정 오수락 0/16, 애매한 말 오수락 0/4였다. 학습에서 분리한 새 42문장은 전체 정답 38/42(동작 17/20, 목록 밖·부정 오수락 0/17, 애매한 말 오수락 1/5), 모델 호출 시간은 가운데값 9.8초·90% 10.2초였다. 한 번씩 잰 작은 표본이고 고정 50문장은 규칙 개발에 사용되어 낙관적이다([평가](언어모델-평가-2026-10-26.md) §13). 늘 '실행은 네 확인 뒤'를 함께 말한다.
- 습관이 만들어지는 며칠을 10분 안에 재현하기, 연습 화면을 자연 학습처럼 보이기.
- 가전을 안 쓴 것을 건강 이상으로, 귀가 공기 제안을 '귀가 예측'으로 부풀리기.
