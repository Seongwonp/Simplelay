## 1. 외부 모델 검토 요지 (10/25, 코드 읽기만 — 실기기 검증 아님)

**한 줄 평:** 지금은 '사용자를 이해하는 AI'보다 '실제 사용 이력으로 먼저 묻고, 허락받아 실행하는 허브'라는 설명이 정확하다.
결선에서는 AI 종류보다 **같은 시각에도 상황·거절에 따라 행동이 달라지는 장면**이 필요하다.

### 약한 고리 세 개 (심사 공격 예상)

| 약한 고리 | 예상 질문 | 10/25 대응 |
|---|---|---|

| 가전 사용 기록을 생활 상태로 해석하는 근거 약함(안부 판정 필터 차이, 거절 이유 구분 없음) | "누구의 습관이며, 오늘 안 쓴 이유를 아나요?" | 남음 — "가전 미사용 = 건강 이상"으로 말하지 않는다 |

**강점으로 인정된 것:** 버튼 실행의 정확한 기능 매칭, 실제·성공·직접 사용만 습관 반영, 낮은 위험 LG 가전 동작만 자동·허락 내용 재검사.

### 우선순위 (외부 모델 제안)

1. 사람이 없을 때는 조용히, 돌아오면 한 번만 제안 — **10/25 반영**
2. 실제 사용 날짜와 제안 이유 보여 주기 — **10/25 반영(쓴 날)**
3. "매일인가요? 평일인가요?" 한 번 확인 후 기억 — 남음
4. "이미 했어요"를 누르면 오늘 다시 권하지 않기 — 남음
5. "기록 없음"과 "기기 연결 끊김"을 구별한 안부 안내 — 남음
6. "허락한 조건 → 실행 → 실제 상태 확인" 한 화면 — 일부(맡기기 확인 칸)
7. 실제 사용자 관찰(몇 단계 덜 거쳤는지) — 코드 변경 없음, 실측 필요

### 하지 말 것

- "검출 모델을 붙였으니 공감지능"이라는 주장 — 사람 검출은 센싱이고, 공감은 이후의 배려 행동으로 증명한다.
- 데모 제안(이력 검사를 우회하는 리허설 경로)을 자연 학습으로 소개하기.
- 작은 LLM·얼굴 식별·감정 추정·새 모델 학습 확장.
- 화면을 검게 덮는 것을 소비전력 절감 실적으로 말하기(백라이트 절전·절감량 미측정).
- CT 종료를 조리 완료로, 가전 미사용을 건강 이상으로 단정하기.
- 습관이 만들어지는 며칠을 10분 안에 재현하기 — 실제로 쌓인 기록을 보인다. 부족하면 '학습 중'을 그대로 보인다.

### 심사 답변 틀(외부 모델 제안)

> 현재 습관 판단은 설명 가능한 규칙 기반입니다. 사용 기록으로 후보를 만들고, 사람이 있는 시점과 거절 의사를 반영해 묻습니다.
> 자동 실행은 별도로 허락한 범위에 제한합니다. 그 차이를 실제 기록과 행동 변화로 보여 드리겠습니다.

## 2. 출처별 요약

**LG — Adding a Human Touch to AI (공감지능 소개)** · https://www.lg.com/global/newsroom/lg-story/beyond-news/adding-a-human-touch-to-ai-lgs-affectionate-intelligence/
- CES 2024에서 AI를 '공감지능(Affectionate Intelligence)'으로 다시 정의. 기술보다 고객 일상이 나아지는 것을 앞세운다.
- 세 기둥: 실시간 생활 지능(생활 패턴 학습) · 조율 지능(필요 예측·기기 조율) · 책임 지능(책임성·안전·개인정보).
- **우리 쓰임:** 발표를 세 기둥에 맞춘다 — 습관 학습 = 생활 지능, 때맞춘 제안·기기 묶기 = 조율 지능, 허락한 것만 자동화·온디바이스·열 나는 가전은 늘 확인 = 책임 지능.

**LG — CES 2025 'A Day in a Life'** · https://www.lg.com/au/about-lg/press-and-media/lg-unveils-a-day-in-a-life-with-affectionate-intelligence-at-lg-world-premiere/
- 기기별 기능 대신 하루의 생활 장면으로 공감지능을 보여 준다. AI 에이전트가 상황을 알아채고 먼저 조치·제안한다.
- **우리 쓰임:** 시연을 '하루 흐름'으로 짠다. LG 시연은 먼저 실행하고 알리는 쪽, 우리는 먼저 묻고 믿음이 쌓이면 맡기는 쪽 — 차별점.

**Amershi 외, CHI 2019 — Guidelines for Human-AI Interaction** · https://www.microsoft.com/en-us/research/wp-content/uploads/2019/01/Guidelines-for-Human-AI-Interaction-camera-ready.pdf
- 인간-AI 상호작용 권고를 18개 가이드라인으로 정리하고 실무자 평가로 검증. 처음 / 상호작용 중 / 틀렸을 때 / 시간이 지나며 네 단계.
- 우리와 관계 깊은 항목: G3 맥락에 맞는 타이밍, G8·G9 쉬운 거절·수정, G11 이유 설명, G13 행동에서 학습, G16 결과 알리기, G17 전체 제어, G18 변경 알림.
- **우리 쓰임:** 18개 대비 체크표 한 장. G3(사람 감지로 말할 때 고르기)·G11(쓴 날 근거)·G17(카메라 끄기·자동 실행 끄기) 강조.

**Horvitz, CHI 1999 — Principles of Mixed-Initiative User Interfaces** · https://www.microsoft.com/en-us/research/publication/principles-mixed-initiative-user-interfaces/
- 시스템이 먼저 나설 때: 사용자 목표의 불확실성, 주의 상태에 맞춘 타이밍, 비용·이익을 따져 '실행 / 묻기 / 가만히'를 고른다. 불확실하면 묻는다.
- **우리 쓰임:** 단계적 맡기기(묻기 → 맡기기)의 근거. "확신이 없을 때 묻는 것이 잘못 짚었을 때의 손해가 가장 작다."

**Huang·Cakmak, UbiComp 2015 — 트리거-액션 규칙의 사용자 이해** · https://hcrlab.cs.washington.edu/publications/huang2015ubicomp/
- 사람들은 '사건'과 '상태' 트리거, 즉시·지속 동작을 서로 다르게 이해하고 끝나는 때를 잘못 짐작한다.
- **우리 쓰임:** 맡기기 확인 칸에 언제·무엇을·하지 않는 경우·끄는 곳을 함께 보인다.

**Ur 외, CHI 2014 — Practical Trigger-Action Programming in the Smart Home** · https://www.blaseur.com/papers/TriggerActionCHI14.pdf
- 사람들이 스마트홈에 바라는 동작의 상당수가 규칙(트리거-액션)형이고(조사에서 약 63%), 초보자도 규칙을 금방 익혔다.
- **우리 쓰임:** "규칙을 사용자가 짜게 하지 않고, 습관에서 규칙 초안을 뽑아 제안한다." 규칙 자체를 독창성으로 내세우지는 않는다.

**YOLOX (2021)** · https://arxiv.org/abs/2107.08430
- 앵커 없는 YOLO 계열 검출기. 여러 크기와 ONNX 등 배포 형식을 제공한다.
- **우리 쓰임:** 공개 사전학습 모델을 연결만 했다는 근거. **우리 실측:** RPi5 CPU에서 640×480 한 장 약 0.8초(10/25). 받은 모델은 Nano가 아닌 더 큰 크기(파일 약 36MB) — 발표에서 "Nano"라고 말하지 않는다.

**LG ThinQ API 공개 (2024-12)** · https://www.lg.com/global/newsroom/news/home-appliance-solution/lg-opens-thinq-api-to-foster-smart-home-innovation/
- ThinQ API를 개인·기업용으로 개방(원격 제어·상태 확인). 개발자 포털 https://smartsolution.developer.lge.com/ko/cloud/landing, Python SDK https://github.com/thinq-connect/pythinqconnect
- **우리 쓰임:** "LG 가전은 공식 API로, 버튼만 있는 옛 가전은 누름 장치로 같은 흐름에 묶는다."

## 3. 발표·질의응답 한 문장

1. "LG가 말한 책임 지능처럼, SimpleLay는 사용자가 허락한 일만 자동화합니다." (LG 공감지능)

4. "규칙을 사용자가 짜게 하지 않고, 실제 쓴 기록에서 초안을 뽑아 근거와 함께 보여 줍니다." (Ur 2014, Amershi G11)

아래처럼 **정해진 동작 목록 중 하나를 고르는 데만** 쓰고 실행은 늘 사람이 확인한다. 공개 모델을 그대로 쓰며 학습하지 않는다(지도교수 방침과 같은 선).

**질의응답 대비**
- "AI가 틀리면요?" → 목록 중 하나만 고르고, 확인 카드에서 사람이 '네'를 눌러야 실행. 모르면 0번(해당 없음).
- "왜 클라우드 LLM이 아니라요?" → 플랫폼 클라우드 에이전트는 사내망 전용이라 결선장에서 쓸 수 없고(10/25 재시험: 접속 오류), 집 안 말을 밖으로 보내지 않는 쪽이 사용자 이해에 맞다.
- "느리지 않나요?" → 보드 실측 가운데값 10초·90% 14초 안(고정 50문장, [평가](언어모델-평가-2026-10-26.md)), 그동안 '생각하고 있어요'. 규칙으로 알아듣는 말은 기다림 없이 바로.
- "집 밖에서는요?" → 지금은 집 안(같은 공유기)에서만 허브에 연결해 허브를 인터넷에 열지 않는다(집 안 기록·사람 감지 정보가 밖으로 나가지 않음 — 책임 지능).
