# 인계 2026-10-06 노트북 → 데스크톱 (2차)

데스크톱(RPi4·RPi5 LAN 연결)에서 순서대로. 단계마다 1커밋, 끝나면 5줄 보고. 1차 인계([인계-2026-10-06-노트북](인계-2026-10-06-노트북.md))는 끝났다.

## 사용자 결정 (10/6)
- **D4 인터폰 호출 감지 = 사람이 직접**(폰에서 지금 실행). 감지 코드는 만들지 않는다. 갭 문서 D4 행을 확정으로, L3(호출 감지) 행은 "시연에 불필요"로 표시.
- **git 이력에서 pptx 제거 = 한다.** 아래 0단계.
- ThinQ 가전: 팀원이 집에 있는지 확인 중. 그 전까지 모의 유지, 코드 작업 없음.

## 0. git 이력에서 발표 자료 제거 (가장 먼저, 다른 커밋 전에)
대상은 이력에 남은 `0818_임베디드.pptx` 하나다(10/6 확인. 작업 전에 `git -c core.quotepath=false log --all --format= --name-only | grep -iE "pptx|pdf|hwp|docx"`로 다시 확인하고, 더 나오면 같이 지운다).
1. 작업 트리 깨끗한지, 원격과 같은지 확인. 노트북 쪽은 이 작업 동안 push하지 않는다.
2. 백업: 저장소 밖에 `git clone --mirror` 한 벌.
3. `git filter-repo --invert-paths --path "0818_임베디드.pptx"` (없으면 `pip install git-filter-repo`). 로컬 pptx 원본 파일은 지우지 않는다.
4. 이력 grep으로 0건 확인, 백엔드 테스트·repo guard 통과 확인.
5. 원격 다시 붙이고 `git push --force origin main` (+ 다른 브랜치·태그가 있으면 같이).
6. 노트북·RPi 배포본 등 다른 클론은 `git fetch && git reset --hard origin/main`이 필요하다고 CLAUDE.md "현재 기준"에 한 줄 남긴다. 저장소는 지금 private·fork 0이다. GitHub 쪽 캐시가 남을 수 있으니 공개 전에 필요하면 GitHub 지원 요청을 고려한다고 적는다.

## 4. 보고서 그림 채우기
- 실패널(RPi5 키오스크 평소·다가오면·동작 중·내 가전, 비상정지 띠)과 폰(에뮬레이터 홈·루틴·기록·가전 추가·비상정지 배너)을 캡처한다. 모의 화면이면 캡션에 "모의 실행 화면"이라고 쓴다.
- 구조도(RPi5·RPi4·모션 MCU 미정·ESP32 콘센트 모듈)는 기존 README 구조도를 정리해서 쓴다.
- `docs/submission/` 초안의 【그림: …】 자리를 채우고 이미지는 `docs/submission/img/`에. 개인 정보·API 키·내부 주소가 화면에 안 보이는지 확인.

## 5. 보드 점검 "앱 권한" 칸
- RPi5·RPi4에서 board_probe를 root가 아닌 앱 계정으로 다시 실행해 "앱 권한" 칸을 채운다. 로컬 설정의 잘못된 인터페이스 지정도 고친다.
- 원본 결과·비공개 설정은 저장소 밖 로컬에만. 확인 못 한 건 미검증으로 둔다. `docs/가산점-증거-대장.md`는 일반 문장으로만 갱신.

## 6. UART 첫 연결 실패 시 기동 실패
- 지금은 백엔드 기동 때 첫 연결이 실패하면 기동 자체가 실패한다([uart-reconnect devlog](devlog_2026-10-06-uart-reconnect.md) 한계). 첫 연결도 같은 백오프로 재시도하고, 연결 전에는 실행을 거절·화면에는 "누름 장치 연결 안 됨"이 보이게.
- 회귀 테스트는 수정 전 코드에서 실패 확인 뒤 수리. 보드에서 RPi4 실행기를 끈 채 RPi5 백엔드를 띄웠다가 실행기를 켜서 자동으로 붙는지 확인.
