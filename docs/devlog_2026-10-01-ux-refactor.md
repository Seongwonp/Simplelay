# 사용 편의 리팩터링 — 2026-10-01

## 검증 환경

노트북의 Windows 애플리케이션 제어가 Flutter 테스트 실행 파일을 차단한다.
`flutter test`는 실행하지 않는다. 작성·수정한 위젯 테스트는 데스크톱에서 실행하고,
수정 전 코드에서 새 기대값이 실패하는지도 확인해야 한다. 골든 비교·갱신도 데스크톱에서 한다.
실제 가전·누름 장치·거리 가독성은 확인 전이다.

## R1 — 문구와 용어

- 용어표를 만들고 폰·키오스크의 허브·플러그·다음에·정지 표현을 맞췄다.
- 결과 문구에서 응답만 받은 상태와 눌림·동작 확인을 구분했다. 오류는 다음 행동을 안내한다.
- 온보딩에서 현재 없는 홈 버튼 안내와 자동 연결 단정을 지우고 허브 연결·루틴을 설명한다.
- 기존 결과·화면 테스트 기대값을 함께 수정하고 온보딩 회귀 위젯 테스트를 추가했다.
- 검증: 변경 Dart 파일 analyze 오류·경고 0건(기존 deprecated info 폰 2건·키오스크 1건). 저장소 가드 통과.
- 미확인: 위젯 실행·수정 전 실패 확인·골든·실기기 낭독 및 레이아웃.

## R2 — 연결 상태

- 인증이 필요한 `/status`로 연결을 확인한다. 401은 “허브 키가 필요해요”로 구분하고 키 변경 때 다시 확인한다.
- 키 선택 표기를 없애고 보기·숨기기 버튼을 추가했다.
- 자동 발견한 주소는 저장값과 분리해 세션에만 유지한다. 통신 실패 때 저장된 이름으로 다시 발견한다.
- 인증 거절·키 보기 위젯 테스트, 주소 재발견·저장값 보존 테스트를 추가하고 주소 저장 회귀 테스트를 새 확인 경로로 맞췄다.
- 검증: analyze 0건, 기존 서버 인증 pytest 25건 통과(서버 동작 변경 없음), 저장소 가드 통과.
- 미확인: 데스크톱 위젯 실행 및 수정 전 실패 확인, 실제 와이파이 주소 변경.

## R4 — 실행 결과

- 실행 상태를 시작 화면 위에 쌓아 뒤로 가기·닫기·확인이 원래 화면으로 돌아간다.
- 결과 하단에 확인 또는 다시 시도와 닫기를 둔다. 실패·안전 정지의 다시 시도는 시작한 화면으로 돌아가 사용자가 다시 승인한다. 미확인은 재실행을 권하지 않는다.
- 실행 중 정지는 고정 영역에 유지한다. 연결 유실 때는 기존 다시 확인 수단도 유지한다.
- 키오스크 성공 화면은 10초 유지하며 남은 초를 표시한다.
- 결과 행동·원래 화면 복귀·미확인 위젯 테스트를 추가하고 키오스크 카운트다운 기대값을 갱신했다.
- 검증: analyze 오류·경고 0건(폰 기존 info 2건), 저장소 가드 통과.
- 미확인: 데스크톱 위젯 실행·수정 전 실패 확인·실제 앱 경로 전환 및 골든.

## R5 — 입력 보호와 등록 이어가기

- 공통 PopScope로 가전 마법사·버튼판·루틴 편집·녹화의 저장 전 이탈을 확인한다.
- 종류를 고르면 이름을 채우되 사용자가 고친 이름은 유지한다. 정지·취소 후보가 하나일 때만 미리 선택하고 직접 바꿀 수 있다.
- 기존 허브 프레임 크기 조회·값이 없을 때만 묻는 흐름은 유지했다.
- 사진 없는 경로에 이름·방·종류를 넘기고 사진 단계를 다시 묻지 않는다.
- 홈에 가전별 남은 설정 수와 위치 맞추기·확인 주행 입구를 둔다. 기존 가전은 같은 id·버튼 id로 사진 매핑을 고치며 가전 정의를 재등록하지 않는다. 모의 주행은 실제 확인으로 세지 않는다.
- 위치 보정은 기존 사진 매핑 API를 일반 화면에서 다시 여는 방식이다. 개발자 전용 모터 미세 조그를 일반 사용자에게 여는 작업은 포함하지 않았다.
- 입력 유지·이탈 취소·기본 이름·사진 없는 전환·설정 카드 테스트를 추가하고 정지 버튼 자동 선택 및 등록 후 안내 기대값을 갱신했다.
- 검증: analyze 오류·경고 0건(info 1건), 저장소 가드 통과.
- 미확인: 데스크톱 위젯 실행·수정 전 실패 확인, 실물 위치·확인 주행. 실제 사진 재매핑과 루틴 저장 후 복귀도 데스크톱에서 확인한다.
