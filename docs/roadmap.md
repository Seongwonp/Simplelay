# 로드맵

> RPi 레이어(SimpleLay 신규 핵심) 중심. Act·Bridge(갠트리)는 Touch Bridge에서 재사용.

---

## 마일스톤

### M1 — 센서 읽기
- [ ] 보유 라즈베리파이에서 전류 센서 값 읽기 (ACS712 등 + ADC)
- [ ] 마이크로 버튼 클릭음/비프음 감지 (임계 또는 간단 FFT)
- [ ] "눌림 vs 안눌림"을 구분하는 최소 신호 확정 (실측 기반)

### M2 — RPi ↔ GRBL 통신
- [ ] RPi가 ESP32/Uno로 단일 버튼 누름 명령 전송
- [ ] GRBL `ok`/`error`/alarm 응답 수신·파싱
- [ ] 연결 방식 확정 (UART/Wi-Fi/BLE)

### M3 — 폐루프 ★ (결선 데모 핵심)
- [ ] 명령 → 센서 검증 → 실패 시 좌표 보정 후 재시도 (1회)
- [ ] 버튼 시퀀스 전체에 폐루프 적용
- [ ] **실패 유발 → 자동 복구 시연** 성공

### M4 — 공감지능
- [ ] 사용 로그 적재 (시간대·목적·결과)
- [ ] 반복 패턴 감지 → 다음 동작 선제 제안
- [ ] 제안 → 사용자 1회 승인 → 실행

### M5 — 앱 연동 + 로그
- [ ] 앱에 검증 결과/재시도 상태 표시
- [ ] 실행 이력·성공률 로그 조회

## 예선 심사평 대응 (결선 개발 항목)

| 심사평 지적 | 대응 | 담당 계층 |
| --- | --- | --- |
| 구동 전력·전원 관리 | 12V 별도 전원·퓨즈, 전력 버짓 문서화 (**미완 — 우선순위 높음**) | 하드웨어 |
| 가전별 버튼 맵 일반화 | 사진 매핑 → 좌표 프로필, 기기별 저장 | app / intent |
| 액추에이터 장착 안정성 | 3D 프레임 + 수직 마운트 + 스프링 완충 | 하드웨어 |
| 다이얼/누름 오차 보정 | **폐루프 재시도(검증 실패 시 보정)** | verifier / controller |

> "다이얼 오차 보정"은 폐루프(closed-loop-design.md)로 자연스럽게 커버된다.
