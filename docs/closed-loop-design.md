# 폐루프 검증 설계 (Closed-Loop Verification)

> SimpleLay의 기술적 차별점. "누르고 끝"이 아니라 "눌렸는지 확인하고 실패 시 재시도"까지.
> 라즈베리파이가 이 폐루프의 주체다.

---

## 문제

버튼을 물리적으로 누르는 장치는 "명령을 보냈다 ≠ 실제로 눌렸다"라는 근본 불확실성이 있다.

- 갠트리 좌표가 미세하게 어긋나 버튼을 헛누를 수 있다.
- 누르는 힘이 부족해 접점이 안 닿을 수 있다.
- 가전이 이미 다른 상태여서 입력이 무시될 수 있다.

명령만 보내고 끝내면 사용자는 "됐겠지"라고 믿을 수밖에 없다. **SimpleLay는 눌렀는지를
직접 확인한다.**

---

## 폐루프 흐름

```
목적 입력 ("우유 데워줘")
   │
   ▼
[intent] 의도 → 버튼 시퀀스 변환   (예: [해동] → [시간+90초] → [시작])
   │
   ▼
[controller] 시퀀스의 각 버튼에 대해:
   │
   ├─→ ① Arduino(X/Y 이동)·BLE 버튼 장치(Z 누름)에 "이동 후 누름" 명령 전송
   │
   ├─→ ② [verifier] 전류·음향 센서로 "이 버튼이 실제로 눌렸는가" 판정
   │        · 전류: 버튼 누름 순간 가전 회로의 전류 변화 감지
   │        · 음향: 버튼 클릭음 / 비프음 감지
   │
   ├─→ ③ 판정 결과
   │        · 성공 → 다음 버튼으로
   │        · 실패 → 재시도 (좌표 미세 보정 후 재누름, N회 한도)
   │
   └─→ ④ N회 실패 시 → 사용자에게 알림 + 로그 기록 + 안전 정지
```

---

## 검증 센서 (verifier) — 판정 방식 후보

> M1에서 실측으로 어느 신호가 신뢰도 높은지 결정한다. 처음부터 하나로 확정하지 않는다.

| 신호 | 감지 대상 | 장점 | 리스크 |
| --- | --- | --- | --- |
| 전류 (홀센서/ACS712 등) | 버튼 눌림 시 가전 회로 전류 변화 | 물리적으로 확실 | 가전마다 전류 패턴 다름 → 캘리브레이션 필요 |
| 음향 (마이크 + 임계/FFT) | 버튼 클릭음, 비프 응답음 | 비접촉, 범용 | 주변 소음에 취약 |
| 접점 프로브 | Z축 팁이 버튼면에 닿음 | 즉각·하드웨어 | "닿음"은 알아도 "입력 수용"은 모름 |

**권장 초기 전략:** 접점 프로브(닿음 확인) + 전류 또는 음향(수용 확인) 2단 판정.
닿기는 했는데 반응이 없으면 = 힘 부족/오정렬로 보고 재시도.

---

## 재시도 정책 (controller)

| 항목 | 기본값(초안) | 비고 |
| --- | --- | --- |
| 최대 재시도 | 3회 | 초과 시 사용자 알림 + 정지 |
| 재시도 전 보정 | Z 누름 깊이 +α, XY 미세 보정 | 오정렬/힘부족 대응 |
| 재시도 간격 | 가전 응답 대기 후 | 가전이 상태 갱신할 시간 확보 |
| 최종 실패 | 로그 + 앱 알림 + E-STOP 연계 | 무한 재시도 금지 |

## 안전 연계

폐루프는 [구동부 안전 설계](../firmware/README.md)와 연결된다.
검증 실패 재시도가 폭주하지 않도록:

- 재시도 횟수 하드 리밋 (controller)
- Z 누름 깊이 소프트 상한 (`pressDepthZ`, Arduino/BLE 버튼 장치 쪽 설정)
- 물리 E-STOP 최우선

---

## 결선 시연 시나리오

1. 정상 동작: "우유 데워줘" → 시퀀스 실행 → 센서 검증 → 성공 표시
2. **일부러 실패 유발** (버튼을 살짝 가리거나 좌표를 틀어둠) → 센서가 "안 눌림" 감지
   → 자동 보정 후 재시도 → 성공
3. 재시도도 실패 → 사용자 알림 + 안전 정지

> 2번이 핵심. 경쟁팀 대부분에 없는 "자가 검증 + 자동 복구"를 눈앞에서 보여주는 장면.

## M3까지의 구현 목표

- [ ] verifier: 최소 1개 센서로 "눌림/안눌림" 이진 판정 (M1)
- [ ] controller: 단일 버튼에 대해 명령 → 검증 → 1회 재시도 (M2~M3)
- [ ] 시퀀스 전체에 폐루프 적용 (M3)
- [ ] 실패 유발 → 자동 복구 시연 성공 (M3)
