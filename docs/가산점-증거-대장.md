# 가산점 증거 대장

2026-10-01. 데스크톱 실측 전 빈 양식이다. **아래 행은 성공 증거가 아니다.**
기준은 [본선 실행계획 §6](본선-실행계획-2026-09-30.md#6-결선-배점과-보드-역할-2026-09-30-부문-세부-안내사항-v6)에 정리한 공식 안내다.
완성도 60·독창성 20·활용성 20, 가산점은 각 5점·최대 10점이다.

| 공식 가산점 문구(실행계획 §6 기준) | 대응 증거 | 미결 조건 |
|---|---|---|
| (1) LG 제공 임베디드 SW 플랫폼 기반으로 하드웨어 3종 연동 | 보드별 앱 계정의 API 최소 호출 + 실제 시연 흐름에서 세 보드 연동 | **대체 근거(팀 확정, 2026-10-05):** 안내 예시의 RPi Zero 자리를 RPi4가 맡는다(역할 매핑은 아래). **실제 3종 연동 증거:** 현재 모의·미측정 — RPi5↔RPi4는 LAN 위 모의 모션까지, ESP32 콘센트 모듈은 펌웨어 컴파일까지이며 세 보드가 한 흐름에서 함께 동작한 기록은 없다. 남은 조건은 보드별 최소 호출과 실제 시연 연동 기록 |
| (2) 멀티모달 확장성: 음성·영상·조도 등 다중 센서를 융합해 상황 인지 정확도를 높인다 | 입력별 최소 호출 + 복수 입력이 하나의 상황 판단·제안에 기여하는 시연 | 센서가 존재하거나 API 한 번 성공한 것만으로 융합 효과를 입증하지 않음 |

보드 수를 늘린 것만으로 가산점 인정을 확정하지 않는다. 역할은 RPi5(해석·제안·키오스크),
RPi4(실행 관리·검증), ESP32(CT 전력·릴레이 비상정지), 모션 MCU(Uno 또는 ESP32 — 팀원 코드 수령 후 확정, CoreXY A/B·시간 기반 Z)로 구분한다.
API 최소 호출 성공과 실제 시연 사용은 **별개의 증거**다. root 호출 성공은 앱 계정 권한 증거가 아니다.

- **대체 근거(역할 매핑, 팀 확정):** 안내 예시의 RPi Zero 자리 = RPi4(실행 관리·검증·정지, RPi5에서 실행을 위임받고 모션 MCU·ESP32 콘센트 모듈과 연결). 이것은 보드 구성의 설명이지 연동 증거가 아니다.
- **실제 3종 연동 증거(현재 모의/미측정):** RPi5↔RPi4 LAN 통신과 폰(에뮬레이터)→RPi5→RPi4 실행은 **모의 모션**으로만 확인했다. ESP32 콘센트 모듈은 펌웨어 컴파일까지이고 실물 연결·CT 측정은 없다. 아래 표의 (1) 행이 채워지기 전에는 3종 연동을 확인했다고 쓰지 않는다.

## 실측 기록 — 실행 전 빈칸 유지

**2026-10-06 보드 점검(읽기 전용 기본 모드) 메모 — 위 표의 성공 증거가 아니다.**
- 점검은 RPi5 백엔드 컨테이너와 RPi4 실행기 컨테이너에서 돌렸다. 둘 다 실제로 root로 돈다. 이 결과는 앱 계정 권한 증거로 쓰지 않는다.
- 키오스크 앱 계정과 같은 UID로 다시 돌렸다.
  - 파이썬 모듈과 로컬 웹 호출은 앱 권한까지 성공했다.
  - 플랫폼 시스템 서비스 최소 호출은 접근 거절이었다. 실행한 프로세스에 앱 보안 레이블이 없었으니(`unconfined`) 실제 앱의 권한과 같은 조건이 아니다. 그래서 **앱 계정 권한은 미검증**으로 둔다.
- 플랫폼 기능 서비스(해석·제안, 음성, 영상 등)의 최소 호출은 이번 점검 대상이 아니었다. 계속 미측정이다.

**2026-10-07 보드 점검 메모(앱 계정 재실행) — 플랫폼 시스템 서비스 최소 호출 1건 성공, 조건부.**
- RPi5에서 키오스크 앱 계정과 같은 UID로 플랫폼 시스템 서비스(시간 정보) **읽기 메서드 1건을 호출했고 성공**했다(2026-10-07 12:22 UTC). 결과 파일은 로컬 비공개 사본에만 둔다.
  - 한계 ①: 호출한 프로세스의 보안 레이블은 실제 앱과 달랐다(`unconfined`). 확인 범위는 같은 UID의 별도 프로세스에서 특정 공개 읽기 메서드 호출 1건 성공(조건부)이며, 실제 앱 문맥 호출은 미검증이다.
  - 한계 ②: 앱 계정에 허용되지 않은 다른 시스템 서비스 2건은 접근 거절이었다(정상 동작).
- 앱을 다시 설치하면 앱 계정 UID가 바뀐다(10/7 확인). 점검 설정의 계정은 설치할 때마다 다시 확인한다.
