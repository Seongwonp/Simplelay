# SimpleLay 개발 현황

> 제24회 임베디드SW경진대회 결선 — 자비스 팀
> 최종 업데이트: 2026-09-16 — 보정 저장 게이트·L3 기준선·사진 전송 동의 수리
> **표기 원칙: "코드 완료"와 "실기기 검증 완료"를 구분해서 적는다.** 심사 질의에서
> 가장 위험한 것은 배선 안 된 것을 완성이라 부르는 것이므로, 이 문서는 실제 배선
> 기준으로만 기술한다. 실행 계획·체크리스트는 [결선로드맵.md](결선로드맵.md) 참고.

## 1. 프로젝트 개요

기존(비스마트) 가전에 **AI 제어 레이어를 얹는** 장치. 가전을 바꾸지 않고 버튼 위에
물리 액추에이터를 부착해, 음성 명령 · 패턴 학습(공감지능) · 선제 제안으로 동작시킨다.

**핵심 루프**: Sense → Interpret → Act + **폐루프 검증** — 버튼이 실제로 눌렸는지
전류·음향 센서로 확인하고, 실패하면 좌표 보정 후 스스로 재시도한다.
(2026-09-16 기준 이 루프는 **모의 구동·모의 센서 위에서만** 돌았다. 실제 모터·센서
검증은 하드웨어 도착 후다 — §3의 실기기 검증 열을 함께 본다.)

**공간 지능 관점(결선 방향)**: 단일 가전 제어가 아니라, IR 리모컨으로도 안 되는
구형·물리버튼 가전들을 공간 지능에 편입시키는 레이어다 — 가전마다 붙는 노드
(ESP32→RPi4), 시간대·온습도·사용 패턴·존재(presence) 맥락, 위험소리 감지가 그 근거.

## 2. 시스템 아키텍처

```
Flutter 폰 앱 (Android)          Flutter 키오스크 (RPi5 15" 터치 패널, 실기기 미검증)
  음성 STT → job 제출              대기/제안/실행/완료 4단계 + 수동 조작
  실행 상태 /status 폴링           SSE 즉시 경보 + /status 폴링
  실행 기록 타임라인               TTS 음성 안내 · 큰 글씨 모드
        │ HTTP (X-API-Key 옵션)         │ localhost (키 면제)
        ▼                               ▼
┌──────────────────────────────────────────────────────┐
│ INTERPRET — RPi5 · FastAPI :8000                     │
│  비동기 job 모델: 접수 즉시 job_id, 실행은 백그라운드 │
│  의도 해석 3계층: 규칙(별칭·정규화) → 벡터DB(dbus) → LLM │
│  패턴 학습(SQLite) → 60초 주기 선제 제안 생성          │
│  presence 게이트(부재 중 자동 제안 보류, 옵션)          │
│  SSE /events (경보·상태 변화 즉시 푸시)                │
│  실행 이력 /history · 리허설 실패 주입 /demo/*         │
└──────────────┬───────────────────────────────────────┘
               │ HTTP → ESP32 노드(가전마다) → UART → RPi4
               ▼
┌──────────────────────────────────────────────────────┐
│ ACT — RPi4                                            │
│  폐루프: 누름 → 센서 검증 → 실패 시 보정 재시도        │
│  UART abort → 협조적 정지(버튼 사이·재시도 경계)       │
│  SensorVerifier(전류+음향 퓨전) · DangerSoundMonitor   │
│   — env 게이트, 실기기 캘리브레이션 대기               │
└──────────────┬───────────────────────────────────────┘
               │ GPIO/시리얼 (실물 어댑터는 HW 통합 주차)
               ▼
   CoreXY 갠트리(제작 중) + Z축(SwitchBot 모터 재사용)
```

## 4. API (RPi5 :8000)

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/health` | 연결·actuator·DND (키 없이 개방 — 연결 확인용) |
| GET | `/sensors` | 온습도 (+`mocked` 플래그) |
| GET | `/status` | 실행 상태 — `job_id`/`last_job_id`/`total_steps`/진행 필드 |
| POST | `/execute` · `/execute-buttons` · `/execute-for-appliance` | **접수 즉시 `{job_id, "accepted"}`** — 완료는 /status 대조 |
| POST | `/stop` | 긴급 정지 — `{ok, was_running}` |
| GET | `/events` | **SSE** — alert·status 변화 즉시 푸시 |
| GET | `/history?limit=` | 실행 이력(재시도 횟수 포함, 최신순) |
| GET/POST | `/presence` | 공간 존재 조회/보고 (감지기용) |
| GET | `/alerts` | 위험소리 최신 스냅샷 |
| GET/POST/DELETE | `/suggestions`… | 제안 목록/승인(job 접수)/거부 |
| POST/DELETE | `/dnd` | 방해 금지 |
| GET/POST/DELETE | `/nodes`… | 가전별 ESP32 노드 등록 |
| POST/DELETE | `/demo/suggest` · `/demo/inject-failure` | 리허설: 제안 강제 생성(`appliance_id` 기본 microwave — 등록 안 된 대상은 404, 대상 없는 제안은 승인이 409) / 검증 실패 주입 |
| POST | `/demo/environment` | 리허설: 온습도 강제 주입 → 환경 제안 생성 |
| GET | `/history.csv` | 실험 기록 내보내기 (허용 목록 열만) |
| POST | `/readiness/{id}` | 노드가 자기 준비 상태를 보고 (전송·모션·센서·보정) |
| PUT | `/appliances/{id}/calibration` | 기준점으로 변환을 구해 버튼 mm 저장 — 검증 실패 422(저장 없음), 판 번호 충돌 409 |
| POST/GET | `/presence/distance` · `/presence/arriving` · `/presence/state` | 공간·노드 전원 상태 머신 관측/조회 — 동작 어휘만 돌려주고 실행은 노드 몫. 기존 `/presence`와 별개 |
| POST | `/panel-scan` | 조작부 사진(base64) → 버튼맵 초안(저장 없음). 꺼짐 503 · 사진 형식/크기 422 · 인식 중 409 · 시간당 상한 초과 429 · 크레딧·한도·연결 503 · 인증·서비스 오류·응답 1 MB 초과 502. `reference_points`를 주면 mm 포함 |
| GET/POST | `/suppressions`… | '다시 추천 안 함' 목록 / 해제 |
| GET/POST | `/dev/state` · `/dev/sessions`… · `/dev/stop` · `/dev/log` | 개발자 모드(모의 전용) — `X-Dev-Token` 필요. 세션 비밀값(`X-Dev-Session-Secret`)·빈도 제한·오류 code 계약은 `rpi/api/dev_router.py` 머리말 |

라우터 전체에 `X-API-Key` 옵션 인증(`SIMPLELAY_API_KEY`) — 루프백(키오스크) 면제.

## 5. 환경 변수

| 변수 | 기본 | 설명 |
|---|---|---|
| `SIMPLELAY_DB_PATH` | (없음=인메모리) | SQLite 경로 — 이력·노드 영속화 |
| `SIMPLELAY_API_KEY` | (없음=개방) | 실행 API 인증 키 |
| `SIMPLELAY_ACT_MODE` | local | `uart` = RPi4 실연결 |
| `SIMPLELAY_SENSORS_ENABLED` | false | RPi4 실센서 퓨전 검증 |
| `SIMPLELAY_DANGER_SOUND_ENABLED` | false | RPi4 위험소리 상시 감지 |
| `SIMPLELAY_PRESENCE_GATING` | false | 부재 중 자동 제안 보류 |
| `SIMPLELAY_GPIO_ENABLED` / `_DHT22_GPIO` / `_HOME_*_GPIO` | false / 4 / 17·27 | DHT22·홈스위치 |
| `SIMPLELAY_LLM_MODE` / `_LLM_BASE_URL` 등 | (없음) | `dbus`=온디바이스 / HTTP LLM |
| `SIMPLELAY_DBUS_CLI` / `_DBUS_*_SERVICE` | (없음) | 기기 D-Bus 서비스 주소 — `dbus` 모드 시 필수(없으면 기동 실패) |

| `SIMPLELAY_LOCAL_APPLIANCES` | (없음) | 로컬 갠트리에 **의도적으로** 물린 커스텀 가전 id(쉼표). 밝히지 않은 노드 없는 커스텀 가전은 실행이 412로 거절된다 |
| `SIMPLELAY_DEV_MODE` | false | 개발자 모드(**mock 어댑터 강제**). 꺼져 있으면 `/dev/*` 전부 404. 세션이 열리면 일반 실행은 409, /stop·물리 E-STOP이 세션도 함께 정지 |
| `SIMPLELAY_DEV_TOKEN` | (없음) | 개발자 API 토큰(16자 이상) — 일반 API 키와 **별개 권한**, 루프백 면제 없음. 개발자 모드가 켜져 있어도 없으면 `/dev/*`가 503(fail closed) |
| `SIMPLELAY_GATEWAY_PORT` / `_BAUD` | (없음) / 115200 | ESP-NOW 게이트웨이 ESP32 시리얼 포트 |
| `SIMPLELAY_UART_PORT` / `_UART_BAUD` | /dev/ttyAMA0 / 115200 | RPi4 UART |
| `SIMPLELAY_VISION_BASE_URL` / `_API_KEY` / `_MODEL` | (없음=꺼짐) | 조작부 사진 인식(OpenAI 호환 Chat Completions). **셋 다 있어야 켜진다.** 키는 서버 환경에만 |
| `SIMPLELAY_VISION_TIMEOUT_SECONDS` | 60 | 인식 요청 제한시간(0 초과 300 이하, 아니면 60) |
| `SIMPLELAY_VISION_MAX_PER_HOUR` | 20 | 인식 서비스로 보내려 한 시도의 시간당 상한(연결 실패 포함). 넘으면 429. **0이면 끔(503)**, 음수·잘못된 값은 20 |
