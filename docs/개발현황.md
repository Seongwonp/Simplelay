> 제24회 임베디드SW경진대회 결선 — 자비스 팀  
> 최종 업데이트: 2026-08-19

---

## 1. 프로젝트 개요

기존 가전에 **AI 제어 레이어를 씌우는** 장치.  
가전을 바꾸지 않고 버튼 위에 물리적 액추에이터를 얹어, 음성 명령 · 패턴 학습 · 선제 제안으로 동작시킨다.

**핵심 루프**: Sense → Interpret → Act + 폐루프 검증  
버튼을 눌렀는지 전류·음향 센서로 실시간 확인하고, 실패하면 좌표 보정 후 재시도.

### 다중 노드 아키텍처 (2026-08-17 확정)

기존: RPi5 ─── UART ───▶ RPi4 (단일 경로)  
신규: RPi5 ─── HTTP ───▶ ESP32 ─── UART ───▶ RPi4 (가전마다 분산)

`NodeRegistry(appliance_id → EspNodeController)` 가 라우팅을 담당.  
등록 없는 요청은 로컬 기본 컨트롤러로 fallback (하위호환 유지).  
ESP-NOW 전환 시 controller_factory만 교체 — 나머지 코드 변경 없음.

## 3. Flutter 폰 앱 (`app/`) — 완성

**플랫폼**: Android (예솔이 Galaxy), iOS 빌드 준비  
**상태 관리**: Riverpod (StateNotifierProvider, StreamProvider.autoDispose)  
**라우팅**: go_router  
**기본 서버 URL**: `http://simplelay.local:8000` (mDNS 자동 연결, SharedPrefs)

### 화면

| 화면 | 주요 기능 |
|------|-----------|
| 온보딩 | 최초 실행 1회, 자동 연결 안내, `onboarding_done` prefs 기록 |
| 홈 | 온습도 스트립, DND 배너, RPi 연결 카드, 선제 제안 목록 |
| 음성 | STT → POST /execute, 파형 비주얼라이저 |
| 제안 확인 | 버튼 맵 그리드(가전별 레이아웃 시각화), 단계 타임라인 |
| 실행 상태 | 단계 체크리스트, 전류·음향 바차트, 긴급 정지 |
| 설정 | 가전 선택, ESP32 노드 등록(가전별 IP), RPi 연결, BLE, 고급 |

### 주요 Provider

| Provider | 역할 |
|----------|------|
| `rpiUrlProvider` | 서버 URL (simplelay.local 기본값 자동 저장) |
| `rpiConnectionProvider` | ping 상태 (unconfigured/checking/connected/unreachable) |
| `sensorProvider` | 온습도 60초 폴링 (StreamProvider.autoDispose) |
| `dndProvider` | DND 상태 (set/clear, /health 기반) |
| `nodeRegistryProvider` | ESP32 노드 목록 (FutureProvider.autoDispose) |
| `selectedApplianceProvider` | 선택된 가전 (SharedPrefs) |

### API (`services/rpi_api_service.dart`)

```
ping(), health(), sensors()
setDnd(minutes), clearDnd()
execute(text), executeButtons(buttons)
executeForAppliance(text, knownButtons)
status(), stop()
suggestions(), approveSuggestion(id), rejectSuggestion(id)
listNodes(), registerNode(applianceId, baseUrl), unregisterNode(applianceId)
```

## 4. Flutter 키오스크 앱 (`rpi5-touchscreen-app/`) — 완성

**플랫폼**: RPi5 7인치 터치스크린 (800×480, 다크 테마)  
**서버**: localhost:8000 (로컬 직통, mDNS 불필요)

### 화면 4단계

| 단계 | 진입 조건 | 표시 내용 |
|------|-----------|-----------|
| 대기 (idle) | 기본 | 날짜·온습도·시계, 상태 dot 2개 (actuator·backend) |
| 제안 (suggestion) | 서버 polling | 제안 내용, 10초 카운트다운, 승인/거부 |
| 실행 중 (executing) | 승인 또는 수동 실행 | 진행 바, 현재 버튼·재시도 횟수, 정지 버튼 |
| 완료 (done) | 실행 완료 | 성공/실패 아이콘, 3초 후 idle 복귀 |

### 제스처

| 제스처 | 동작 |
|--------|------|
| 화면 탭 | 수동 버튼 조작 화면 |
| 화면 롱프레스 | DND 오버레이 |
| 우하단 dot 3탭 | **관리자 설정 오버레이** (가전 전환 + ESP32 IP 등록) |

### API (`services/kiosk_api_service.dart`)

```
checkHealth(), sensors(), alerts()
setDnd(minutes), clearDnd()
suggestions(), status()
executeButtons(buttons, applianceId?)
approveSuggestion(id), rejectSuggestion(id), stop()
listNodes(), registerNode(applianceId, baseUrl), unregisterNode(applianceId)
```

## 5. RPi5 Python 서버 (`rpi/`) — 완성 + 실환경 준비

**엔트리포인트**: `rpi/main.py`  
**포트**: 8000  
**mDNS**: avahi-daemon → `simplelay.local`  
**배포**: `scripts/setup_rpi.sh` 원클릭 설치  

### API 엔드포인트

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/health` | 연결 확인 + actuator_ready + DND 상태 |
| GET | `/sensors` | 온습도 (DHT22 실연결 또는 mock fallback) |
| GET | `/alerts` | 위험소리 alert 최신 스냅샷 |
| POST | `/dnd` | DND 설정 |
| DELETE | `/dnd` | DND 해제 |
| POST | `/execute` | 자연어 → 버튼 시퀀스 실행 |
| POST | `/execute-buttons` | 버튼 시퀀스 직접 실행 |
| POST | `/execute-for-appliance` | 사용자 정의 가전 음성 명령 (LLM 필요) |
| GET | `/status` | 실행 상태 조회 |
| POST | `/stop` | 긴급 정지 |
| GET | `/suggestions` | 선제 제안 목록 |
| POST | `/suggestions/{id}/approve` | 제안 승인 |
| POST | `/suggestions/{id}/reject` | 제안 거부 |
| GET | `/nodes` | 노드 목록 |
| POST | `/nodes/{appliance_id}` | 노드 등록/교체 |
| DELETE | `/nodes/{appliance_id}` | 노드 해제 |

### 환경 변수 (`rpi/api/config.py`)

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `SIMPLELAY_GPIO_ENABLED` | false | true = 실기기 GPIO 읽기 |
| `SIMPLELAY_DHT22_GPIO` | 4 | DHT22 데이터 핀 BCM |
| `SIMPLELAY_HOME_X_GPIO` | 17 | CoreXY X축 홈 스위치 BCM |
| `SIMPLELAY_HOME_Y_GPIO` | 27 | CoreXY Y축 홈 스위치 BCM |
| `SIMPLELAY_HOME_Z_GPIO` | (없음) | Z축 홈 스위치 BCM (선택) |
| `SIMPLELAY_LLM_MODE` | (없음) | `dbus` = 온디바이스 internal_ai |
| `SIMPLELAY_LLM_BASE_URL` | (없음) | OpenAI 호환 엔드포인트 |
| `SIMPLELAY_ACT_MODE` | local | `uart` = RPi4 UART 실연결 |

### 의도 해석 계층

1. **VectordbIntentResolver** — 온디바이스 벡터DB 유사도 (빠름, 오프라인)
2. **RuleBasedIntentResolver** — 정확 일치 규칙 폴백
3. **LlmIntentResolver** — OpenAI 호환 또는 internal_ai D-Bus (느리지만 유연)

### 센서 퓨전 검증 (`rpi/verifier/`)

```
current_weight: 0.7  (전류 신호 우선)
audio_weight:   0.3
confidence_threshold: 0.5

전류✅ 음향✅ → pressed=True,  confidence=1.0
전류✅ 음향❌ → pressed=True,  confidence=0.7
전류❌ 음향✅ → pressed=True,  confidence=0.6
전류❌ 음향❌ → pressed=False, confidence=0.0
```

## 6. ESP32 펌웨어 (`firmware-node/`) — 스캐폴딩 완성

**환경**: PlatformIO, ESP32  
**역할**: RPi5의 HTTP 명령을 UART로 RPi4에 전달 (HTTP↔UART 브리지)

```
POST /execute  →  UART send  →  RPi4  →  UART recv  →  HTTP 응답
GET /alerts    →  alertActive 상태 반환
```

| 설정 | 값 |
|------|----|
| WiFi | `config.h`의 WIFI_SSID/PASSWORD (배포 시 교체) |
| HTTP 포트 | 8080 |
| UART 보드레이트 | 115200 |
| UART RX/TX 핀 | GPIO 16 / 17 |
| 응답 타임아웃 | 30초 |

## 7. 하드웨어 현황

| 부품 | 용도 | 상태 |
|------|------|------|
| RPi 5 8GB | INTERPRET + 키오스크 UI | **보유** |
| RPi 4 4GB | ACT (폐루프 제어) | **보유** |
| ESP32 ×3 | 노드 브리지 | **보유** |
| Arduino Nano | CoreXY PID 제어 | **보유** |
| JMOD-MOTOR-1 (TB6612FNG) | CoreXY 모터 드라이버 | **보유** |
| FIT0482 DC 기어드 모터 ×2 | CoreXY XY축 | **조달 예정** |
| SwitchBot 내부 DC 모터 | Z축 (분리 완료) | **보유** |
| Arduino Nano + 모터쉴드 | Z축 드라이버 | **보유** |
| ACS712 전류 센서 | 버튼 눌림 검증 | **조달 예정** |
| 마이크 모듈 | 음향 검증 + 경보 감지 | **조달 예정** |
| DHT22 | 온습도 센서 | **조달 예정** |
| 7인치 터치스크린 | RPi5 키오스크 | **보유** |

### CoreXY 주의사항

GRBL 사용 불가 (DC 기어드 모터 호환 없음).  
커스텀 Arduino PID + **좌표 믹싱 필수**:

```
모터 A 펄스 = X + Y
모터 B 펄스 = X - Y
```

이걸 빠뜨리면 대각선 이동 시 경로 드리프트 발생.

## 8. 배포 및 실환경 설정

### RPi5 원클릭 설치

```bash
git clone https://github.com/Seongwonp/Simplelay.git
cd Simplelay
sudo ./scripts/setup_rpi.sh
```

설치 내용:
- hostname → `simplelay` (avahi-daemon → `simplelay.local:8000` mDNS)
- Python venv + 프로젝트 + GPIO 패키지 (`adafruit-circuitpython-dht`, `lgpio`, `gpiozero`)
- systemd 서비스 (`/etc/systemd/system/simplelay.service`) 자동 등록

### 실기기 전환 시 변경 사항

`/etc/systemd/system/simplelay.service` 수정 후 `sudo systemctl restart simplelay`:

```ini
Environment=SIMPLELAY_GPIO_ENABLED=true     # DHT22 + 홈 스위치 활성
Environment=SIMPLELAY_DHT22_GPIO=4          # DHT22 데이터 핀
Environment=SIMPLELAY_HOME_X_GPIO=17        # X축 홈 스위치
Environment=SIMPLELAY_HOME_Y_GPIO=27        # Y축 홈 스위치
Environment=SIMPLELAY_ACT_MODE=uart         # RPi4 UART 실연결
```
