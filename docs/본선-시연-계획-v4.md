## 1. 장면 대본

### ① 제안 거절 (0:00–0:20)

- 제안 카드가 뜬다(사용자 루틴 또는 습관 근거). 발표자가 "안 할래요"를 누른다.
- 보일 것: 장치는 움직이지 않는다. 이후 같은 조건에서 자동 실행도 일어나지 않는다(허용한 적이 없으므로).
- 말할 것: "승인하지 않으면 누르지 않습니다. 거절한 제안이 나중에 몰래 실행되지도 않습니다."

### ② 첫 조리 승인 → 공기청정기 + "다음부터 자동으로" (0:20–2:40)

1. 전자레인지 조리 제안을 승인한다. **가열은 짧게(예: 30초).**
2. CoreXY 갠트리가 버튼을 실제로 누른다(솔레노이드 Z). 화면은 누름 확인(L1)을 보인다.
3. 콘센트 모듈 CT가 가열 시작을 확인한다(L3). 30초 뒤 **조리 완료는 CT 판정으로만** 확인한다 — 버튼 누름 완료는 조리 완료가 아니다.
4. 완료가 확인되면 공기청정기 강풍 제안이 뜬다. 발표자가 "다음부터도 자동으로"를 고르면 확인 화면이 나온다:
   조건(전자레인지 조리 완료가 확인됐을 때)·대상(거실 공기청정기)·동작(풍량 강) → "허용하고 이번에도 실행".
5. ThinQ로 강풍 명령 → 상태 재조회로 바뀐 것을 확인한 뒤에만 "공기청정기 풍량을 바꿨어요"라고 표시한다.
- 말할 것: "공기청정기는 식사 뒤에 켜 두는 사용자 습관으로 설명드립니다. 풍량을 바꾼 것이지 공기가 깨끗해졌다고 확인한 것은 아닙니다."

### ③ 같은 조건에서 다시 (2:40–4:20)

1. 준비 동작: 공기청정기를 약풍으로 되돌린다. 발표자: "같은 조건에서 다시 자동으로 바뀌는지 보겠습니다."
2. 두 번째 조리를 승인한다(조리 자체는 매번 승인 — 물리 버튼 누름은 자동 실행 대상이 아니다).
3. 완료 확인 → **추가 승인 없이** 공기청정기 강풍 변경 → 상태 재조회로 '변경 성공'.

### ④ 기록 확인 → 자동 실행 끄기 (4:20–4:50)

- 기록 탭에서 전자레인지(누름·가열 시작·완료)와 공기청정기(변경 성공) 결과를 각각 보인다.
- 루틴 목록에서 자동 실행을 끈다. "언제든 끌 수 있고, 조건이 바뀌면 다시 허용을 받습니다."

### ⑤ 일부 실패 처리 (4:50–5:20)

- 사전 녹화 영상 또는 준비된 기록으로 설명한다. 예: 공기청정기 명령은 보냈지만 상태 재조회가 실패한 경우 → '결과 확인 불가'로 남고 자동으로 다시 보내지 않는다.
- 대본에 결과 문구를 미리 고정하지 않는다 — 그날 실제로 얻은 근거대로 읽는다(§4).

## 3. 선행 조건 (우선순위)

1. **CoreXY 실제 누름** — 레일 조정 → 방향 시험 → `G` 폐루프 → `H` 원점 → 솔레노이드로 전자레인지 버튼 누름. 기록은 [실측 기록표](실측-기록표.md) §4 성공률.
2. **CT 조리 시작·완료 판정 실측** — 짧은 가열(30초) 정상, **가열 중 전력 감소**(출력 조절로 전력이 내려가는 구간), **중간 취소**, **종료 후 팬 동작**을 완료로 오판하지 않는지까지. 기록은 [실측 기록표](실측-기록표.md) §6.
   이 조건을 못 맞추면 자동 실행 조건(조리 완료)을 다시 설계한다 — 버튼 누름 완료로 대신하지 않는다.
3. **공기청정기 ThinQ 실물 제어 + 대회장 인터넷** — 여행용 공유기 + 핫스팟. 실가전 도착 날 [ThinQ 실물 확인 절차](ThinQ-실물-확인-절차.md). 인터넷이 안 되면 모의 클라우드 대비 모드로 돌리고 "오늘은 모의 클라우드입니다"라고 먼저 말한다.
4. **자동 실행 규칙 구현** — 조리 완료(확인된 사건) → 공기청정기 풍량 변경 하나만. 사용자가 고를 때만 켜지고, 물리 누름 단계는 자동 대상이 아니며, 같은 사건에 한 번만, 결과 미확인이면 다시 보내지 않는다.

## 4. 원칙

**장애 결과 문구를 대본에 고정하지 않는다.** 실제 얻은 근거대로 읽는다.

| 상황 | 표시 |
|---|---|
| 보내기 전에 연결 불가 | 명령을 보내지 못함 |
| 접수됐지만 상태를 확인하지 못함 | 결과 확인 불가 |
| 상태 재조회로 바뀐 것을 확인 | 변경 성공 |

- **버튼 누름 완료 ≠ 조리 완료.** 조리 완료는 CT 판정으로만 말한다.
- **풍량 변경 ≠ 공기가 깨끗함.** 공기청정기는 사용자의 식사 후 습관으로 설명한다.
- **가열 시간은 짧게**(예: 30초). 빈 상태 가열 금지 등 런북 안전 체크리스트를 따른다([결선 운영 런북](결선-운영-런북.md)).
- 모의 표시("모의 실행 · 실제 조작 아님")를 가리지 않는다. 서버가 보고하지 않은 성공을 말로 만들지 않는다.

## 6. 무대 배치 — 함께 맞출 항목

- 책상 150×55cm ×2: 전자레인지 + CoreXY 갠트리 + 콘센트 모듈을 한 책상, 공기청정기를 관객이 풍량 변화를 볼 수 있는 자리에.
- 키오스크 패널과 폰 화면(미러링)이 관객 쪽을 향하게.
- 여행용 공유기 + 핫스팟(ThinQ 클라우드용), RPi5·RPi4 같은 망.
- 사전 녹화 영상(⑤·백업)과 노트북 모의 서버를 1분 안에 전환할 수 있게.
