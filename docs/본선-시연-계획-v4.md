## 1. 장면별 운영 메모

### ① 다가가면 화면이 깸

- 시작 전 키오스크가 자리 비움 시계 화면이어야 한다. 사람 감지는 '언제 말을 걸지'에만 쓴다 — 실행·승인의 근거가 아니다. 오래 비웠다 온 인사는 3시간이 넘어야 나와서 결선장에서는 보이지 않는다(말로만).
- 지금 RPi5 env에 촬영용 시험값(사람 감지 5·10·30초)이 있다. 결선 때 둘지 되돌릴지는 사용자 결정 — 둔다면 위 표대로 연출이라고 말한다.
- 심사위원이 카메라 앞을 지나가도 화면이 깬다. 관객 쪽을 덜 보도록 각도를 리허설에서 맞춘다.

### ② 말 알아듣기

- 폰에서 말하고, 본체 안 언어 모델이 정해진 동작 목록 가운데 하나만 고른다. 실행은 사람이 '네'를 눌러야 한다. 기다리는 동안 '생각하고 있어요'.
- 숫자는 "보드 실측 8~12초, 시험 문장 8개"까지만 말한다. 정확도라고 말하지 않는다.
- 공기청정기는 상태를 다시 읽어 바뀐 것을 확인한 뒤에만 '됐어요'다(§4). 장면 뒤 서예솔이 공기청정기를 꺼서 ③을 위해 되돌린다.

### ③④ 습관 카드와 맡기기

- 습관은 같은 시간대에 서로 다른 3일·3번 쓴 실제 기록에서만 나온다. 평일·주말 습관은 그날 종류에만 묻는다. 가짜 기록으로 습관을 만들지 않는다.
- 연습 카드를 쓰면 화면의 '제안 · 시연 데이터' 표시를 가리지 않는다. 연습 카드를 맡겨 생긴 루틴은 시연 뒤 지운다(§9 절차).
- 맡기기 확인 칸은 화면 글자 그대로 읽는다. "자주 '네'를 눌러도 저절로 맡기지 않습니다"를 꼭 말한다.

### ⑥ 거절

- '이미 했어요'는 그날 다시 묻지 않고 거절로 세지 않는다. 이틀 연속 거절하면 3일 쉰다. 아예 받지 않겠다고 하면 다시 묻지 않는다.
- 시연용으로 거절 기록을 미리 만들지 않는다.

### ⑧ 열 나는 가전

- 열 나는 가전(전자레인지·인덕션)은 맡길 수 없고 매번 '네' 확인이다. 화면 결과 글자를 그대로 읽는다 — 누름 장치가 눌렀다는 것과 가전이 가열했다는 것은 다르다.
- 누름 장치 설명은 서예솔이 한 줄로 끝낸다. 갠트리 기계는 같은 팀 HW 담당의 다른 프로젝트와 함께 쓴다([재사용 경계](reuse-boundary.md)) — 질의에서 물으면 자세히.
- 가열 여부·콘센트 모듈 갈래는 §5.

| 리허설 | 방법 | 통과 기준 |
|---|---|---|
| 이동 중 정지(무대 기구) | 실행 직후 키오스크 정지. 폰 정지·`POST /stop`도 한 번씩 | 정지 화면의 말이 `/status` 정지 단계와 맞다(`verified`일 때만 '멈췄어요'). 정지 뒤 추가 누름 없음 |

## 4. 결과 문구 원칙

**결과 문구를 대본에 고정하지 않는다.** 그날 실제 얻은 근거대로 읽는다.

| 상황 | 표시(폰 결과 배지 — 근거 줄) |
|---|---|
| 보내기 전에 연결 불가 | '못 했어요' — '보내지 않았어요' |
| 접수됐지만 상태를 확인하지 못함 | '몰라요' — '보냈지만 설정이 바뀌었는지 몰라요. 집에서 가전을 확인해야 해요.' |
| 상태 재조회로 바뀐 것을 확인 | '됐어요' — '상태를 확인했어요' |
| 보내기 전 조회에서 이미 그 설정 | '이미 그 설정이라 보내지 않았어요' |

- 폰과 키오스크 문장이 조금 다르다(키오스크 '보냈지만 됐는지 몰라요. 가전을 봐 주세요.'). 함께 보일 때는 각 화면 글자를 그대로 읽는다.
- 확인하지 못하면 '몰라요'로 남기고 자동으로 다시 보내지 않는다. 서버가 보고하지 않은 성공을 말로 만들지 않는다.
- 정지는 엔코더로 멈춤을 본 때만 '누름 장치가 멈췄어요', 그 밖은 '누름 장치가 멈췄는지 몰라요'와 '다시 멈추기'.
- 연습 표시(폰 배지 '연습', 키오스크 띠 '연습이에요. 실제 가전은 그대로예요', 카드 '제안 · 시연 데이터')를 가리지 않는다.

### 5-2. 옛 주 시연(가열 종료 → 공기청정기 자동)의 남은 쓰임

- 10/13~19 판의 '가열 종료 감지 → 공기청정기 바람 세게 → 다음부터 자동으로'는 **주 시연에서 뺐다**. 규칙(`cook_done_air`)은 모의 끝-끝까지 구현·시험돼 있고([devlog](devlog/devlog_2026-10-13-auto-rule.md)), 결선 전 정리 때 '가열 종료 → 공기청정기' 규칙은 **꺼짐**으로 둔다.
- 질의에서 "옛 가전과 LG 가전을 잇는 장면은?"을 물으면 말로 설명하고, 콘센트 모듈이 준비됐으면 질의 시간에만 보인다. 준비 안 됐으면 **모의**(가열 종료 주입)로, '연습' 표시를 가리지 않고 보인다.

## 6. 무대 배치

- 책상 150×55cm ×2: 키오스크와 공기청정기를 관객이 함께 볼 수 있게, 전자레인지 + 누름 장치(+ 콘센트 모듈)는 다른 책상. 본체 카메라는 발표자가 다가가는 길을 보게.
- 키오스크 패널과 폰 화면(미러링)이 관객 쪽을 향하게. 기구 카메라는 조작부 근접.
- 여행용 공유기 + 핫스팟(LG 클라우드·날씨용), RPi5·RPi4 같은 망.
- 녹화 영상(⑧·백업)과 노트북 모의 서버를 1분 안에 전환할 수 있게.

## 9. 깨끗한 시연 준비 점검표 (설치 14:50~15:20 마지막 10분)

> 심사위원이 보는 화면에는 오늘 보일 가전·규칙·기록만 있어야 한다. 설치 순서는 [결선 운영 런북](결선-운영-런북.md) §3. 한 사람이 읽고 다른 사람이 화면으로 확인한다.

**먼저 볼 셋**
- [ ] **습관 기록:** '알게 된 것'에서 실제 기록으로 생긴 습관과 결선장 시각에 맞는 것이 있는지 → 장면 ③을 실물로 할지 연습으로 할지 정한다.
- [ ] **카메라 켜짐:** 키오스크 설정 '사람 감지 카메라' 켜짐, 자리 비움 화면으로 들어가는지 한 번 본다.
- [ ] **자동 실행 꺼짐:** 장면 ④에서 맡길 루틴이 이미 맡겨진 채가 아니다. '가열 종료 → 공기청정기' 규칙 꺼짐.

**가전·규칙·기록**
- [ ] 가전 목록은 오늘 시연하는 것만 — 공기청정기, 전자레인지. 미설정·시험 가전이 없다. 연습 기기가 남아 있으면 '연습' 표시가 보이게 둔다.
- [ ] 개발자 모드 꺼짐. 개발자 모드를 끄면 내장 전자레인지가 목록에서 숨는 문제는 결정한 방식대로 확인.
- [ ] 시각 규칙(22:00 켜기·07:00 끄기)이 평가 시간에 울리지 않는다.
- [ ] **하루 묻는 횟수 상한 끔**(런북 — `SIMPLELAY_DAILY_ASK_LIMIT=off`, 백업 뒤). 시연 뒤 되돌린다.
- [ ] 기록 탭 맨 위가 오늘과 상관없는 연습·실패 기록이 아니다. 실물 근거 기록(`state_confirmed` 등)은 지우지 않는다.
- [ ] 조용한 시간·방해 금지가 평가 시간(15:40~16:00)에 걸려 있지 않다 — 걸리면 카드·자동 실행이 막힌다.

**연습 기록 지우기 — 팀 둘 다 승인 + DB 백업이 있을 때만.** 하나라도 빠지면 지우지 않고 "연습 기록입니다"라고 말한다.
1. 박성원·서예솔 둘 다 승인, 무엇을 지울지 말로 정한다. 실물 근거 기록은 지우지 않는다.
2. 본체 DB 백업을 먼저 — `simplelay-backup-YYYY-MM-DD-before-<이유>.db`, 크기가 0이 아닌지 확인.
3. 앱 화면의 삭제로 지운다. DB를 직접 고치지 않는다.
4. `/health/detail` 준비 확인 → 키오스크·폰 반영 확인.
5. 지운 것과 백업 이름을 그날 기록에 남긴다.

**날씨·시간·폰**
- [ ] 본체 시각이 맞다(RPi5는 RTC 배터리 없음 — 인터넷에 붙었는지, 아니면 노트북 시각으로).
- [ ] 날씨·바깥 공기가 대회장 기준 실제 값이거나, 없으면 대체 문구 그대로. 오래된 경보 알림은 닫는다(지우지 않는다).
- [ ] 시연 폰: 개인 알림 끔, 충전, 릴리스 APK, 미러링.
- [ ] 본체 env 개발자 실물 조작 끔, API 문서 페이지 닫힘(CLAUDE.md '평가 전에 끌 것').
- [ ] 마지막: 키오스크 첫 화면(또는 장면 ①을 위해 자리 비움 화면), 실행 중·정지 대기·비상 대기 표시 없음.
