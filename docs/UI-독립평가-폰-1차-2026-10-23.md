# 폰 UI 1차 검토와 아이콘·배너 시안

사용자 요청으로 AI 도구의 별도 세션에서 당시 코드·골든을 읽기 전용 검토했다. 실사용 시험, 실물 작동 평가, 사용성 개선 수치가 아니다.

## 발견

1. **P1: 옛 탐색 구조가 남음.** 홈의 ‘저장한 동작 전체’에서 ‘루틴 / 내 루틴 / 자동으로 하기’ 화면으로 돌아가 새 자동 실행 탭과 경로·용어가 겹친다. `app/lib/screens/routines_screen.dart`의 저장 동작 화면은 조회·편집·생성에 집중시키고 자동 설정은 새 탭으로 연결할 것.
2. **P2: 전체 목록 입구가 사라짐.** `app/lib/screens/home/routines.dart`에서 직접 실행하는 항목이 없으면 반환하여 시간 예약만 있는 사용자는 홈에서 전체 목록에 접근할 수 없다. 전체 목록·생성 입구를 표시 필터와 분리하고 로딩도 빈 공간 대신 표시할 것.
3. **P2: 큰 글씨에서 과업까지 거리가 김.** `task_home_large.png`, `task_automation_large.png`에서 브랜드·연결·음성·설명이 여러 줄이다. 자동 실행 안내를 줄이고 배너는 작게 또는 큰 글씨에서 생략할 것. 장식이 주 행동을 밀어내지 않아야 한다.
4. **P2: 거절의 화면 글자와 낭독 이름 불일치.** `app/lib/screens/home/suggestion.dart`의 보이는 ‘이번엔 안 할게요’가 접근성 이름에서는 ‘다음에’다. 대상명과 이번 제안만 거절한다는 뜻으로 맞출 것.

## 유지할 점

- 주 실행 버튼 하나를 강조하고 가전 탐색과 실행을 구별한 구조.
- 설정의 탭 숨김·원래 위치 복귀·정지 수단 유지.
- 공통 청록과 별도 경고·정지·연습 색, 미확인 결과의 정직한 표시.

## 이번 시안과 사용자 반응

이미지 생성 도구로 앱 아이콘·작은 홈 배너·홈 배치가 함께 보이는 **한 장의 제안 이미지**를 만들었다. 실제 앱 캡처나 배포 산출물이 아니다. 앱 자산은 이번 단계에서 교체하지 않았다.

- 브랜드 후보: 금색 S 대신 한 번의 터치를 나타내는 단순한 심볼, 기존 청록 계열 유지.
- 배너 후보: ‘복잡한 가전을 더 간단하게’. 낮은 높이, 비상호작용. 중요한 경고·제안·실행 버튼보다 낮은 우선순위.
- 사용자는 **오른쪽 세 번째 홈 UI와 한눈에 알아보이는 가전 그림**을 특히 선호했다. 실제 적용 시 추상적인 작은 기호보다 전자레인지·공기청정기 실루엣을 충분한 크기로 표시하는 것을 기준으로 삼는다.
- 일반 가전 그림은 종류를 설명할 뿐 실제 기기의 사진·전원·준비 상태를 증명하지 않는다. 이름·상태·연습 표시·사진 조작의 대체 버튼은 유지한다.

후속 구현 우선순위는 저장 동작 탐색과 전체 목록 입구 → 문구·낭독 일치 → 큰 글씨 대응 → 승인된 그림·배너 적용이다. 이 문서는 발견·방향의 기록이며 위 결함을 수정했다고 주장하지 않는다.
