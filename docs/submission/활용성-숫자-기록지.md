# 활용성 숫자 — 현장 기록지 (2026-10-19)

제출 서류에서 비어 있는 **활용성 숫자 세 가지**(원가 · 설치 시간 · 팀 밖 사용성)를 현장에서 바로 채우는 기록지다.
**방법·반복 수·담당·목표일은 [제출 전 검증 과업](../제출전-검증-과업.md)이 기준이고, 이 문서는 그 방법으로 적을 칸만 둔다.** 두 문서가 어긋나면 그쪽을 따른다.

- **모든 칸은 비어 있다.** 재지 않은 칸은 `측정 뒤 기입`으로 두고, 모의·추정·쇼핑몰 표시가로 채우지 않는다.
- 하지 못한 것은 빈칸이 아니라 **`수행하지 못함 — 이유`**로 적는다.
- 숫자를 서류로 옮기는 곳은 §4에 모았다. **한 번 잰 값을 "누구나 N분"으로 일반화하지 않는다.**
- 개인정보는 [사용자 의견 계획](../사용자-의견-계획.md) §1을 따른다 — 참여자는 `U1`·`U2`, 특성은 "70대"처럼 넓은 범주로만. 이름·연락처·장애 정보·얼굴·음성 원본은 어디에도 남기지 않는다.

## 1. 원가 — 시연 1대 BOM

품목 전체 목록은 [제출 전 검증 과업 §3-1](../제출전-검증-과업.md)에 있다. 여기서는 **금액과 출처**만 채운다.

**채우는 규칙.**
- **실제 구매가만** 합산한다. 영수증·주문 내역이 없으면 금액 칸을 비우고 출처 칸에 `영수증 없음`이라고 적는다.
- 쇼핑몰 표시가를 참고로 적을 때는 금액 칸이 아니라 **비고 칸**에 `조사 12,000원(2026-10-__)`처럼 적고 **합계에 넣지 않는다.**
- 지급품·기존 보유품은 금액을 적되 조달 칸으로 구분해, 합계를 **지급품 포함/제외 두 줄**로 낸다.
- 3D 출력물은 재료비 기준인지 외주비 기준인지 비고에 적는다.

| 구분 | 품목 | 수량 | 실제 구매가(원) | 조달 | 단가 출처(영수증·주문 번호·날짜) | 비고 |
|---|---|---|---|---|---|---|

**말할 때.** "지급품을 빼면 ○○원입니다"처럼 **범위를 먼저** 말한다. 공기청정기는 시연 대상 가전이라 원가에 넣지 않고 따로 말한다.
상용 버튼 로봇과 가격을 비교하지 않는다 — 우리 쪽은 1대 제작 원가이고 상대는 양산 소비자가라서 같은 기준이 아니다.

## 2. 설치 시간

단계 정의는 [실측 기록표 §2](../실측-기록표.md)(① 부착 → ② 원점 → ③ 버튼 좌표 보정 → ④ 준비 확인 → ⑤ 첫 누름 확인)를 그대로 쓴다.
**①~④는 콘센트 모듈 없이도 잴 수 있고, ⑤는 솔레노이드가 있어야 한다.** 스톱워치로 재고, 손·장치만 보이게 영상으로 남긴다.

**재는 방법.** 단계가 끝난 순간에 스톱워치를 **멈추지 않고** 랩만 찍는다(단계 사이 전환 시간도 설치 시간이다). 막혀서 문서를 다시 읽은 시간도 포함한다.
도움을 받았으면 그 단계에 `도움 1회`로 적고, 시간을 보정하지 않는다.

| 회차 | 설치자 | ① 부착 | ② 원점 | ③ 좌표 보정 | ④ 준비 확인 | ⑤ 첫 누름 | 합계 | 도움 횟수 | 막힌 곳 |
|---|---|---|---|---|---|---|---|---|---|
| 1 | 팀원(HW) — 처음 붙이기 | | | | | | | | |
| 2 | 팀원(HW) — 떼고 다시 붙이기 | | | | | | | | |
| 3 | **처음 해 보는 사람** | | | | | | | | |

| 재부착 뒤 버튼 위치 | 결과 |
|---|---|
| '30초' 버튼 | 측정 뒤 기입 (mm 또는 눌림/안 눌림) |
| '시작' 버튼 | 측정 뒤 기입 |

- 3회차 참여자가 팀 밖이면 §3과 같은 개인정보 원칙을 따른다.
- 결과는 [실측 기록표 §2](../실측-기록표.md)에도 함께 적는다.
- **말할 때:** "한 번 재서 ○분이었습니다. 표본 1회라 평균이 아닙니다."

## 3. 팀 밖 초기 사용성 점검 — 1~2명

**이름은 '초기 사용성 점검'이다.** 사용자 평가도, 접근성 검증도, 당사자 평가도 아니다. 고령자·시각장애인이 참여하지 않았다면 그 사용자를 위한 접근성을 검증했다고 말하지 않는다.
참여했더라도 1~2명으로 일반화하지 않는다.

**준비.** 모의 서버(실제 가전은 움직이지 않는다) + 폰 앱 + 키오스크(15.8형 패널, 없으면 노트북 브라우저). 화면의 연습·모의 표시를 가리지 않는다.
참여자마다 상태를 처음으로 되돌린다. 가전 등록(사진·버튼 자리 잡기)은 **설치자의 일이라 이 점검에서 뺀다** — 매일 쓰는 화면만 본다.

**진행자 규칙.** 아래 대본만 그대로 읽는다. **버튼 이름·위치를 알려 주지 않는다.** 10초 넘게 멈춘 곳은 기록지에 적는다. 한 과업이 5분을 넘으면 도움을 주고 `도움 받아`로 센다.

### 3-1. 핵심 과업 3개 (반드시 한다)

| # | 진행자가 그대로 읽는 말 | 성공 기준 | 보는 것 |
|---|---|---|---|
| **T1 이해하고 승인** | "화면에 뜬 카드를 읽고, 이 기계가 **무엇을 하려는지** 먼저 말씀해 주세요. 그다음, 하도록 허락해 주세요." | 대상 가전과 동작을 맞게 말하고, 승인해 결과 화면까지 봄 | 카드 문장과 글자 크기를 이해하는지. 승인 전에 **누를 순서**를 읽는지 |
| **T2 거절** | "다음에 뜨는 카드는 이번에는 하지 않겠다고 해 주세요." | **'이번엔 안 할게요'**로 넘김 | 승인과 거절을 헷갈리지 않는지. 거절을 '다시 받지 않기'로 오해하지 않는지 |
| **T3 정지** | "지금 하고 있는 일을 멈추고 싶어졌습니다. 멈춰 보세요." | 실행 중 **'정지'**를 눌러 정지 결과 문장까지 봄 | 정지 단추를 **몇 초 안에** 찾는지. 결과 문장을 멈춘 것으로 읽는지 |

## 4. 숫자를 서류로 옮기는 곳

채운 값을 아래 자리에 **그대로** 옮긴다. 옮길 때 문장을 세게 바꾸지 않는다.

| 숫자 | 옮길 곳 | 쓸 수 있는 문장 |
|---|---|---|
| 원가(지급품 포함/제외) | [보고서](개발완료보고서-초안.md) §6-5 · [소개서](작품소개서-초안.md) '잴 값' 표 | "시연 1대 실제 구매가 ○○원(지급품 제외)." |
| 설치 시간 3회차 | 보고서 §5-3 · 소개서 같은 줄 · [실측 기록표 §2](../실측-기록표.md) | "처음 해 보는 사람이 ○분 걸렸습니다(1회)." |
| 사용성 점검 결과 | 보고서 §5-3 · 소개서 | "팀 밖 N명이 모의 화면 핵심 과업 3개 중 k개를 도움 없이 끝냈고, 막힌 곳 j개를 고쳤습니다." |
| 막힌 곳 → 고친 것 | 보고서 §7 의견 반영 표 | "점검에서 나온 ○○를 □□로 고쳤습니다." |

**쓰면 안 되는 문장.** "고령자도 쉽게 쓸 수 있습니다" · "접근성을 검증했습니다" · "설치는 누구나 ○분" · "상용 제품보다 저렴합니다".
질의응답에서 이 세 숫자를 묻는 질문의 답은 [질의응답 대비](../질의응답-대비.md) Q11에 있다.
