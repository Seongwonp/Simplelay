# 개발 도구(AI 코딩 도구) 사용 고지 — 초안 (2026-10-14)

> **상태: 초안. 확정하지 않았다.** 대회 공식 규정·안내 문서는 이 초안을 쓸 때 열지 않았다(사용자 지시).
> 사용자(팀)가 규정 조항을 직접 확인하고 §2 질문의 답을 받은 뒤 문안·위치를 확정한다. 확정 전에는 제출 서류에 넣지 않는다.
> 원칙은 **사실대로 — 과장도 축소도 하지 않는다.** 도구가 한 일을 팀이 한 것처럼 쓰지 않고, 팀이 한 판단을 도구가 한 것처럼 쓰지도 않는다.

## 1. 고지 문안 초안

### 1-1. 짧은 판 (작품소개서·README 한 줄용)

> 본 작품의 소프트웨어 개발에는 생성형 AI 코딩 도구를 코드·시험 코드·문서 작성 보조와 코드 검토 보조에 사용했습니다.
> 문제 정의, 시스템 구조와 안전 정책 결정, 하드웨어 설계·제작·배선, 실물 시험과 결과 판정은 팀이 수행했습니다.

### 1-2. 긴 판 (개발완료보고서 §7용)

**사용한 범위(도구가 한 일).**
- 허브·실행기·폰 앱·키오스크의 코드와 자동 시험 코드 작성·수정 보조. 팀이 정한 요구·정책을 코드로 옮기고, 팀이 찾은 결함을 고치는 데 썼다.
- 설계 문서·작업 기록(devlog)·제출 서류 초안 작성 보조.
- 코드·문서 교차 검토: 다른 AI 도구에 심사위원·평가자 관점의 검토를 맡겨 결함 후보를 받았다. 받은 지적은 팀이 채택 여부를 정했고, 고친 것은 수정 전 실패하는 시험으로 확인했다.
- 개발 PC·보드에서 빌드·시험·배포 명령 실행 보조. 【확인: 보드 배포와 측정 스크립트 실행을 도구가 수행한 범위와, 그때 팀원이 입회·승인했는지 사실대로 적는다】

**팀이 한 일.**
- 문제 정의와 대상 사용자, 시연 시나리오(v4) 결정.
- 시스템 구조·보드 역할·안전 정책 결정(예: 버튼 누름은 매번 승인, 자동 실행은 허용한 낮은 위험 ThinQ 동작만, 가열 종료를 조리 완료로 말하지 않음, 결과를 잃으면 다시 보내지 않음).
- 하드웨어 설계·제작·배선·조립(갠트리·솔레노이드·콘센트 모듈). 모션 펌웨어의 제어 핵심은 팀원(HW 담당)이 이전 작품에서 작성한 것이다([재사용 경계](../reuse-boundary.md)). 【확인: 원작 펌웨어 작성에 AI 도구를 썼는지 HW 담당에게 묻고 사실대로 적는다】
- 실물 시험의 수행·관찰과 결과 판정(무엇을 "실물 확인"이라고 부를지 포함), 실측값 기록.
- 도구가 만든 코드·문서를 읽고 자동 시험·실기기 확인을 거쳐 반영할지 결정.

**검증 방법.** 도구가 쓴 코드도 사람이 쓴 코드와 같은 기준으로 다뤘다 — 자동 시험(10/14 기준 백엔드+RPi4 2,969·폰 793·키오스크 318, 골든 제외), 수정 전 실패 확인, 실물로 본 것과 모의로 본 것의 구분.

【확인: 위 문장 중 사실과 다른 곳, 빠진 사용 범위(예: 발표 자료·영상 대본·그림 제작에 쓴 도구)가 있으면 고친다】

## 2. 사무국에 물을 질문

1. **허용 범위:** 생성형 AI 도구(코딩 보조 도구 포함)를 코드·시험 코드·문서·발표 자료 작성에 쓰는 것이 허용되는가? 제한되는 산출물(예: 보고서 본문, 발표 자료)이 있는가?
2. **고지 의무와 방법:** 사용했다면 고지해야 하는가? 한다면 어느 문서의 어디에(개발완료보고서의 별도 장, 작품소개서, 공개 저장소 README, 발표) 어떤 형식으로 적는가? 정해진 양식·문구가 있는가?
3. **공개 저장소의 도구 설정 파일:** 공개 GitHub 저장소에 AI 도구용 작업 규칙 파일(예: 루트의 도구 설정 문서)이나 도구가 남긴 작업 기록을 두어도 되는가? 두어야 하는가, 빼야 하는가? 이미 커밋 이력에 있는 경우 처리 기준이 있는가?
4. **커밋 이력 표기:** 커밋 메시지·공동 작성자 표기에 도구 사용을 남기지 않은 것이 문제가 되는가? 이력을 다시 쓰지 않고 문서 고지로 갈음해도 되는가?
5. **외부 검토 기록:** AI 도구로 받은 모의 심사·코드 검토 결과 문서를 공개 저장소에 두어도 되는가?
6. **심사 반영:** AI 도구 사용 여부·범위가 독창성·완성도 평가나 실격 사유에 영향을 주는가? 기존 작품 재사용 고지와 같은 장에 함께 적어도 되는가?

## 3. 확정 절차

1. 사용자가 공식 규정의 해당 조항을 직접 읽고 조항 번호를 아래에 적는다: 【규정 조항: 】
2. §2 질문 중 규정으로 풀리지 않은 것을 사무국에 메일로 묻고 답을 받는다(답신 원문은 저장소 밖 로컬에 보관).
3. §1 문안을 확정해 보고서 §7·소개서·README의 정해진 위치에 넣고, 이 문서의 상태 줄을 "확정(날짜)"으로 바꾼다.
4. §4 점검 결과 중 고칠 것은 사용자가 정한 뒤 고친다. CLAUDE.md는 이 초안 작업에서 수정하지 않았다.
