### 쓰던 가전을 바꾸지 않고, 승인한 버튼만 누르고, 전력으로 확인한다

작은 버튼을 정확히 누르고 여러 단계 메뉴를 기억하는 일은 고령자와 저시력 사용자에게 부담이다. 멀쩡한 버튼식 가전을 스마트 가전으로 바꾸기도 어렵다.
버튼을 대신 눌러 주는 장치는 있지만, **명령을 보냈다고 가전이 동작한 것은 아니다.**

SimpleLay는 조작부 위에 버튼 누름 장치(CoreXY 갠트리 + 솔레노이드)를 얹고, 한 흐름으로 일한다.

1. **제안** — 사용 기록이나 정해진 시각으로 할 일을 큰 글씨 카드로 보인다.
2. **승인** — 사용자가 승인한 그 명령만 실행한다(버튼 누름은 매번 승인).
3. **누름** — 갠트리가 조작부의 버튼을 차례로 누른다(예: 30초 → 시작).
4. **확인** — 콘센트 CT 전력으로 가열 시작·종료를 확인한다. 확인하지 못하면 그대로 말하고 다시 누르지 않는다.
5. **이어서** — 가열 종료 뒤 LG 공기청정기 바람을 세게 할지 묻고, 보낸 뒤 상태를 다시 읽어 바뀐 것을 본 때만 성공이라 한다. '다음부터도 자동으로'를 고르면 같은 조건에서 승인 없이 한다(낮은 위험 동작만).

처음 등록(조작부 사진·버튼 위치)은 보호자·설치자가 폰으로, 매일 쓰는 승인·거절·정지는 당사자가 키오스크와 폰으로 한다. 가열 종료 감지(조리 완료가 아닐 수 있음) — 취소·문 열림과 아직 구분하지 못하므로 화면도 그렇게 말한다.

### 하드웨어 — 함께 쓰는 것과 새로 만든 것

| 보드 | 역할 | 함께 쓰는 것 / 새로 만든 것 |
|---|---|---|
| RPi5 허브 | 제안·승인·기록, 15.8형 터치 키오스크, ThinQ 연동 | 새로(키오스크 앱 전체, 승인 결속, 제안·자동 실행 규칙) |
| RPi4 실행기 | 버튼 순서 실행·결과 확인·정지 보고 | 새로(확인·재시도·정지 세 단계 보고) |
| ESP32 모션 | CoreXY 갠트리(엔코더 모터 2개) + 솔레노이드 | **갠트리 기계 1대와 모션 제어 핵심은 같은 팀 HW 담당의 다른 프로젝트와 함께 씀.** 모션 보드는 따로, 실행기 규약·안전 계층은 새로 |
| ESP32 콘센트 모듈 | CT 전력 계측, 릴레이, 비상정지 래치 | 전부 새로 |

재사용 비율은 숫자로 말하지 않는다(줄 단위로 대조하지 않았다). 표 전체는 개발완료보고서 §3-1.

## 2쪽 — 시연과, 무엇이 실물인가

### 결선 시연 (v4, 약 6분)

1. **제안 거절** — '이번엔 안 할게요' → 장치는 움직이지 않는다.
2. **첫 조리 승인** — 갠트리가 전자레인지 버튼을 누르고 → 가열 시작·종료 감지 → '공기청정기 바람을 세게 할까요?' → '다음부터도 자동으로' → '허락하고 이번에도 하기' → 상태를 다시 읽어 확인.
3. **같은 조건에서 다시** — 조리는 다시 승인, 공기청정기는 추가 승인 없이. 이미 그 설정이면 변경 명령 없이 상태만 확인.
4. **기록 확인 → 자동 실행 끄기**(루틴 탭 '자동 규칙').
5. **정지 · 일부 실패** — 실행 중 정지하면 엔코더로 멈춤을 본 때만 '누름 장치가 멈췄어요', 그 밖은 '멈췄는지 몰라요'. 보냈지만 확인 못 하면 '보냈지만 설정이 바뀌었는지 몰라요'로 남기고 다시 보내지 않는다.

준비되지 않은 장면은 먼저 말하고 **모의 실행**(실제 가전은 누르지 않음, 화면에는 '연습'으로 표시)으로 보인다.

### 되는 것 / 아직인 것

이 표가 실물·모의를 말하는 유일한 표다. **다섯 장면 모두, 처음부터 끝까지 실물로 성공한 것은 아직 없다** — 남은 것은 실제 버튼 누름과 전력 판정이다.

| | 되는 것 (실물로 확인) | 아직인 것 (모의·미측정) |
|---|---|---|
| 누름 장치 | 모터 축 구동·엔코더 계수, 누름 제어 신호, 원점 미확인 시 실행 차단, 걸리면 다시 누르지 않고 멈춤(10/12~14, 벨트·솔레노이드 없는 시험대) | **캐리지 이동, 솔레노이드로 실제 버튼 누름** — 장착 작업 중 |
| 정지 | 보냄 → 모션 보드 확인 → 멈춤 확인, 10회 모두 멈춤 확인(중앙값 160 ms, 10/13 모터 축) | 캐리지가 움직이는 중·누르는 중의 정지. 전원 차단 회로 없음 |
| 전력 확인 | — | **CT로 가열 시작·종료 판정** — 설계·펌웨어 완료(컴파일·가짜 모듈 시험), 회로 제작 중. 제출 영상에는 없음, 결선(11/6) 목표 |
| LG 가전 | 실제 공기청정기로 찾기·추가·켜기·바람 세기 변경을 상태 재조회로 확인. 정해진 시각에 카드 없이 22:00 켜기·07:00 끄기(10/15~17, 각 1회) | 대회장 네트워크 조건 |
| 가열 종료 → 공기청정기 | — | 실제 전력부터 잇는 흐름 — 지금은 가열 종료를 주입한 모의로 끝까지 |
| 화면 | 15.8형 실패널 키오스크·부팅 자동 실행, 처음 화면, LG 가전 실행 화면, 다음 한 번 건너뛰기(10/16~18) | 실패·정지·비상 화면 상당수는 시험 렌더까지, 낭독·3 m 가독성 미확인 |
| 안전 보강 | — | 정지 경계 보강·토글 버튼 재누름 금지는 시험 통과·두 보드 배포까지, 실물 상황 시험 전 |
| 제안·등록 | — | 합성 이력·합성 좌표까지 |
