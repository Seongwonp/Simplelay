## 우리 집 가전, 바꾸지 않고 똑똑하게

### 문제

- 스마트 가전은 비싸다. 집에 있는 전자레인지나 세탁기는 그대로 쓸 만한데 원격 조작도 알림도 없다.
- 버튼이 작고 메뉴가 깊어서 어르신이나 손이 불편한 사람에게는 매일 하는 조작도 부담이다.
- 버튼을 눌러 주는 로봇은 이미 있다. 하지만 **눌렀는지, 가전이 정말 돌기 시작했는지**는 아무도 확인하지 않는다.

### SimpleLay

**가전 위에 얹는 작은 손가락 로봇**과 그것을 다루는 **허브**다.

- 버튼식 가전은 XY 갠트리가 버튼을 대신 누른다.
- 스마트 가전은 ThinQ Connect로 다룬다.
- 두 경로 모두 **"먼저 묻고, 승인받고, 실행하고, 됐는지 확인하는"** 같은 흐름을 탄다.

## 한 사람의 하루

시연 시나리오 v2의 여섯 장면을 하루 순서로 엮었다.

**아침 7시.**
- 지난 몇 주 동안 이 시간에 직접 즉석밥을 데운 날이 쌓였다(28일 중 서로 다른 3일 이상).
- 거실 화면에 카드 한 장이 뜬다. "즉석밥 데울까요?"
- "시작"을 누르면 손가락 로봇이 [즉석밥] → [시작]을 차례로 누른다. 승인하지 않으면 아무것도 움직이지 않는다.
- *지금 수준: 제안·승인·실행 흐름은 모의로 검증했다. 실제 사용 이력은 아직 없어 시연에서는 시연용 카드를 쓴다.*

**조리가 끝나면.**
- "조리가 끝났어요. 공기청정기를 강하게 틀까요?"
- 한 가전의 결과가 다음 가전의 **제안**이 된다. 승인하면 ThinQ로 명령을 보낸다. 상태가 실제로 바뀐 것을 다시 읽어 확인했을 때만 "확인됨"이라고 적는다.
- *지금 수준: 모의. ThinQ 실제 가전 연결은 등록 가전 확보 뒤.*

**버튼이 덜 눌렸을 때.**
- 로봇은 누른 뒤 모터 전류와 가전 비프음으로 눌렸는지 확인한다.
- 확인이 안 되면 위치와 깊이를 조금 고쳐 다시 누른다. 세 번 안 되면 멈추고 알린다.
- *지금 수준: 설계·구현했고 모의 입력으로 검증했다. 시연의 실패는 일부러 넣는다. 실제 센서 판정 임계값은 실측 예정이다.*

**저녁 휴식.**
- "공기청정기를 켜고 선풍기를 약풍으로 켤까요?"
- 승인 한 번으로 두 가전의 단계를 묶는다. 앞 단계가 확인되지 않으면 다음 단계를 보내지 않는다.
- *지금 수준: 모의.*

**급할 때.**
- 폰이 먹통이어도 거실 화면에서 정지할 수 있다.
- 사용자가 멈춘 것("정지됨")과 확인 실패로 멈춘 것("안전 정지")을 다른 말로 알리고, 장치를 확인해 달라고 한다.
- *지금 수준: 화면 정지는 모의로 검증했다. 전원을 끊는 물리 비상정지 회로는 아직 없다.*

**싫을 때.**
- "다음에"를 누르면 이번만 넘긴다.
- 집에 없거나 이유가 사라져 시스템이 거둔 제안은 "싫어한다"로 배우지 않는다.
- *지금 수준: 모의.*

> 확장 계획: 세탁기(외출 전 시작 제안), 인터폰(방문자 → 승인 시 문 열기), 귀가 시 에어컨, 아침 복약 안내를 같은 흐름에 붙인다. 이는 실행 계획 단계다. 【제출 전 실제 구현·검증 여부로 고쳐 쓴다】

## 어떻게 동작하나

```
폰 · 거실 화면 ──▶ RPi5 허브 ──▶ RPi4 실행기 ──▶ 모션 제어기 ──▶ 손가락 로봇
                (해석·제안·승인)   (누름·확인·정지)          (CoreXY + Z 누름)
                     │                    ▲
                     └─▶ ThinQ(스마트 가전)   ESP32 콘센트 모듈(전력으로 "정말 돌았나" 확인)
```

- **RPi5**: 말과 버튼 이름을 누를 순서로 바꾼다. 습관을 세어 제안하고, 승인을 지킨다. 15.8형 거실 화면을 띄운다.
- **RPi4**: 누르고, 확인하고, 안 되면 다시 누르거나 멈춘다.
- **ESP32 콘센트 모듈**: 플러그에 흐르는 전력으로 가전이 실제로 동작하는지 본다. 비상시 전원을 끊는다(제작 예정).
- 세 보드는 LG 제공 임베디드 SW 플랫폼 위에서 동작한다.
- 핵심 경로는 **인터넷 없이** 돈다.

## 무엇이 다른가

1. **눌렀다가 아니라 "됐다"까지 본다.** 눌림, 가전 수용, 실제 동작의 세 층으로 나눠 확인하고, 층마다 복구 방법이 다르다.
2. **버튼 가전과 스마트 가전을 한 흐름에.** 오래된 가전과 새 가전이 같은 화면, 같은 승인, 같은 기록을 쓴다.
3. **화면은 서버가 확인한 것만 말한다.** 보낸 것, 받은 것, 상태가 바뀐 것을 구분한다. 모의 동작은 "모의"라고 표시한다.
4. **메뉴는 사용자가 만든다.** 조작부 사진 위를 짚어 버튼을 등록하고 루틴을 녹화한다. 고정 명령 버튼이 없다.
5. **교체 없이 붙인다.** 가전을 바꾸지 않아 비용과 폐기물이 적다. 【가격 비교 기입】

## 안전 원칙

- **승인 없이 움직이지 않는다.** 가열 기기는 특히 그렇다. 음성으로는 시작할 수 없고 멈출 수만 있다(설계).
- **확인하지 못하면 다시 보내지 않는다.** 결과를 잃으면 "확인 불가"로 두고 사람에게 묻는다. 중복 가열을 막기 위해서다.
- **정지는 화면과 따로 간다.** 폰이 먹통이어도 거실 화면에서 멈춘다. 전원 차단형 비상정지는 콘센트 모듈에 둔다(제작 예정).
- **가전 정지와 로봇 정지를 나눈다.** 가전의 정지 버튼을 누르는 것과 로봇 전원을 끊는 것은 별개의 수단이다.
- **접근성 표준을 따른다.** KS X 3253, KS X 9211, 고령층 친화 키오스크 기준. 큰 글씨, 음성 안내, 넓은 터치 영역, 색만으로 말하지 않기.
