## 1쪽 — 일상을 알아채고, 사람이 있을 때 묻고, 맡긴 것만

사진 자리(촬영 예정)

그림 1. 15.8형 키오스크(본체)와 공기청정기, 버튼식 전자레인지 위 누름 장치. 실물 사진.

### 집이 먼저 알아 두고, 맡긴 만큼만 알아서 한다

스마트홈은 앱을 열고, 규칙을 짜고, 알림에 답하라고 한다. 고령자나 처음 쓰는 사람에게는 그 자체가 부담이다.
SimpleLay는 사람이 직접 쓴 기록에서 일상을 알아채고, 사람이 있을 때 묻고, 사람이 맡긴 것만 알아서 한다.
LG 공감지능의 세 기둥(생활 · 조율 · 책임)에 맞춰 만들었다.

| 기둥 | SimpleLay가 하는 것 |
|---|---|
| **생활** — 알아챈다 | 앱·키오스크로 직접 쓴 것을 기록하고, 같은 시간대에 사흘 이상, 세 번 이상 되풀이하면 습관으로 알아챈다(카드에 쓴 날을 보임). LG 앱·리모컨으로 공기청정기 전원을 바꾼 것도 직접 사용으로 기록한다(모의 시험만). "공기가 텁텁하네"는 현재 규칙이 동작을 고르는 예이며 언어 모델 시연이 아니다. 규칙이 처리하지 못한 말에 한해 본체 안 언어 모델이 정해진 목록에서 후보 하나를 고르고, 실행 전 사람이 확인한다(인터넷 없이. 보드 규칙+모델 평가: 고정 50문장 동작 맞힘 29/30, 목록 밖·부정 오수락 0/16, 애매한 말 오수락 0/4. 학습에서 분리한 새 42문장은 전체 정답 38/42·목록 밖과 부정 오수락 0/17, 모델 호출 가운데값 9.8초. 한 번씩 잰 작은 표본이며 고정 세트는 규칙을 만든 문장이라 낙관적) |
| **조율** — 때와 기기를 맞춘다 | 사람이 있을 때, 평소 시각 10분 전에 "지금 할까요?"를 묻는다. 한동안 안 보이면 화면을 쉬고, 다가가면 깬다. 실내·바깥 공기, 날씨, 방 밝기를 엮어 제안하거나, 가전을 움직이지 않는 조언(환기 등)만 한다 |
| **책임** — 맡긴 것만 | 자주 승인해도 저절로 맡기지 않는다 — 사용자가 확인 칸(언제·무엇을·하지 않는 경우·끄는 곳)을 보고 눌러야 한다. 맡길 수 있는 것은 위험이 낮은 LG 가전 동작뿐. 열 나는 가전은 매번 '네' 확인을 받는다. 연달아 두 번 거절하거나 답이 없으면 그 습관은 7일 쉬고, '이미 했어요'는 그날 다시 묻지 않는다. 맡긴 동작은 5분 안에 맡기기를 해제할 수 있고, 반대 동작이 분명한 경우에만 원래대로 돌린다. 본체가 알게 된 것을 그대로 보이고 숨길 수 있다. 판단은 집 안 본체에서, 카메라는 사람 있음/없음만 보고 사진을 남기지 않으며 끌 수 있다 |

**상용 서비스와 다른 점(설계 차이).** 상용 서비스는 앱 알림으로 제안한다. SimpleLay는 실제 기록에서 사흘 이상, 세 번 이상 되풀이한 것만, 집에 사람이 있을 때 묻고, 맡긴 것만 자동으로 한다. 상용 쪽 방식(예: 묻는 것이 기본이고 자동 실행은 따로 켬)은 공개 자료 기준이며 **발표 전 재확인**한다. 성능 비교가 아니다.

### 하드웨어 — 흐름에 넣는 수단

버튼만 있는 옛 가전도 같은 흐름에 넣기 위해 조작부 위에 누름 장치(CoreXY 갠트리)를 얹는다. LG 가전은 공식 API로, 옛 가전은 누름 장치로 묶는다.

| 보드 | 역할 | 함께 쓰는 것 / 새로 만든 것 |
|---|---|---|
| RPi5 본체 | 기록·습관 판단·제안·맡기기, 15.8형 터치 키오스크, 사람 감지·언어 모델(기기 안), LG 가전 연동 | 새로(공개 모델을 2에폭 미세조정) |
| RPi4 실행기 | 버튼 순서 실행·결과 확인·정지 보고 | 새로 |
| ESP32 모션 | CoreXY 갠트리 + 누름 | **갠트리 기계 1대와 모션 제어 핵심은 같은 팀 HW 담당의 다른 프로젝트와 함께 씀.** 모션 보드는 따로, 실행기 규약·안전 계층은 새로 |
| ESP32 콘센트 모듈 | 전력 계측, 릴레이, 비상정지 래치 — 설계·펌웨어 단계. 회로 제작·연결 전이며 실제 가열 감시나 안전 근거로 사용하지 않음 | 전부 새로 |

재사용 비율은 숫자로 말하지 않는다. 표 전체는 개발완료보고서 §3-1.

## 2쪽 — 시연과, 무엇이 실물인가

### 결선 시연 (약 7분)

1. **다가가면 화면이 깸** — 자리 비움 시계 화면 → 사람이 보이면 처음 화면.
2. **"공기가 텁텁하네"** — 공기 불평 규칙이 '공기청정기를 켤까요?'를 제안 → '네'. 이 표현은 언어 모델이 고른 것이 아니다.
3. **습관 카드** — 10/25부터 쌓은 실제 기록에서 나온 카드(쓴 날 근거). 기록이 모자라면 '학습 중'을 보이고 연습 카드라고 밝힌다.
4. **맡기기** — 확인 칸을 읽고 사용자가 누른다.
5. **알게 된 것** — 습관별 평소 시각·근거·상태, 숨기기.
6. **'이미 했어요'** — 그날 다시 묻지 않음.
7. **콘센트 모듈** — 아직 회로 제작·연결 전이며 이번 시연의 안전 근거로 쓰지 않는다(다음 단계 한 줄).
8. **전자레인지는 매번 확인** — 누름 장치가 리허설에서 통과했을 때만.
9. **자동 실행·카메라 끄기.**

준비되지 않은 장면은 먼저 말하고 **연습**(화면에 '연습' 표시)이나 녹화로 보인다.
