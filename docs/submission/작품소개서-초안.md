## 우리 집 가전, 바꾸지 않고 똑똑하게

### 문제

- 스마트 가전은 비싸다. 집에 있는 전자레인지나 세탁기는 그대로 쓸 만한데 원격 조작도 알림도 없다.
- 버튼이 작고 메뉴가 깊어서 어르신이나 손이 불편한 사람에게는 매일 하는 조작도 부담이다.
- 버튼을 눌러 주는 로봇은 이미 있다. 하지만 **눌렀는지, 가전이 정말 돌기 시작했는지**는 아무도 확인하지 않는다.

### SimpleLay

**가전 위에 얹는 작은 손가락 로봇**과 그것을 다루는 **허브**다.

- 버튼식 가전은 XY 갠트리가 버튼을 대신 누른다.
- 스마트 가전은 ThinQ Connect로 다룬다.
- 두 경로 모두 **"먼저 묻고, 승인받고, 실행하고, 됐는지 확인하는"** 같은 흐름을 탄다.

## 한 사람의 하루

시연 시나리오 v3의 여섯 장면이다. 버튼만 있는 가전 세 가지 — **전자레인지·세탁기·인터폰** — 가 같은 등록·승인·확인 흐름을 탄다. 시연은 6분이다.

**아침 7시 30분 — 아침 데우기.**
- 사용자가 폰에서 만든 '아침 데우기' 루틴(평일 07:30)이 거실 화면에 카드로 뜬다. "'아침 데우기' 루틴을 실행할까요?"
- "시작"을 누르면 손가락 로봇이 전자레인지의 [즉석밥] → [시작]을 차례로 누르고 햇반을 데운다. 승인하지 않으면 아무것도 움직이지 않는다.
- 데우기가 시작된 것이 확인되면 "약 드실 시간이에요"를 폰 알림함과 거실 화면 안내 한 줄로 알린다. 시간 알림까지이고 약을 판단하지는 않는다.
- *지금 수준: 루틴·승인·실행·안내 흐름은 모의로 검증했다. 시연장에서는 시각을 기다릴 수 없어 '지금 실행'으로 띄운다. 전자레인지는 실제로 데울 계획이고, 빈 상태 가열 금지·조리 시간 상한·비상정지 확인을 거친 뒤에만 데운다. 콘센트 전력으로 "정말 돌기 시작했는지" 확인하는 경로는 만들었고 실측 전이다.*

**외출 전 — 세탁 시작, 버튼이 덜 눌렸을 때.**
- '외출 전 세탁' 루틴이 세탁기 [전원] → [표준] → [시작]을 누른다.
- 로봇은 누른 뒤 모터 전류와 가전 비프음으로 눌렸는지 확인한다. 확인이 안 되면 위치와 깊이를 조금 고쳐 다시 누른다. 세 번 안 되면 멈추고 알린다.
- *지금 수준: 설계·구현했고 모의 입력으로 검증했다. 시연의 실패는 일부러 넣는다. 실제 센서 판정 임계값은 실측 예정이다. 세탁기는 조작부 모형으로 보인다.*

**낮 — 방문자 문 열기.**
- 인터폰의 [문열림]처럼 민감한 동작은 언제나 사람이 보고 승인해야 누른다.
- *지금 수준: 모의. 인터폰 호출을 스스로 알아채는 기능은 없어 사람이 직접 띄운다. 문이 열렸는지는 확인하지 않는다. 인터폰은 조작부 모형으로 보인다.*

**귀가 — 세탁이 끝났어요.**
- 세탁기 플러그의 전력이 운전에서 대기로 돌아오고, 끝날 때 나는 종료음까지 함께 잡히면 "세탁이 끝났어요. 빨래를 꺼내 널어 주세요"라고 알린다.
- 하나만 잡히면 "세탁이 끝난 것 같아요 — 확인해 주세요"로 낮춰 말한다. 세탁기 전원은 끊지 않고 재기만 한다.
- *지금 수준: 판정 경로(전력 하강 + 종료음 교차 확인)는 가짜 콘센트 모듈과 합성 음으로 시험했다. 실제 세탁기·CT·마이크로는 측정 전이고 기준값은 추정이다. 무대 세탁기는 물을 돌리지 않으므로 두 신호를 시연 주입으로 넣고 그렇게 표시한다.*

**급할 때 — 비상정지.**
- 콘센트 모듈의 버튼을 누르면 화면·네트워크와 상관없이 전자레인지 전원이 끊긴다.
- 거실 화면 위쪽 띠와 폰 배너가 "비상정지가 걸려 있어요"를 알리고, 사람이 버튼을 풀고 화면에서 확인하기 전에는 다시 움직이지 않는다. 자동으로 풀리지 않는다.
- 화면의 정지 버튼도 같은 정지를 요청한다. "정지됨"(사용자가 멈춤)과 "안전 정지"(확인 실패로 멈춤)를 다른 말로 알리고 장치를 확인해 달라고 한다.
- *지금 수준: 콘센트 모듈 펌웨어는 컴파일까지, 회로는 조립 전이다. 래치·확인 해제 흐름은 가짜 모듈과 시뮬레이터로 시험했고, 화면 띠·배너는 키오스크 1.5.0과 폰 앱에 들어갔다.*

**싫을 때 — 사용자 통제.**
- "다음에"를 누르면 이번만 넘긴다.
- 집에 없어서 시스템이 거둔 제안은 "싫어한다"로 배우지 않는다.
- *지금 수준: 모의. 재실은 수동 입력이다.*

> 질의응답에서 보일 것: 스마트 가전(ThinQ Connect) 경로를 같은 승인·확인 계약으로 묶은 구조와 장애 주입(모의), 습관 기반 제안(28일 중 서로 다른 3일 이상). 시연 무대에서는 갠트리 1대(전자레인지)를 먼저 실물로 만들고 세탁기·인터폰은 조작부 모형으로 보인다.

## 어떻게 동작하나

```
폰 · 거실 화면 ──▶ RPi5 허브 ──▶ RPi4 실행기 ──▶ 모션 제어기 ──▶ 손가락 로봇
                (해석·제안·승인)   (누름·확인·정지)          (CoreXY + Z 누름)
                     │                    ▲
                     └─▶ ThinQ(스마트 가전, 모의)   ESP32 콘센트 모듈(전력으로 "정말 돌았나"·"끝났나" 확인, 비상 차단)
```

- **RPi5**: 말과 버튼 이름을 누를 순서로 바꾼다. 습관을 세어 제안하고, 승인을 지킨다. 15.8형 거실 화면을 띄운다.
- **RPi4**(안내문 예시의 RPi Zero 자리): 누르고, 확인하고, 안 되면 다시 누르거나 멈춘다. 콘센트 전력과 종료음으로 가전이 끝났는지 판정한다.
- **ESP32 콘센트 모듈**: 플러그에 흐르는 전력(CT)으로 가전이 실제로 동작하는지, 끝났는지 본다. 비상 버튼을 누르면 모듈 안에서 바로 가전 전원을 끊는다(펌웨어 컴파일까지, 회로 조립 중). CT는 전자레인지·세탁기를 동시에 재려고 두 개로 늘리는 중이다(부품 구매·펌웨어 작업 중).
- 세 보드는 LG 제공 임베디드 SW 플랫폼 위에서 동작한다.
- 핵심 경로는 **인터넷 없이** 돈다.

## 무엇이 다른가

1. **눌렀다가 아니라 "됐다"까지 본다.** 눌림, 가전 수용, 실제 동작의 세 층으로 나눠 확인하고, 층마다 복구 방법이 다르다.
2. **여러 가전에 같은 흐름.** 조작부 모양이 다른 버튼식 가전 세 가지가 같은 등록·승인·확인 흐름을 탄다. 스마트 가전(ThinQ)도 같은 계약에 묶었다(모의).
3. **신호 둘이 맞을 때만 단정한다.** 세탁 완료는 전력 하강과 종료음이 함께 잡혀야 "끝났어요", 하나면 "끝난 것 같아요 — 확인해 주세요".
4. **화면은 서버가 확인한 것만 말한다.** 보낸 것, 받은 것, 상태가 바뀐 것을 구분한다. 모의 동작은 "모의"라고 표시한다.
5. **메뉴와 루틴은 사용자가 만든다.** 조작부 사진 위를 짚어 버튼을 등록하고 루틴을 만든다. 고정 명령 버튼이 없다.
6. **교체 없이 붙인다.** 가전을 바꾸지 않아 비용과 폐기물이 적다. 【가격 비교 기입】

## 안전 원칙

- **승인 없이 움직이지 않는다.** 가열 기기는 특히 그렇다. 음성으로는 시작할 수 없고 멈출 수만 있다(설계).
- **가열은 안전 확인 뒤에만.** 시연에서 햇반을 실제로 데우되, 빈 상태 가열 금지·조리 시간 상한·비상정지 동작 확인을 설치 체크리스트로 거친다.
- **확인하지 못하면 다시 보내지 않는다.** 결과를 잃으면 "확인 불가"로 두고 사람에게 묻는다. 중복 가열을 막기 위해서다.
- **정지는 화면과 따로 간다.** 폰이 먹통이어도 거실 화면에서 멈춘다. 콘센트 모듈 버튼은 화면·네트워크와 무관하게 가전 전원을 끊고, 사람이 확인해야 풀린다(펌웨어 컴파일까지, 회로 조립 중).
- **끊을 것과 재기만 할 것을 나눈다.** 전자레인지는 릴레이로 끊을 수 있게 하고, 기동 전류가 큰 세탁기는 전원을 끊지 않고 CT로 재기만 한다.
- **가전 정지와 로봇 정지를 나눈다.** 가전의 정지 버튼을 누르는 것과 로봇 전원을 끊는 것은 별개의 수단이다.
- **접근성 표준을 따른다.** KS X 3253, KS X 9211, 고령층 친화 키오스크 기준. 큰 글씨, 음성 안내, 넓은 터치 영역, 색만으로 말하지 않기.
