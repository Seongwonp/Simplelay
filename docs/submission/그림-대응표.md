## 증거를 모으며 발견하고 고친 것 (10/7)

- 서버에만 있는 가전이 폰 홈·루틴에 보이지 않던 문제(`f3c1e7a`)
- 설정 카드 5장이 쌓여 가전 목록이 화면 밖으로 밀리던 문제 → 카드 한 장으로 묶음(`d87f5f8`)
- 실행 상태 화면이 루틴 카드의 질문을 되풀이하던 문제(`e46e0e5`)
