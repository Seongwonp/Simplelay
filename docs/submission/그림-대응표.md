# 보고서 그림 대응표 (2026-10-19)

[보고서](개발완료보고서-초안.md)와 [소개서](작품소개서-초안.md)의 현행 번호를 기준으로 한다. **10/19 번호 정리:** 사진 자리까지 포함해 나오는 순서대로 번호를 다시 매기고 캡션을 확정했다 — 보고서 그림 1~9, 소개서 그림 1~2. **10/19 추가:** 그림 6(키오스크 실패널)·그림 7(폰 홈·루틴·기록)을 실제 허브 캡처로 채웠다. 하드웨어 사진(그림 1·2, 소개서 그림 1 — 갠트리·콘센트 모듈·무대)은 촬영 전이라 자리로 둔다. 사진·캡처·실측 그래프는 본문에 '사진 자리(촬영 예정)'·'그래프 자리(측정 뒤 기입)' 한 줄과 확정 캡션을 둔다.
본문에는 지금 상태와 맞는 설계도만 넣고, 구버전 캡처·구버전 구성도는 본문에서 뺐다. 빈 그림의 할 일은 아래와 [체크리스트](제출-체크리스트.md) §5에 둔다.
골든 렌더를 패널 사진으로 쓰지 않는다. 선 색·모양으로 검증 수준을 말하지 않는다 — 검증 수준은 보고서 표로만 말한다.
