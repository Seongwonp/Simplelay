## 3. 시연 영상

**목표.**
- 길이 5~10분. 지도교수 의견: 동기, 한계, 성능 평가, 확장성을 담는다.
- 현장 시연이 실패할 때 대체 수단으로도 쓴다.
- **촬영 완료 10/20**(평가 의견). 장면 순서는 [시연 v4](../본선-시연-계획-v4.md) §0 다섯 장면(전자레인지 → 공기청정기)을 따른다(세탁기·인터폰·공기청정기 켜기 제안은 선택 보조). 비교 조건 실험의 실패 조건 장면도 함께 찍는다([제출 전 검증 과업](../제출전-검증-과업.md) §1).

**촬영 규칙.**
- 등급(실물/부분 실물/전부 모의)을 장면마다 자막으로 표시한다. 세탁기·인터폰은 **조작부 모형**이면 "모형"이라고 자막에 적는다.
- 모의 표시가 화면에 보이게 찍는다.
- 실패 주입은 "일부러 넣은 실패", 세탁 완료는 "시연 주입"이라고 자막으로 밝힌다.
- **전자레인지 가열은 [런북](../결선-운영-런북.md) §3-7 안전 체크리스트(빈 상태 가열 금지·조리 시간 상한·비상정지 동작 확인)를 통과한 뒤에만** 찍는다. 콘센트 모듈 회로가 없으면 가열하지 않고 **전원을 분리한 조작부·모형에서 누름만** 찍는다(전원이 들어온 전자레인지에서 시작 버튼을 누르면 가열이 시작된다).
- 내부 주소, 키, 플랫폼 내부 이름이 화면에 나오지 않게 한다.

**촬영 목록.** 컷 목록은 [런북](../결선-운영-런북.md) §9 "사용 장면 중심"으로 옮겼다(2026-10-10). 순서는 다음과 같다.
1. 장치 부착·사용자 과업·최신 폰/키오스크 승인 화면
2. v4 ① 거절 → ② 첫 승인·CT 가열 종료·강풍·자동 실행 허용
3. v4 ③ 같은 조건 재실행 → ④ 기록·자동 실행 끄기 → ⑤ 일부 실패 기록/영상
4. 정지·비상정지와 실제 검증 수준
5. 선택 보조: 공기청정기 켜기는 녹화 또는 명확히 표시한 모의(주 시연 제외), 인터폰·세탁 알림
6. 실측 그래프·한계·공개 링크

컷을 고칠 때는 런북 §9 한 곳만 고친다.

**영상 점검.**
- [ ] 자막의 검증 수준이 보고서 §5-1 표와 같다.
- [ ] 그래프는 실측 데이터로 만든 것만 넣었다("예시(합성 데이터)" 워터마크 그림 없음).
- [ ] 사람이 나온 컷은 손과 화면만 보인다(얼굴·개인 물건 없음).
- [ ] 백업용 원본 파일을 노트북과 USB 메모리 두 곳에 둔다(런북 §1-1).

## 5. 제출 전 채울 칸 (보고서·소개서 본문에서 옮김, 2026-10-18)

보고서·소개서 본문에는 【기입】을 두지 않는다. 재지 않은 값은 본문에 "미측정(실물 시험 뒤 기입)" 또는 "미수행(제출 전 수행 뒤 기입)"으로 적혀 있고, 채우면 그 줄을 결과로 바꾼다.
'필요한 것'의 **ESP32**는 모션 보드 복귀·벨트·솔레노이드 장착, **CT**는 콘센트 모듈 회로 제작이 먼저라는 뜻이다.

### 5-1. 실물이 있어야 채울 수 있는 칸

| 칸 | 넣을 곳 | 필요한 것 |
|---|---|---|
| 【기입】 캐리지 이동·원점 오차(mm) | 보고서 §5-2 | ESP32 |
