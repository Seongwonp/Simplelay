## 3. 시연 영상

**목표.**
- 길이 5~10분. 지도교수 의견: 동기, 한계, 성능 평가, 확장성을 담는다.
- 현장 시연이 실패할 때 대체 수단으로도 쓴다.
- **촬영 완료 10/20**(평가 의견). 장면 순서는 [시나리오 v3](../본선-시연-시나리오-v3.md) §1을 따른다. 2026-10-06 "한 사람의 하루"(전자레인지·세탁기·인터폰)로 확정됐으므로 아래 컷 표(아직 v2 장면)를 v3로 바꿔야 한다(§4 미결 1, [구현 갭](../시연-v3-구현-갭.md) S12).

**촬영 규칙.**
- 등급(실물/부분 실물/전부 모의)을 장면마다 자막으로 표시한다.
- 모의 표시가 화면에 보이게 찍는다.
- 실패 주입은 "일부러 넣은 실패"라고 자막으로 밝힌다.
- 가열하지 않는다.
- 내부 주소, 키, 플랫폼 내부 이름이 화면에 나오지 않게 한다.
