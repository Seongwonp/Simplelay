## 3. 시연 영상

**목표.**
- 길이 5~10분. 지도교수 의견: 동기, 한계, 성능 평가, 확장성을 담는다.
- 현장 시연이 실패할 때 대체 수단으로도 쓴다.
- **촬영 완료 10/20**(평가 의견). 장면 순서는 [시나리오 v3](../본선-시연-시나리오-v3.md) §1 "한 사람의 하루"(전자레인지·세탁기·인터폰, 6장면)를 따른다.

**촬영 규칙.**
- 등급(실물/부분 실물/전부 모의)을 장면마다 자막으로 표시한다. 세탁기·인터폰은 **조작부 모형**이면 "모형"이라고 자막에 적는다.
- 모의 표시가 화면에 보이게 찍는다.
- 실패 주입은 "일부러 넣은 실패", 세탁 완료는 "시연 주입"이라고 자막으로 밝힌다.
- **전자레인지 가열은 [런북](../결선-운영-런북.md) §3-7 안전 체크리스트(빈 상태 가열 금지·조리 시간 상한·비상정지 동작 확인)를 통과한 뒤에만** 찍는다. 콘센트 모듈 회로가 없으면 가열하지 않고 "시작 버튼 누름까지"만 찍는다.
- 내부 주소, 키, 플랫폼 내부 이름이 화면에 나오지 않게 한다.
