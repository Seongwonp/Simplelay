# 제출 영상 콘티 (10/28 제출, 10/27 촬영)

2026-10-26 작성. 기준: [제출 체크리스트 §3](제출-체크리스트.md)(길이 5~10분, 등급 자막, 얼굴·내부 주소 노출 금지), [시연 v4 §0](../본선-시연-계획-v4.md) 장면 ①~⑨, [결선 발표 대본](../발표/결선-발표-대본.md), [10/26 LG 앱 사용 기록 devlog](../devlog/devlog_2026-10-26-thinq-manual-use.md).

**원칙.** 핵심만 찍는다: 사용자를 알아채고, 묻고, 맡기고, 끌 수 있다. 우드락 집 모형·LED 연출은 11/6 현장 시연용이라 **이 영상에 넣지 않는다.** 습관 기록이 없으면 '학습 중' 화면과 '연습' 표시를 그대로 보인다. 실제처럼 꾸미지 않는다. CT(전력 감지) 장면은 없다. 목표 길이 약 6분(허용 5~10분).

## 2. 촬영 순서(효율)

컷 번호가 아니라 준비물이 같은 것끼리 묶는다.

1. **세팅 A: 폰+키오스크+공기청정기 (컷 2·3·8 + 설치 확인)** — ThinQ 연결 상태를 확인한 김에 앱으로 켜는 컷 8의 시험을 가장 먼저 한다(판독 120초를 기다리는 동안 컷 2 촬영).
2. **세팅 B: 키오스크 화면 위주 (컷 1·4·5·6·7·10)** — 같은 카드 상태에서 4→5→6→7 순서. 카드가 소진되면 보드에서 재주입이 필요하니 카드 수를 먼저 확인. 컷 1(깨움)은 시작 직전에, 컷 10(끄기)은 마지막에 찍는다. 컷 10 뒤에는 카메라가 꺼져 있다.
3. **세팅 C: 모터 (컷 9)** — 노트북(COM4)과 RPi4 전환이 필요해 따로 묶는다. 앞의 세팅이 끝난 뒤 시간이 남을 때만. 실패하면 뺀다.
4. **편집 전용 (컷 0·11)** — 촬영 없이 자막 카드. 촬영 후 환경 값(사람 감지 시험값)은 되돌린다.

## 4. 편집 점검

- 모든 컷에 등급 자막(실물/연출/모의/연습)이 보인다. 연습 카드는 '연습' 표시가 화면에 같이 나온다.
- 우드락 집 모형·LED가 화면에 없다.
- 내부 주소, 키, 얼굴, 개인 물건이 없다.
- 자막의 검증 수준이 보고서 §5-1과 같다. 앱으로 켠 기록은 확인된 만큼만 쓴다.
