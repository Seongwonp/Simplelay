# SimpleLay 브랜드 (2026-09-30 확정)

- **워드마크:** 소문자 `simplelay`. i의 점을 골드(`#D9A356`) 원으로 바꿔 "누를 버튼"을 뜻한다.
  - 글꼴은 Manrope SemiBold(600)을 윤곽선으로 바꿨다. SIL Open Font License 1.1이며 `OFL-Manrope.txt`를 함께 둔다.
  - 파일: 밝은 바탕용 `simplelay-wordmark-dark-on-light`, 어두운 바탕용 `simplelay-wordmark-light-on-dark`, 어두운 배지 포함 `simplelay-wordmark-on-dark-bg`. 각각 `.svg`와 `.png`(가로 1600px)가 있다.
- **앱 아이콘(시안 C · 폐루프 S):** 어두운 바탕(`#15181D`) 위에 한 번에 그린 골드 S 선과 끝의 흰 점(누르는 손끝)이다.
  - 파일: `simplelay-icon.svg`(둥근 모서리), `simplelay-icon-square.svg`(각진 정사각), `simplelay-icon-foreground.svg`(Android 적응형 아이콘 전경, 108 캔버스 중앙 66 안).
  - PNG는 48·72·96·144·192·512·1024px이다. 폰 앱 `app/android/.../mipmap-*/ic_launcher.png`에 반영했다.
- **색:** 골드 `#D9A356`, 어두운 바탕 `#15181D`, 밝은 글자 `#ECEEF0`. 앱 디자인 시스템([design-system.md](../../design-system.md))과 같다.
- **남은 것:** Android 적응형 아이콘 XML과 iOS·웹 아이콘, 키오스크 시작 화면 로고 배치는 데스크톱 Flutter 작업 때 붙인다.
