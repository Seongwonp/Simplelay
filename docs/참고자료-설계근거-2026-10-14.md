# 참고 자료와 설계 근거 (2026-10-14)

새 기능을 늘리기 위한 목록이 아니다. 지금 구현을 점검할 기준이다. 각 자료에서 고른 원칙을 **관련 코드·화면 → 시험 방법 → 확인 결과 → 남은 한계**로 잇는다.

**주의:** 논문 인용이나 지침 참고는 제품 성능 검증·보안 인증·접근성 인증이 아니다. 발표·서류에서도 "지침을 참고해 점검했다"까지만 말한다.

공식 HTML 지침과 논문 소개·초록만 확인했다. PDF 원문은 열지 않았다.
