# 솔레노이드 안전 전달표 — HW 담당용 (2026-10-16)

**검증 수준: 코드 확인만. 실제 코일·배선·복귀·발열은 미측정.** 실제 가전 대신 더미 패널에서 시작한다.
기구·전원 차단 담당과 기록 담당을 나누고, 이상 시 소프트웨어 응답을 기다리지 않고 준비한 전원 차단 수단을 쓴다.
펌웨어는 [모션 보드](../firmware-motion-corexy/README.md), 실물 시험은 [PS-1](안전계약-적용-보고-2026-10-15.md) §3을 따른다.

저항·다이오드·전압 수치는 실제 부품에 맞춰 HW 담당이 확정한다. 이 표를 부품 선정·회로 검증의 완료 근거로 쓰지 않는다.

## 3. 장착 뒤 첫 시험과 기록

1. 보드 식별·펌웨어 SHA·배선 확인 → 더미 패널, 짧은 단발 누름. 전원 순서는 위 표 확인 후 결정한다.
2. 누름 유지 중 소프트웨어 정지 / 전원 차단 / MCU 리셋을 각각 시험한다. 코일 전류·플런저 복귀·남은 누름 시간을 함께 기록한다.
3. 반복 누름의 온도·냉각, 이동 중 차단의 처짐·정지 거리까지 확인한다. 가전 버튼 최소 간격·길게 누름 기준과 비교한다.
4. [PS-1](안전계약-적용-보고-2026-10-15.md) S0~S5·S8~S11로 확장한다. 벨트·솔레노이드가 없으면 축·제어 신호 시험이라고만 기록한다.
