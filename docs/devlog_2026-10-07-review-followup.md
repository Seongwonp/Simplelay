## #3 전류 측정 세대 격리
- 창마다 별도 종료 이벤트를 쓰고, 잠금 안에서 세대와 종료 여부를 확인한 뒤 표본·오류를 반영한다. join 제한 뒤에도 옛 이벤트를 지우지 않는다.
- 회귀 `test_current_generation.py` 2건: 실제 join 2초를 넘긴 읽기를 새 창이 열린 뒤 반환시켰다. **수정 전 2건 실패**(옛 스레드 계속 수집, 옛 오류로 새 창 실패), 수정 뒤 관련 시험 **15/15 통과**.
- 드라이버 내부에서 영구 정지한 읽기는 파이썬이 강제로 종료할 수 없다. 반환하면 결과를 버리고 종료하며, 장치 읽기 제한시간은 실물 확인 필요.

## #5 불확실한 누름 뒤 같은 실행 차단
- 모션 실행 중 제한시간·전송 오류에도 `_reset_mid_run`을 세워 자동 원점·재누름을 막는다. 명시적인 다음 실행 경계에서 해제하는 기존 정책은 유지한다.
- `test_serial_motion.py` 회귀 2건: 응답 유실·전송 예외를 각각 주입. 시험 준비 인자 오류를 고친 뒤 **수정 전 모두 실패**(같은 실행이 재누름 뒤 성공으로 끝남), 수정 뒤 모션 관련 **53/53 통과**. 전송 명령 수와 다음 명시적 요청의 복구도 확인한다.
