# 인계 2026-10-27 — 노트북(학교)

데스크톱 새벽 작업 마감. RPi5는 `sync; poweroff`로 꺼서 들고 감. 앞선 인계는 [10/26 노트북 인계](인계-2026-10-26-노트북.md).

## 1. 바뀐 것(새벽)

- **본체 언어 모델 교체:** 보드에 2차 미세조정(2에폭) 파일을 올려 시험 채택. 보드 재평가(새 42문장 30→38, 오수락 2/17→0/17, 가운데값 13.4→9.8초) — [평가 §13](발표/언어모델-평가-2026-10-26.md), [보드 devlog](devlog/devlog_2026-10-27-lora-board.md). 설정 백업 `config_24.json.bak-20261027`이 보드 언어 모델 폴더에 있다.
- **원래 모델 파일은 보드에 없다**(공간 부족) — 데스크톱 저장소 밖 작업 폴더에 해시 맞춰 백업. 되돌리려면 그 파일을 보드에 다시 올리고 설정 백업으로 바꾼 뒤 `simplelay-llm` 재시작.
- 발표 숫자(README·대본·작품소개서)는 새 보드 값으로 갱신됨. 표현은 "공개 모델을 정해진 동작 고르기에만 조금 맞춤"으로 — 지도교수 '새 모델 학습 금지' 방침과 충돌하지 않게 말한다.

## 2. 학교에서 켤 때

1. 핫스팟에 붙으면 주소가 바뀔 수 있다 → RPi4 env `SIMPLELAY_LINK_ALLOW_FROM`, RPi5 env `SIMPLELAY_UART_PORT` 두 줄(바꾸기 전 `env.bak-날짜-이유` 백업). 시각이 멈춰 있으면 맞춘다.
2. `docker ps`에 `simplelay-llm`·`simplelay-backend`·`simplelay-presence`가 떠 있는지.
3. 폰 '말로 하기' 또는 키오스크에서 **"공기가 텁텁하네"**(규칙 경로)와 규칙 밖 문장 하나(예: "방이 좀 답답한데")를 말해 확인 카드가 뜨는지 — 실물 사용 경로 확인은 아직 안 했다. 실행은 '네'를 눌러야 한다.

- 실물로 확인하지 못한 이동·누름·자동 실행은 서류에 **미검증**으로 둔다.
