## 2. 하드웨어 진단 결과 (10/25 밤, 노트북에서 원본 텍스트 명령으로)

| 명령(HW 담당 안내 그대로) | 결과 |
|---|---|
| `M 0.3 0.3 300` 등 네 방향 | 캐리지가 **표대로 잘 움직임**(눈으로 확인) |
| 그때 `P` | 엔코더 A는 방향대로 변함, **엔코더 B는 늘 같은 값**(0 근처) |
| `Z` → `G 5 0` | `FAULT FOLLOW_ERROR`(B가 안 움직였다고 판단해 세게 밂 — 학교의 '파워가 너무 세다', 집의 '폭주') |

- 결론: 모터·드라이버 정상, **B 엔코더 신호(C1→GPIO18, C2→GPIO19, 3.3V·GND)가 ESP32에 안 들어온다.** 우리 명령은 원본과 같은 이동 함수(`enqueueMove`)를 탄다 — JSON 이동은 원점 필수·음수 거절·도착 오차 보고만 더한다.
- 전원(배터리 접촉)이 약하면 A도 7카운트로 떨어진다 — 시험 전 배터리 확인.
- **폭주하면** 텍스트 `S`(정지) 또는 배터리를 뺀다.
- 원본 펌웨어 규약 요약: `Z` 지금 자리 원점(움직이지 않음), `G x y` mm 이동→`DONE`, `T` 스위치봇 누름, `M a b ms` 생 PWM(방향 확인용), `P` 상태, `K kp ki kd kff` PID. 원점 좌하단, +X 오른쪽, +Y 위, **음수 좌표 거절**.
- 스위치봇은 10/25 밤 꺼져 있었다 — 누름 시험 전에 켠다.

## 3. 10/26 할 일 (순서)

1. **납땜 확인(노트북):** 모션 보드를 노트북에 꽂고 배터리 연결, 시리얼 115200으로 `P` → B를 손으로 돌리며 `P`(enc 두 번째 값이 꾸준히 변해야 함) → `Z` → `G 5 0`이 `DONE`, `G 0 0`. 안 되면 HW 담당.
2. **RPi4로 복귀:** 보드를 RPi4에 꽂고 `sh /mnt/rawdata/run_act.sh`(재부팅했으면 먼저 `systemctl start docker`, 시계 맞추기). 로그에 `motion MCU on /dev/serial/by-id/... state=unhomed`.
3. **앱 개발자 모드(폰):** 설정 → 앱 정보 'SimpleLay' 7번 → 설정 맨 아래 개발자 → 개발자 도구 → 토큰(본체 env `SIMPLELAY_DEV_TOKEN`, 사용자가 직접 입력) → 세션 시작 → 캐리지를 **매핑할 버튼판 왼쪽 아래 모서리**에 두고 **원점** → 1mm로 x+·y+ 방향 확인 → 5mm.
4. **매핑(폰):** 홈 → 가전 추가 → '사진첩에서 고르기'(종이 버튼판 사진은 에뮬레이터 사진첩 `microwave_panel.jpg`) → 네 모서리(왼쪽 위부터 시계 방향) → 초록 네모 가로·세로 mm(자로 잼) → 버튼 짚고 이름(10초·20초·M5·M3·M4·테스트·시작·정지) → 정지 버튼 '정지', 기다리는 자리 → 확인 주행. 서버는 `SIMPLELAY_FRAME_Y_UP=1`로 왼쪽 아래가 원점이 되게 계산한다.
5. **실제 누름·촬영:** 앱 또는 키오스크에서 그 가전 버튼 실행(승인) → 이동 → 스위치봇 누름 → 결과. 정지 대기·정지 → 다시 실행도 한 번. **영상·문서에 모의 결과를 섞지 않는다**(모의 보드는 결과가 '연습'으로 기록된다).
6. **시험값 되돌리기:** RPi5 env 사람 감지 `SIMPLELAY_ROOM_DIM_SECONDS=5`·`_AWAY_SECONDS=10`·`_GREET_GAP_SECONDS=30`은 촬영용 — 끝나면 줄을 지우거나 600·3600·10800. 키오스크 절전 화면은 새 키오스크 설치 뒤에만 보인다.

### 네트워크 메모
- 학교: 팀 폰 핫스팟(주소 바뀌면 RPi4 `SIMPLELAY_LINK_ALLOW_FROM`, RPi5 `SIMPLELAY_UART_PORT=socket://<RPi4>:7000`, `SIMPLELAY_PAIR_HOST=http://<RPi5>:8000` 고침 — 바꾸기 전 `env.bak-날짜-이유`).
- 집: 공유기 고정 주소(실제 값은 저장소 밖 메모). 10/25 밤 집 주소로 맞춰 둠(백업 `env.bak-20261025-home`).
- 폰이 401이면 앱이 연결 키를 잃은 것 — 키오스크 설정 → 휴대폰 연결하기로 다시 연결. `SIMPLELAY_PAIR_HOST`가 없으면 키오스크 코드 요청이 503.
- 보드 이미지 갱신은 핫스팟에서 `build_on_device.sh`가 큰 패키지 받다 시간 초과가 났다 — 코드만 바뀌었으면 기존 이미지에 `/app/rpi`·`/app/rpi4`만 바꿔 넣고 `docker commit`(같은 CMD·ENV) 하는 방식으로 했다. RPi4에도 같은 커밋.

### 사람 감지(온디바이스) 실행 메모
- 감지 프로그램(플랫폼 SDK로 빌드한 실행 파일·스크립트·라이브러리)은 **저장소 밖**(보드 데이터 폴더 안 감지 전용 폴더, 노트북 로컬 폴더 — 경로는 저장소 밖 메모)에 있다. 플랫폼 SDK 이름·내부 API는 공개 문서에 쓰지 않는다.
- 보드 재부팅 뒤 자동 시작은 아직 없다: RPi5의 감지 전용 폴더에서 `setsid sh run_presence.sh </dev/null >/dev/null 2>&1 &`. 결과 파일 `/mnt/rawdata/simplelay/presence_cam.json`(사람 수만, 사진 저장 없음). 카메라 끄기 표시 파일 `presence_camera_off`가 있으면 카메라를 닫는다.

## 4. 데스크톱에서 할 일 (키오스크 빌드 환경이 데스크톱에 있다)

1. **키오스크 새 화면 설치:** 최신 main으로 키오스크 ipk 빌드 → RPi5 설치(저장소 밖 로컬 빌드 환경, 설치 도구는 TTY 필요). 확인할 화면: 처음 화면 얇은 연결 알림, 설정 → 휴대폰 연결하기(스크롤 없는 한 화면), 설정 '사람 감지 카메라' 스위치, 자리 비움이면 화면 쉬기·돌아오면 깨우기·인사, 제안 카드 '맡기기'·'매일 이 시간에'.
2. **용어 통일 마무리(사용자 승인됨):** 기능 이름은 '루틴'·'자동 실행' 둘만. 서버 문구(`rpi/routines/auto_rules.py`·`candidates.py` '자동으로 하기' → '자동 실행', `rpi/api/service.py` `GANTRY_ABSENT_REASON` → "누름 장치가 이 가전에 달려 있지 않아요")와 폰·키오스크 문구(폰 `kGantryAbsentReason`, `rule_labels.dart` `kUserOffReason`, 홈 '저장한 동작 전체' → '루틴 전체', 키오스크 '저장된 동작'·'자동 루틴', 폰 정지 줄 "다른 곳에서 시작한 동작 진행 중 · [정지]")를 **한 커밋**에. 옛 문구 시험(`rpi/tests/test_plain_wording.py` 등) 함께 갱신. 저장된 옛 사유는 `_LEGACY_AUTO_NAME`으로 새 이름으로 보이게.
3. **사람 감지 자동 시작:** RPi5 부팅 때 감지 스크립트가 뜨게(키오스크 감시 컨테이너처럼 재시작 정책이 있는 컨테이너로 돌리거나 기존 부팅 훅 — 시스템 영역 읽기 전용 주의).
4. **열 안 나는 물리 가전 맡기기(결선 전):** CT 상태 확인 + 사람 있음 + 사용자가 '맡겨도 되는 가전'으로 표시한 경우만. 열 나는 가전은 늘 확인. 자주 승인해도 저절로 맡기지 않는다(`auto_rules.py` 머리말 정책).
5. **CT 보드:** 지금 보드는 USB 칩이 CH340이라 RPi4·RPi5에 드라이버가 없다(cp210x·ftdi·pl2303만 있음). CP2102·CH9102 칩 보드나 CP2102 변환기로 바꾼다.

## 5. 주의 (CLAUDE.md 규칙 재확인)

- HW 코드(ESP32 스케치·헤더·핀·PID)는 HW 담당만 고친다 — 우리 어댑터를 원본 규약에 맞춘다. `K` 값 조정도 HW 담당 판단.
- 비공개 자료(플랫폼 문서·SDK·키 값)는 커밋·외부 전송 금지. 커밋 메시지에 도구 이름·Co-Authored-By 넣지 않는다.
- 커밋 전: `rpi/tests/test_repo_guard.py`·`test_doc_links.py`, analyze 오류·경고 0, 실패 확인 게이트.
