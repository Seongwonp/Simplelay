# 촬영 대본 — 하드웨어 없이 찍는 장면 (2026-10-20 목표)

ESP32 모션 보드가 솔레노이드·레일 작업으로 나가 있고 콘센트 모듈 회로는 제작 전이다. 그래서 **지금 있는 것만으로 찍을 수 있는 장면**을 먼저 찍는다.
갠트리·CT가 돌아온 뒤 찍을 연속 장면은 [실물 장면 대본](촬영-대본-실물-장면.md)에 따로 있다.

- 컷 목록의 기준은 [운영 런북 §9](결선-운영-런북.md), 길이·자막 규칙·점검은 [제출 체크리스트 §3](submission/제출-체크리스트.md), 장면 순서는 [시연 v4](본선-시연-계획-v4.md)다. **이 문서는 그 규칙을 다시 쓰지 않고 컷별 대본만 적는다.**
- **말하면 안 되는 문장**은 [v4 §8](본선-시연-계획-v4.md) 표를 그대로 따른다. 특히 "조리가 끝난 것을 확인했습니다"·"공기가 깨끗해졌습니다"는 쓰지 않는다.
- 아래 **'화면 글자'는 2026-10-19 코드에서 그대로 옮긴 것**이다. 촬영 전에 `git log --oneline -- app rpi5-touchscreen-app`으로 '문구' 커밋이 있었는지 보고, 바뀌었으면 **화면에 보이는 글자를 따라 읽는다**(대본이 아니라 화면이 기준이다).

## 0. 이 날 찍는 것 / 찍지 않는 것

| 찍는다 | 찍지 않는다 (실물 대본으로 넘김) |
|---|---|
| 실제 공기청정기를 **정해진 시각 규칙**으로 켜고 끄는 것 | 갠트리가 전자레인지 버튼을 실제로 누르는 것 |
| LG 가전 실행 화면(보내는 중 → 결과)과 실패널 처음 화면 | CT로 가열 시작·종료를 잡는 것 |
| 다음 한 번 건너뛰기·되돌리기 | '누름 장치가 멈췄어요'(엔코더로 본 정지 결과) |
| 정지 단추와 정지 흐름 — **연습으로만** | 전자레인지에 붙인 갠트리 사진 |
| 일부러 넣은 실패 결과 화면 | 실측 그래프 |
| 폰 가전 등록 5단계·루틴 저장 | |

**연습(모의) 실행으로 찍은 컷은 실물인 척하지 않는다.** 화면에 연습 띠가 있으면 가리지 않고, 자막에도 같은 말을 적는다.

## 1. 준비물

| 무엇 | 비고 |
|---|---|
| 캠코더 1대 + 삼각대 | 고정 컷(화면 정면)이 주다. 손떨림 컷은 쓰지 않는다 |
| 보조 카메라 또는 폰 1대 + 작은 삼각대 | 폰 화면과 키오스크 화면을 **같은 시각에** 찍을 때 쓴다(장면 B·C) |
| SD카드 2장, 여분 배터리 | 한 장이 가득 차면 바꿔 끼우고 원본은 바로 노트북에 복사 |
| 외부 마이크 또는 조용한 방 | 말이 들려야 한다. 공기청정기 바람 소리가 말을 덮지 않게 거리를 둔다 |
| 조명 1~2개(또는 낮의 창) | 15.8형 패널에 반사가 생기지 않는 각도를 먼저 찾는다 |
| 15.8형 키오스크 패널 + RPi5 허브 | 켜 두고 시각이 맞는지 본다(허브는 시계 배터리가 없어 인터넷에 붙어야 시각이 맞는다) |
| 실제 공기청정기 | ThinQ 실제 모드. 공기질 센서 설정이 '항상'이어야 꺼진 상태에서도 값이 온다 |
| 폰(최신 앱) | 촬영 전에 설치 날짜를 확인한다 |
| 자·줄자 | 패널 크기를 말할 때 화면에 함께 보일 소품(선택) |

**촬영 전 점검.** 허브를 다시 켠 뒤에는 준비가 끝난 것을 확인하고(런북 §5-2) 실행한다. 화면에 내부 주소·키·개인 정보가 보이지 않는지 한 번 보고 시작한다.

## 2. 장면 A — 정해진 시각에 실제 공기청정기가 켜진다 (가장 먼저 찍는다)

지금 실물로 확인된 것 중 **제일 센 장면**이다. 사람이 아무것도 누르지 않는데 실제 가전이 바뀐다.

| 컷 | 무엇이 보이나 | 화면 글자(그대로) | 말할 것 |
|---|---|---|---|
| A-1 | 키오스크 처음 화면 — 큰 시계와 시계 아래 다음 루틴 줄 | 작은 머리말 **'자동 루틴'**, 그 아래 시각과 루틴 이름 | "카드로 물어보지 않고 정해진 시각에 하는 루틴은 '자동 루틴'이라고 미리 보여 줍니다." |
| A-2 | 꺼져 있는 실제 공기청정기(본체 표시등이 보이게) | — | "지금 공기청정기는 꺼져 있습니다." |
| A-3 | **기다렸다가** 시각이 되는 순간. 키오스크와 공기청정기가 한 화면에 들어오게 | 실행 화면 **'공기청정기를 켜고 있어요'** / 아래 작게 **'바뀐 것을 확인하면 알려 드릴게요'** | "사람이 누르지 않았습니다. 정해진 시각이 됐을 뿐입니다." |
| A-4 | 공기청정기가 실제로 켜지고, 화면이 결과로 바뀜 | 결과 화면(상태를 다시 읽어 확인한 때만 확인 표시) | "보내고 끝이 아니라, 상태를 다시 읽어서 바뀐 것을 본 다음에만 됐다고 말합니다." |
| A-5 | 폰 기록 탭의 그 줄 | 배지 **'됐어요'** | "기록에도 자동으로 한 것이라고 남습니다." |

**찍는 방법.** 실제 22:00·07:00을 기다리지 않고, **루틴 시각을 촬영 시각 2~3분 뒤로 바꿔 두고 기다려 찍는다.** 시각 규칙·실제 가전·상태 재조회는 모두 실물 그대로다.
자막: `실제 공기청정기 · 실제 시각 규칙(촬영을 위해 시각만 바꿈)`. 10/16 22:00 켜기·10/17 07:00 끄기를 실제로 확인한 날짜도 자막에 한 줄 넣는다.
**과장하지 않을 것:** 집 Wi-Fi에서 각각 한 번씩 본 것이다. "항상 2초 안에 된다"고 말하지 않는다 — 그날 화면에 보인 것만 말한다.

## 3. 장면 B — LG 가전 실행 화면 (승인 → 보내는 중 → 결과)

| 컷 | 무엇이 보이나 | 화면 글자(그대로) | 말할 것 |
|---|---|---|---|
| B-1 | 제안 카드 또는 루틴 호출 → 승인 전 확인 | 거절 쪽 글자 단추 **'이번엔 안 할게요'** | "승인하지 않으면 아무 일도 하지 않습니다." |
| B-2 | 승인 직후 실행 화면. 정지 단추가 같은 자리에 크게 | **'바람을 세게 바꾸고 있어요'**, 정지 단추 옆 **'정지를 누르면 더 하지 않아요'** | "보내는 중에도 멈출 수 있고, 멈추면 그 뒤를 더 하지 않습니다. 이미 바뀐 설정을 되돌린다는 뜻은 아닙니다." |
| B-3 | 결과 — 상태를 다시 읽어 바뀐 것을 본 경우 | 확인 표시가 있는 결과 화면 | "바뀐 것을 확인했습니다. 공기가 깨끗해졌다는 뜻은 아닙니다 — 바람 세기를 바꾼 것입니다." |
| B-4 | 실제 공기청정기 쪽을 같은 컷에 | — | (말 없이 바람 세기가 바뀐 것을 보인다) |
| B-5 | 이미 그 설정일 때 한 번 더 시도 | 폰 결과 **'이미 그 설정이라 보내지 않았어요'** | "이미 그 설정이면 명령을 보내지 않고 상태만 확인합니다." |

자막: `실제 공기청정기 · 실패널 키오스크`. 폰과 키오스크를 함께 찍으면 두 화면이 같은 말을 하는 것이 보인다.

## 4. 장면 C — 다음 한 번만 건너뛰기, 그리고 되돌리기

| 컷 | 무엇이 보이나 | 화면 글자(그대로) | 말할 것 |
|---|---|---|---|
| C-1 | 키오스크 처음 화면의 다음 루틴 줄과 그 옆 단추 | **'오늘은 건너뛰기'** | "오늘만 쉬고 싶을 때 루틴을 지우지 않고 이 회차만 넘깁니다." |
| C-2 | 누른 뒤 같은 자리 | **'되돌리기'** | "잘못 눌렀으면 바로 되돌립니다." |
| C-3 | 폰 루틴 탭의 같은 루틴 줄 | 그 회차만 건너뜀 표시 | "폰에서 해도, 본체에서 해도 같은 곳에 남습니다." |
| C-4 | 본체를 다시 켠 뒤 같은 화면 | 건너뛴 회차가 그대로 | "본체를 다시 켜도 유지됩니다(10/18 실제 본체에서 확인)." |

자막: `실제 본체(허브)·실제 폰`. C-4는 재부팅을 기다려야 하니 다른 컷을 찍는 사이에 끼워 찍는다.

## 5. 장면 D — 정지 (이 날은 연습으로만)

실제 누름 장치가 없으므로 **'누름 장치가 멈췄어요'는 이 날 찍지 않는다.** 엔코더로 멈춤을 본 때만 나오는 말이라, 연습 실행에서는 나오지 않는다.

| 컷 | 무엇이 보이나 | 화면 글자(그대로) | 말할 것 |
|---|---|---|---|
| D-1 | 연습 실행 중 화면 — 연습 띠가 위에 | 띠 **'연습이에요. 실제 가전은 그대로예요'** | "지금은 연습입니다. 실제 가전은 그대로입니다." |
| D-2 | 정지 단추를 누른다. 손과 화면이 한 컷에 | 정지 결과 화면 | "정지는 화면 어디서나 같은 자리에 있습니다." |
| D-3 | 폰 홈에서 음성으로 "멈춰" | 정지로 받아들인 화면 | "말로도 멈춥니다. '멈춰'·'그만'·'정지'입니다." |
| D-4 | (카메라를 보고) 정지 세 단계 설명 | — | "실제 장치에서는 정지를 보냄·모션 보드가 받음·엔코더로 멈춘 것을 확인함 세 단계로 나눠 보고합니다. 시험대에서 열 번 모두 멈춤까지 확인했고, 캐리지가 움직이는 중의 정지 거리는 아직 측정 전입니다." |

자막: `연습(모의 실행) — 실제 누름 장치는 작업 중`. D-4는 말로만 하는 컷이니 숫자를 말할 때 [실측 기록표](실측-기록표.md)에 있는 값만 말한다.
**실제 음성 정지 경로는 아직 실물로 확인하지 않았다** — 화면이 정지로 받아들이는 것까지만 보이고, 말로 설명을 덧붙이지 않는다.

## 6. 장면 E — 일부러 넣은 실패

| 컷 | 무엇이 보이나 | 화면 글자(그대로) | 말할 것 |
|---|---|---|---|
| E-1 | 실패를 주입하고 실행 | 폰 배지 **'몰라요'**, 근거 줄 **'보냈지만 설정이 바뀌었는지 몰라요. 집에서 가전을 확인해야 해요.'** | "보내긴 했는데 바뀐 것을 확인하지 못했습니다. 그러면 '됐어요'라고 하지 않습니다." |
| E-2 | 같은 상황의 키오스크 | 키오스크 **'공기청정기에 켜 달라고 했어요'** / **'켜졌는지는 아직 몰라요'** | "모르는 것은 모른다고 말합니다." |
| E-3 | 그 뒤 화면을 그대로 둔다 | 자동으로 다시 보내지 않음 | "자동으로 다시 보내지 않습니다. 두 번 켜지는 것이 더 위험합니다." |
| E-4 | 기록 탭 | 실패 줄과 이유 한 줄 | "확인하지 못한 것도 기록에 그대로 남습니다." |

자막: `일부러 넣은 실패(리허설 기능)`. 실제 센서 고장 사례가 아니라고 자막에 적는다.
E-1과 E-2의 **문장이 서로 조금 다르다**(폰은 '설정이 바뀌었는지', 키오스크는 '됐는지'). 둘을 나란히 보일 때는 화면 글자를 각각 그대로 읽는다.

## 8. 장면 G — 폰으로 등록하고 루틴을 만든다 (보호자·설치자 몫)

| 컷 | 무엇이 보이나 | 말할 것 |
|---|---|---|
| G-1 | 가전 추가 ① 조작부 사진 → ② 네 귀퉁이 → ③ 버튼 고르고 이름 | "처음 한 번은 보호자나 설치자가 조작부 사진에서 버튼 자리를 잡아 줍니다." |
| G-2 | ④ 정지 버튼·기다리는 자리 → ⑤ 자리 확인 | "마지막에 자리를 확인합니다." |
| G-3 | ⑤를 건너뛰었을 때 | 화면 글자 **'아직 자리 확인을 안 했어요'** (단추는 **'자리 확인 없이 끝내기'**) — "건너뛰면 건너뛴 채로 남습니다. 확인한 척하지 않습니다." |
| G-4 | 루틴 저장 — 사진 위 버튼을 순서대로 짚는다 | "자주 쓰는 순서를 저장합니다. 저장만 하고 누르지는 않습니다." |

자막: `실제 폰 · 합성 좌표(실제 조작부 보정은 측정 전)`. 실제 조작부의 위치 오차는 아직 재지 않았다는 것을 자막에 적는다.

## 9. 장면 H — 한계를 우리 입으로 말하는 컷

편집에서 맨 뒤에 붙인다. 한 번에 다 말하지 말고 세 문장으로 끊어 찍는다.

1. "오늘 보신 것 중 실제 가전이 바뀐 것은 공기청정기입니다. 전자레인지 버튼을 실제로 누르는 것과 콘센트 전력으로 가열을 판정하는 것은 **아직 측정 전**입니다."
2. "갠트리와 모션 제어 핵심은 같은 팀 하드웨어 담당이 만든 기계 한 대를 다른 프로젝트와 함께 씁니다. 이번에 새로 만든 것은 승인받은 명령만 누르고, 눌렸는지 확인하고, 먼저 제안하는 계층입니다."
3. "가열이 끝난 것은 전력으로 감지합니다. 취소나 문 열림으로 끝난 것과는 **아직 구분하지 못합니다.** 그래서 화면도 '조리 완료가 아닐 수 있어요'라고 말합니다."

## 10. 찍은 뒤 바로 할 것
