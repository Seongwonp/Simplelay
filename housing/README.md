# 키오스크 하우징 (2안 · 쐐기형 박스)

15.8형 터치 패널, RPi5, DHT22 온습도 센서를 상자 하나에 넣는 3D 프린터 분할 출력용 모델이다. 구조와 근거는 2026-10-16 하우징 구조안(1안·2안 비교)을 따르고, 2026-10-18 [하우징 검토](../docs/하우징-검토-2026-10-18.md)의 우선순위 1~11 중 실측 없이 할 수 있는 것을 반영했다.

- **모델:** [`simplelay_box.scad`](simplelay_box.scad). 무료 프로그램 OpenSCAD로 연다. 숫자를 바꾸면 전체가 다시 계산된다.
- **크기(1차안):** 폭 약 396 × 깊이 170 × 높이 약 260 mm. 앞면은 20° 뒤로 기울었다(10/18: 오른쪽 여유 `side_room` 8 → 16 mm라 폭이 8 mm 늘었다).
- **프린터 가정:** 220 × 220 × 250 mm. 모든 조각이 그 안에 들어간다. 가장 큰 조각은 198 × 170 × 130 mm다(렌더할 때 조각별 크기가 echo로 나온다).

## 조각 (파일 위쪽 `part` 값을 바꿔 하나씩 렌더 F6 → STL 내보내기)

| `part` | 개수 | 내용 |
|---|---|---|
| `shell_LB`·`shell_RB`·`shell_LT`·`shell_RT` | 각 1 | 몸통 4조각(왼쪽·오른쪽 × 아래·위). 화면 창, 위판 배기 슬롯, 센서 칸, 버튼 구멍, 받침 턱·멈춤 턱·고리 받침, 뒤판 나사 받침, 이음 덧살이 들어 있다. **위 조각(LT·RT)은 위판이 판에 닿게 뒤집힌 방향으로 나온다**(서포트 줄이기) |
| `back_LB`·`back_RB`·`back_LT`·`back_RT` | 각 1 | 뒤판 4조각(눕혀 출력). 몸통 뒤 테두리 안쪽에 끼운다. 아래 흡기 슬롯, 전원 입구, RPi5 고정 구멍(M2.5 — 모두 RT 조각)이 있다 |
| `sensor_lid` | 1 | 센서 칸 뚜껑(뒤 가장자리 선 홈 6 × 3) |
| `panel_clip` | 4 | 패널 누름 L자 고리 — 경사면 안쪽 고리 받침(인서트)에 M3로 조인다 |
| `fit_test` | 1 | **먼저 뽑는 맞춤 시험 조각**(67 × 69 × 99, 약 1시간) — 앞판 왼쪽 아래 모서리(화면 창 모서리·받침 턱·멈춤 턱·센서 칸·플러그 여유). 실제 패널을 대 보고 확인한 뒤 큰 조각을 뽑는다 |
| `vesa_plate` | (선택) | VESA 75 × 75 누름판. `panel_hold = "vesa"`일 때만. 패널 뒤 구멍 위치·나사·상자에 잇는 방법이 실측 전이라 기본은 고리 |
| `splice` | (선택) | 옛 평판 보강판(접착). `seam = "splice"`일 때만 쓴다 |
| `assembly`·`cutaway` | — | 전체 조립 모습·안쪽 단면 확인용(출력하지 않음) |

## 조립 순서

1. 몸통 아래 두 조각을 맞대고 분할면 안쪽 덧살끼리 M3 볼트 + 너트로 조인다(바닥 3·앞 턱 1). 위 두 조각도 같은 방법(위판 2). 그다음 위아래를 옆벽 덧살 볼트(양쪽 2개씩)로 조인다. 경사면 띠(창 위·아래·좌·우)는 패널이 바로 붙어 덧살 자리가 없으니 접착한다.
2. 뒤판 나사 받침 12곳과 고리 받침 4곳에 M3 열 인서트를 넣는다(납땜인두로 눌러 넣는다).
3. 패널을 넣는다: **아래 모서리를 받침 턱(좌우 멈춤 턱 사이)에 먼저 걸고, 위쪽을 앞으로 세워** 경사면 안쪽에 붙인다. 뒤에서 곧장 밀어 넣지 않는다. 창 뒤에 얇은 폼을 두고, `panel_clip` 4개를 고리 받침에 M3로 조인다 — 빠지지 않을 만큼만(세게 누르면 가장자리 헛터치 우려).
4. 패널 왼쪽 옆면에 **세 가닥**을 꽂는다: 영상(HDMI — 패널 쪽 단자가 mini HDMI일 수 있음, 실측)·터치(RPi5 USB-A ↔ 패널 USB-C 데이터)·전원(PD 어댑터 → 패널 USB-C 전원). HDMI만 꽂으면 터치가 안 된다. 오른쪽 옆면 OSD 버튼은 여유가 16 mm라 손가락이 닿지 않는다 — 전원 연결 시 저절로 켜지는지 먼저 보고, 안 켜지면 누름 막대를 구멍에 넣는다.
5. DHT22를 앞 아래 센서 칸에 눕혀 넣고(격자 면이 앞 슬롯 쪽), 3선을 `sensor_lid` 뒤 선 홈으로 뺀다. 뚜껑은 앞쪽을 받침 턱 밑으로 밀어 넣은 뒤 뒤쪽을 내려 칸 안쪽 받침 턱에 얹는다. 칸은 옆·뒤 칸막이와 뚜껑으로 본체 안 공기와 나뉘고 앞 턱·바닥 슬롯으로 바깥 공기를 받는다(선 홈으로 본체 안과 조금 통한다). 패널을 넣기 전에 해도 된다(손이 더 잘 들어간다).
6. RPi5를 뒤판 RT 조각에 고정하고(M2.5, 스탠드오프 필요, 쿨러는 안쪽) 선을 연결한다. 뒤판 4조각을 M3 나사로 닫는다(조각마다 3개). RT 조각이 정비 문이다.
7. 바닥 네 모서리 홈에 고무발을 붙인다(바닥 슬롯으로 센서 칸에 공기가 들도록 바닥이 떠 있어야 한다).

## 렌더 확인(2026-10-18, OpenSCAD 2021.01)

- **조각 STL 12개를 다시 뽑았다**([`stl/`](stl/): 몸통 4 · 뒤판 4 · `sensor_lid` · `panel_clip` · `fit_test` · `splice`). 10/16 STL을 덮어썼다.
  - 모든 조각이 한 덩어리다(CGAL `Volumes: 2`), 경고·오류 없음.
  - 모두 220 × 220 × 250 안이다: 몸통 198 × 170(위 조각 134) × 130.1, 뒤판 194.7 × 126.8 × 3, 뚜껑 59.4 × 54.4 × 2, 고리 19.3 × 10 × 3, `fit_test` 67 × 69 × 99.
  - echo 확인: 뒤판 나사 LB/RB/LT/RT = 3/3/3/3, 받침 가장자리 ~ 분할선 최소 15 mm, 가운데·위 줄 받침 ~ 패널 옆 최소 4 mm(패널 폭 밖), RPi5 구멍 4개 RT 조각, 배기 28개 7,560 mm²(흡기 3,500 mm²), 센서 칸 앞 504 + 바닥 1,204 mm²(이전 앞 336).
- **패널 넣는 길 간섭(검토 §3-3): 비어 있음.** 세워 넣기(받침 턱 모서리를 축으로 2°~60°)와 곧장 밀어 넣기(뒤로 0~120 mm) 둘 다 뒤판 받침·이음 덧살·고리 받침과 겹치지 않는다. 최종 자리의 패널은 받침 턱 윗면과 면으로만 닿는다(겹침 부피 없음).
- 렌더 사진(10/18 모델): [정면](renders/front.png) · [단면(왼쪽 일부를 잘라 안쪽을 본 모습)](renders/cutaway.png) · [맞춤 시험 조각](renders/fit_test.png)
- 숫자를 고쳤으면 STL을 다시 뽑는다(`housing` 폴더에서).

### 패널 넣는 길 다시 확인하기

`housing` 폴더에 아래 내용으로 확인 파일을 임시로 만들어(저장소에 넣지 않는다) `openscad -o out.stl -D 'part="none"' 확인파일.scad`. "Current top level object is empty"가 나오면 간섭 없음.

```
include <simplelay_box.scad>
module pl() translate([panel_x0, wall, panel_up]) cube([panel_w, panel_t, panel_h]);
module rot(a) face_frame() translate([0, wall, panel_up]) rotate([-a, 0, 0]) translate([0, -wall, -panel_up]) pl();
intersection() {
    insert_obstacles();   // 뒤판 받침 · 이음 덧살 · 고리 받침
    union() {
        for (a = [2 : 2 : 60]) rot(a);                                  // 아래 모서리를 받침 턱에 걸고 세우기
        for (d = [0 : 4 : 120]) translate([0, d, 0]) face_frame() pl(); // 뒤에서 곧장 밀어 넣기
    }
}
```

플러그 몸체는 이 확인에 들어 있지 않다. 플러그를 꽂은 채 세워 넣으려면 실측한 플러그 크기를 `pl()`에 더해 다시 돌린다(왼쪽 고리 받침·옆벽 덧살과 겹칠 수 있다).

**검증 수준:** OpenSCAD 렌더(형상, 한 덩어리, 조각 크기, 패널 넣는 길 간섭)까지 확인했다. 슬라이서 오버행·서포트, 3D 출력, 패널·RPi5·플러그 맞춤, 실물 조립, 열(RPi5 온도·센서 오차)은 아직 확인하지 않았다.
