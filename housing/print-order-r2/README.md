# 업체 전달용 — R2 왼쪽 몸통 선출력

## 출력 요청

- **필수:** `01_left_shell_r2.stl` 1개. 작은 시험편이 아니라 최종 하우징의 왼쪽 절반(위·아래 통짜)이다. 모니터 전체를 담는 완성 상자 1개는 아니다.
- **함께 출력 권장:** `02_panel_clip.stl` 1개. 모니터 뒤 고정 클립 맞춤 확인용. 최종 왼쪽에는 2개, 전체에는 4개를 사용한다. 나사·인서트·폼은 포함되지 않는다.

| 항목 | 값 |
|---|---|
| 몸통 STL 크기 | 218 × 170 × 260.225 mm |
| 클립 STL 크기 | 19.25 × 10 × 3 mm |
| 단위·배율 | mm · 100%, 자동 축소 금지 |
| 완성 상자 전체 폭 | 436 mm (이전 396 mm와 다름) |
| 왼쪽 포트 공간 | 총 60 mm, 이전 20 mm에서 +40 mm |
| 왼쪽 아래 클립 받침 | 패널 아래 끝 기준 35 → 105 mm, +70 mm |
| 왼쪽 위 클립 받침 | 패널 아래 끝 기준 190 mm 유지 |
| 패널 외형·두께·화면 창 | 기존 값 유지 |

## 업체 확인 사항

- 기본 자세는 바닥면을 출력판에 놓는 방향. 이 자세의 높이는 260.225 mm이므로 256 mm 높이 장비에는 그대로 들어가지 않는다. 장비의 실제 유효 크기·브림 여유를 확인한다. 임의 축소·분할 금지.
- 출력 방향·재료·레이어·벽 수·서포트·후처리는 업체와 협의한다. 내부 받침, 가로 방향 핀 구멍, 고리 받침의 오버행과 서포트 제거 접근성을 슬라이서에서 확인한다. 무서포트 출력을 보증한 파일이 아니다.
- 기존 출력 설정을 알 수 있다면 맞춘다. 구멍 안의 서포트 잔여물을 확인하고, 끼움 치수를 바꾸는 연마·구멍 확대·XY 보정은 사전 협의한다.
- 외관 면은 앞 경사면·왼쪽 옆면이다. 뒤틀림도 확인한다.

## 출력 후 확인

1. 모니터 크기·두께·화면 창 맞춤을 확인한다.
2. 실제 사용할 HDMI·USB-C 케이블을 모두 꽂고 뺀다. 60 mm는 합의한 설계 여유이지 실제 플러그·굽힘을 측정한 값이 아니다.
3. 클립을 새 위치에 대어 뒤 가장자리에 걸리는지 확인한다. 실제 인서트·M3 나사 규격과 체결 깊이를 확인한다. Ø4 인서트 구멍에 나사를 바로 조이는 설계가 아니다.
4. 클립 자리의 패널 뒤 두께에 따라 폼·클립 턱 보정이 필요할 수 있다. 패널을 휘게 조이거나 유리·포트에 하중을 주지 않는다.
5. 핀 구멍 Ø4, 핀 Ø3.8은 유지했다. 방향별 끼움 차이는 아직 미해결이므로 선출력에서 확인한다. 핀은 위치 맞춤용이며 구조 하중은 볼트 접합부가 맡는다.

## 버전·호환성

- **옛 폭 396 mm 몸통·뒤판과 섞어 조립하지 않는다.** 나머지도 R2 설정으로 새로 생성해야 한다.
- 이번 몸통은 최종 좌·우 통짜 2조각 조립 방식. 불필요한 몸통 위·아래 이음 덧살·핀 구멍은 제거했다. 뒤판 4분할·RPi5 정비 문은 유지한다.
- 이번 주문은 왼쪽 선출력만. 나머지 출력은 맞춤 확인 후 진행한다. 오른쪽 버튼·USB 접근, 전체 조립·열 검증은 아직 완료하지 않았다.
- 두 SCAD 파일은 같은 폴더에 둔다. 소스는 참고용이며 출력 주문은 위 STL 파일명·치수 기준이다.
- `preview_interior.png`는 형상 확인용 그림이다.

## 검증 범위

- OpenSCAD CGAL: Simple=yes, Volumes=2(외부 공간 포함, 고체 1개).
- 몸통 삼각형 5,488개, 모서리 공유 수가 2가 아닌 경우 0개. 부피 약 383.17 cm³. 서포트·채움 설정에 따라 재료 사용량은 달라진다.
- 패널 몸체와 고정 받침 사이 CAD 교집합은 비어 있음. 의도된 패널 받침·측면 멈춤 턱은 이 검사에서 제외. 실제 플러그 치수는 미측정이므로 케이블 간섭 검증은 별도다.
- 기본(구형) 작은 맞춤 시험편을 다시 렌더해 기존 STL과 정점 집합이 같음을 확인했다. R2는 별도 설정으로 적용된다.
