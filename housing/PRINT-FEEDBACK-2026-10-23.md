# 10/23 실물 맞춤 결과와 다음 출력

## 이번에 확인된 것

- 사용자 확인: 출력 마감 좋음, 모니터 외형 크기·두께 맞음. 해당 치수는 유지한다.
- 사용자 확인: 커넥터를 꽂는 부분이 하우징 돌출부에 막힘. 핀은 들어가는 구멍과 안 들어가는 구멍이 있음.
- 받은 `fit_test.stl`, `dowel_pin.stl`은 저장소 STL과 SHA256이 같다. 다른 모델을 출력해서 생긴 차이는 아니다.
- 사진에는 모니터와 실제 플러그를 끼운 상태가 없어 간섭하는 정확한 돌출부·위치·필요 절개량은 아직 확정할 수 없다.

## 1. 커넥터 간섭 — 크기 전체를 늘리지 않는다

현 모델은 왼쪽 플러그 공간 20 mm를 가정하고, 같은 쪽에 멈춤 턱과 고리 받침을 둔다. `fit_test`에도 왼쪽 아래 멈춤 턱과 아래쪽 고리 받침이 들어 있다. 기존 모니터 삽입 간섭 검사는 **플러그를 제외**했다. 패널 몸체가 맞았다고 커넥터까지 맞는 모델은 아니다.

수정 순서:

1. 모니터를 시험편에 맞춘 채 막히는 돌출부를 표시한다. 멈춤 턱인지, 원형 나사 구멍이 있는 고리 받침인지, 받침 바닥인지 구분한다.
2. 전원만이 아니라 영상·터치용 플러그도 실제 사용할 케이블로 함께 확인한다.
3. 포트가 차지하는 구간과 플러그 몸체·꽂는 방향의 공간을 확보한다. 해당 구간의 턱·고리 받침은 옮기거나 국부 절개한다. 지지·나사 자리를 통째로 없애지 않는다.
4. 플러그를 꽂은 상태와 꽂고 빼는 과정까지 시험편으로 다시 확인한 뒤 큰 몸통을 출력한다.

필요한 추가 정보는 **막히는 부분을 표시한 장착 사진**, 모니터 아래 끝에서 포트 구간까지 거리, 실제 플러그 몸체 크기다. 사진 비율로 mm를 확정하지 않는다. 아직 본체 CAD·기존 STL은 바꾸지 않았다.

## 2. 모니터 뒤 고정 — 별도 부품이 원래 있다

`panel_clip.stl`은 기존 설계의 별도 부품이다. 이번 세 출력(맞춤 시험편·핀 시험편·핀)에 포함되지 않는다. 최종은 4개이며, 먼저 **1개만 시험 출력**한다.

- 경사면 안쪽 나사 받침에 M3 나사로 고리를 붙이고, 고리 끝이 폼을 사이에 두고 패널 뒤 가장자리를 잡는 방식이다.
- 인서트 구멍 Ø4는 나사산이 아니다. 실제 사용할 M3 인서트 사양·길이를 확인해야 한다. 나사를 그냥 조여 고정 완료로 판단하지 않는다.
- 패널 뒤가 얇은 구간(4.7 mm)인지 두꺼운 구간(9.6 mm)인지에 따라 `clip_step` 또는 폼 두께를 조정해야 한다. 현재 `clip_step=0`, 폼 1 mm는 아직 실물 검증 전이다.
- 커넥터와 고리가 겹치면 고리 위치부터 바꾼다. 커넥터 확보 전에 4개 고정 위치를 확정하지 않는다.
- 상자 뒤판은 모니터 고정 고리와 별개다. VESA판은 상자 연결 방식이 미확정이므로 바로 최종 고정 부품으로 쓰지 않는다.

## 3. 핀 — 방향과 공차를 나눠 확인

받은 `dowel_test.stl`은 24 × 18 × 16 mm 시험 블록이다. 메시의 원형 단면 좌표에서 수직 구멍은 중심 (8,9), 수평 구멍은 중심 (y=9,z=8), 두 방향 모두 Ø4.0으로 확인된다. 핀 설계는 Ø3.8이다. 두 구멍은 다른 지름을 고르는 시험이 아니라 출력 방향 차이를 확인하는 시험이다.

한쪽만 안 맞는다면 수평 구멍 상부 처짐·출력 오차가 원인 후보지만, 사진만으로 확정하지 않는다. 핀 자체 거칠기·첫 층 퍼짐도 확인한다. 억지로 밀어 넣다가 핀을 부러뜨리지 않는다.

추가 시험편 `dowel_calibration.scad` / `stl/dowel_calibration.stl`:

- Ø4.0 / 4.1 / 4.2 / 4.3 / 4.4, 각 칸에 수직·수평 막힌 구멍 1개씩. 각 깊이 10.5 mm.
- 원래 핀으로 시험한다. 핀과 구멍을 동시에 바꾸지 않는다.
- 최종과 같은 재료·레이어·슬라이서 구멍 보정으로 출력하고 배율은 100%로 둔다.
- 수직·수평 각각 손으로 끝까지 들어가고 빼지는 최소 지름을 기록한다. 이 결과로 방향별 구멍 보정이 필요한지 정한다.
- 이 핀은 위치 맞춤용이다. 최종 구조 하중은 덧살 볼트·접합부가 맡는다.

| 4.1 | 미확인 | 미확인 |

## 다음 출력 범위

핀 공차 시험편 1개 + 기존 패널 고리 1개를 먼저 확인한다. 커넥터 간섭 위치 확인 전에는 대형 몸통 4조각을 재출력하지 않는다. 공차 시험편의 렌더·메시 검사는 출력 성공이나 실물 맞춤을 뜻하지 않는다.

## 파일 검증

- 공차 시험편: OpenSCAD CGAL 렌더 성공, `Simple: yes`, `Volumes: 2`(외부 공간 포함, 연결된 고체 1개).
- STL 크기: 176 × 18 × 16.6 mm. A1 mini 180 mm 폭 안이지만 여유가 4 mm뿐이므로 큰 브림·스커트를 사용한다면 A1에서 출력하거나 배치를 확인한다. 맞추려고 축소하지 않는다.
- 메시 검사: 공차 시험편 5,148개 삼각형, 모서리 공유 수가 2가 아닌 경우 0개. 기존 핀 시험편과 패널 고리도 같은 항목 0개.
- 사용자 제공 원본 STL과 기존 몸통·패널 치수는 변경하지 않았다. 실물 재출력·케이블 장착·고리 고정은 아직 확인하지 않았다.
